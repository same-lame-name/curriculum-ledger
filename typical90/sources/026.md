# 026 — Choosing N/2 Independent Vertices in a Tree

**Difficulty:** ★×4 (author's star rating)
**Link:** https://atcoder.jp/contests/typical90/tasks/typical90_z
**Source:** AtCoder Typical90 #026 — official statement and samples; editorial essence distilled from the official Japanese slides.

## Statement (original Japanese)
N 頂点の木があり、頂点には 1, 2, 3, ..., N と番号が振られています。
i (1≦i≦N-1) 番目の辺は、頂点 A[i] と B[i] を結んでいます。

最初、木のすべての頂点は白く塗られています。
N/2 個の頂点を、次の条件を満たすように赤く塗る方法を 1 つ出力してください。
・赤く塗られている 2 つの頂点が隣接している場所は存在しない。ただし、頂点 u, v が隣接しているとは、頂点 u と v を直接結ぶ辺が存在することを指す。

## Statement (English translation)
There is a tree with N vertices, numbered 1, 2, 3, ..., N.
The i-th edge (1 ≦ i ≦ N−1) connects vertices A[i] and B[i].

Initially, every vertex of the tree is painted white.
Output one way to paint N/2 vertices red satisfying the following condition:
・There is no place where two red-painted vertices are adjacent. Here, vertices u and v are said to be adjacent when there is an edge directly connecting u and v.

## Constraints
・1 ≦ N ≦ 10^5
・N は偶数
・1 ≦ A[i] < B[i] ≦ N
・入力はすべて整数
・与えられるグラフは木である

## Author's Editorial — Concept & Essence
- **Keyword (キーワード):** 二部グラフの性質を使おう
- **Core idea:** Every tree is bipartite, so it can be 2-colored red/green so that adjacent vertices get different colors. One of the two color classes has at least N/2 vertices; output any N/2 vertices from that larger class. This is exactly a maximum independent set.
- **Editorial steps:**
  - First, define a bipartite graph: a graph in which vertices directly connected by an edge are painted in different colors. (The slide's left two examples are bipartite; the rightmost one is not.) A bipartite graph contains no odd-length cycle, and a maximum matching can be computed in polynomial time.
  - A tree is always bipartite, so it can be 2-colored red and green. (If you don't know graph coloring, try to prove it yourself; it is related to the four-color theorem.)
  - When a tree is 2-colored, one of the red/green color classes occupies at least N/2 vertices. Therefore output N/2 vertices chosen from that class.
  - The 2-coloring can be implemented with depth-first search:
    ```cpp
    // G をグラフ、col[i] を頂点 i の色 (0, 1) とする
    void dfs(int pos, int cur) {
        col[pos] = cur;
        for (int i : G[pos]) {
            if (col[i] == -1) dfs(i, 1 - cur);
        }
    }
    ```
- **Complexity:** O(N)
- **Author's takeaway / typical pattern (典型):** Using the properties of bipartite graphs solves this in O(N). The special properties of trees and bipartite graphs appear often at AtCoder, so if you don't know them, be sure to look them up. The problem asks for a "configuration maximizing the number of chosen vertices", i.e. a maximum independent set (left as a reader exercise).

## Author's Reference Solution
`026.cpp` — 2-color the tree with DFS starting from vertex 1, collect the two color classes G1 and G2, and print the first N/2 vertices of the larger one.

```cpp
#include <iostream>
#include <vector>
using namespace std;

// Input
int N;
int A[1 << 18], B[1 << 18];

// Graph
vector<int> G[1 << 18];
int col[1 << 18];

void dfs(int pos, int cur) {
	col[pos] = cur;
	for (int i : G[pos]) {
		if (col[i] >= 1) continue;
		dfs(i, 3 - cur);
	}
}

int main() {
	// Step #1. Input
	cin >> N;
	for (int i = 1; i <= N - 1; i++) {
		cin >> A[i] >> B[i];
		G[A[i]].push_back(B[i]);
		G[B[i]].push_back(A[i]);
	}

	// Step #2. Graph Coloring
	dfs(1, 1);

	// Step #3. Get Answer
	vector<int> G1, G2;
	for (int i = 1; i <= N; i++) {
		if (col[i] == 1) G1.push_back(i);
		if (col[i] == 2) G2.push_back(i);
	}
	if (G1.size() > G2.size()) {
		for (int i = 0; i < (N / 2); i++) {
			if (i) cout << " ";
			cout << G1[i];
		}
		cout << endl;
	}
	else {
		for (int i = 0; i < (N / 2); i++) {
			if (i) cout << " ";
			cout << G2[i];
		}
		cout << endl;
	}
	return 0;
}
```
