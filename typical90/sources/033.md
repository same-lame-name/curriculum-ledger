## Statement (English translation)
E869120 is planning an illumination to be shown in winter. The illumination consists of H (rows) × W (columns) = HW LEDs. Each LED can be freely switched on or off.

The illumination is called **improper** when the following condition holds:
《Condition》There exists a 2 (rows) × 2 (columns) region, fully contained in the illumination and consisting of 4 LEDs, in which **2 or more** of the LEDs are lit.

Among the lighting patterns of a *proper* (not improper) illumination, find the maximum possible number of lit LEDs.

## Constraints
```
・1 ≦ H, W ≦ 100
・入力はすべて整数
```

## Author's Editorial — Concept & Essence
- **Keyword (キーワード):** コーナーケースに気を付けよう
- **Core idea:** The condition "no 2×2 block contains exactly two lit LEDs" limits how densely LEDs can be lit. By partitioning the grid into 2×2 blocks one can argue an upper bound of ⌈H/2⌉·⌈W/2⌉, and lighting exactly the cells whose row and column indices are both odd attains it. The single exception is when H = 1 or W = 1, where the 2×2 condition is vacuous and every LED can be lit — a corner case that the naive formula misses.
- **Editorial steps:**
  - First consider the case (H, W) = (4, 8). As in the figure, when the grid is divided into 8 regions, each same-colored region can contain at most 1 lit LED (upper bound).
  - However, writing (i, j) for the cell in row i from the top and column j from the left, lighting the cells where both i and j are odd allows 8 LEDs to be lit (lower bound).
  - Thus the upper and lower bounds coincide, and the maximum is 8.
  - By the same reasoning, for a general (H, W) it is optimal to light the cells where both i and j are odd, and the count is ⌈H÷2⌉ × ⌈W÷2⌉.
  - **Important things to think about (※):** ① think of an upper bound for the answer and then construct a configuration that achieves that upper bound; ② experiment on small cases and derive the general law.
  - The following program is presented:
    ```cpp
    int H, W;
    cin >> H >> W;
    cout << ((H + 1) / 2) * ((W + 1) / 2) << endl;
    ```
  - Unfortunately, this gets WA on the case (H, W) = (1, 8). The above solution outputs 4, but actually all 8 LEDs can be lit while satisfying the problem's condition. Such an exception is called a **corner case**. The following implementation is correct:
    ```cpp
    if (H == 1 || W == 1) cout << H * W << endl;
    else cout << ((H + 1) / 2) * ((W + 1) / 2) << endl;
    ```
- **Complexity:** Not explicitly stated in the editorial. The final implementation is O(1).
- **Author's takeaway / typical pattern (典型):** It is important to solve problems while paying attention to corner cases. Tips for avoiding corner cases include: proving the solution carefully; paying attention also to the lower end of the Constraints; and reading the problem statement's conditions carefully.

## Author's Reference Solution
`code/033.cpp` — O(1): if either dimension is 1, every LED can be lit (H·W); otherwise light the odd-row/odd-column cells, giving ⌈H/2⌉·⌈W/2⌉.

```cpp
#include <iostream>
using namespace std;

int H, W;

int main() {
	cin >> H >> W;
	if (H == 1 || W == 1) cout << H * W << endl;
	else cout << ((H + 1) / 2) * ((W + 1) / 2) << endl;
	return 0;
}
```
