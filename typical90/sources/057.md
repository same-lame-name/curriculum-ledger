## Statement (original Japanese)
```
1, 2, ..., M と番号付けられた M 枚のパネルがあり、全てのパネルは最初裏向きです。
また、あなたの前には 1, 2, ..., N と番号付けられた N 個のスイッチがあります。
スイッチ i を押すことにより、以下のことが起こります。
	・T[i] 枚のパネル A[i][1], ..., A[i][T[i]] が裏返り、表裏が変わる。
ここで、一度押したスイッチは二度と押すことができません。

あなたの仕事はこの M 枚のパネルの表裏を希望通りにすることです。なお、希望は長さが M の 0, 1からなる列 Sで与えられ、
S[j]=0 は、パネル j を裏に、 S[j]=1 はパネル j を表にすることを意味します。

パネルの押し方は押す順番を考慮しないと 2^N 通りありますが、このうち希望を満たす押し方は何通りでしょうか。
ただし、答えは非常に大きくなる可能性があるので、998244353 で割った余りを出力してください。
```

## Statement (English translation)
There are M panels numbered 1, 2, ..., M, and all the panels are face down at first.
Also, in front of you there are N switches numbered 1, 2, ..., N.
Pressing switch i causes the following to happen.
	・T[i] panels A[i][1], ..., A[i][T[i]] are flipped, so that their front and back sides change.
Here, a switch that has been pressed once can never be pressed again.

Your job is to make the front and back sides of these M panels as desired. The desire is given as a length-M sequence S consisting of 0 and 1,
where S[j]=0 means panel j should be face down, and S[j]=1 means panel j should be face up.

Ignoring the order of pressing, there are 2^N ways to press the panels; among these, how many ways satisfy the desire?
However, since the answer can be very large, output the remainder when it is divided by 998244353.

## Constraints
```
【制約】
・1 ≦ N,M ≦ 300
・1 ≦ T[i] ≦ M
・1 ≦ A[i][1] < ... < A[i][T[i]] ≦ M
・S[i]=0 または S[i]=1
・入力される値は全て整数である
```

## Author's Editorial — Concept & Essence
- **Keyword (キーワード):** 行列の掃き出し法を知ろう (know how to do row reduction / Gaussian elimination on a matrix)
- **Core idea:** Write the switches as the rows of an N × M 0/1 matrix A (A[i][k] = 1 iff switch i flips panel k), so that pressing a set of switches is the XOR of the corresponding rows, and the wish is a vector S. Counting the subsets of rows whose XOR is S is then linear algebra over F₂. The slide's engine is an operation that changes A without changing the answer — replace 「スイッチ j を押す」 by 「スイッチ j, i を押す」 — and iterating it acts exactly like 行基本変形 (elementary row operations), reducing A to upper triangular form; then the switches are decided greedily from the top, which answers 「パネルの裏表を希望通りにできるか」 and, when possible, gives the count 2^(number of all-zero rows).
- **Editorial steps:**
  - **Step 1 (encode as bits and XOR):** Set A[i][k] = 1 when pressing switch i flips panel k and 0 otherwise. Pressing a set of switches flips exactly the panels with an odd number of presses among the switches affecting them — the slide notes 「この問題の 1 回の操作は、ビット演算の XOR 操作と同じです」, and that XOR problems can often be solved by 掃き出し法 over the finite field F₂ (「（有限体 F₂ 上の）掃き出し法で解けることがあります」).
  - **Step 2 (the count-preserving operation):** Fix i, j and change 「スイッチ j での変化」 into 「スイッチ j, i での変化」 — concretely, for every k with A[i][k] = 1, flip A[j][k] (i.e. row_j ← row_j XOR row_i). The slide's case table: 何も押さない → 何も押さない; i を押す → i を押す; j を押す → i, j 両方押す; i, j 両方押す → j を押す. Since this maps the 2^N press patterns bijectively onto themselves, 「この操作をして A を変えても、問題の答えは変わりません」. A worked instance with (i, j) = (1, 2) on the slide's 4 × 5 matrix: Switch 1 = 1 0 1 1 0, Switch 2 = 1 0 0 1 1, Switch 3 = 0 1 1 1 0, Switch 4 = 0 0 1 0 1; row 2 becomes 1 0 0 1 1 XOR 1 0 1 1 0 = 0 0 1 0 1.
  - **Step 3 (eliminate — the analogue of row reduction):** Repeat the operation to bring A into an 「解きやすい形」. For k = 1, 2, …, N in order: if there is a row p with A[p][1] = … = A[p][k−1] = 0 and A[p][k] = 1, then for every other row q with A[q][k] = 1 apply the operation with (i, j) = (p, q). The slide states that this is the same thing as 行基本変形 (「これは、行列の『行基本変形』と同様のものになっています」); the footnote defines the three elementary operations as (i) adding a constant multiple of one row to another, (ii) swapping two rows, (iii) multiplying a row by a constant, and notes that in the mod-2 world they are the same idea.
  - **Step 4 (read off the answer greedily):** After a suitable permutation of the rows (「適切に行を並べ替える」) the matrix is upper triangular. Then deciding the switches greedily from the top row downwards answers whether the panels can be made as wished, and if they can, the number of ways is 2^(number of all-zero rows). The slide's trace: target 10110; reduced matrix Switch 1 = 1 0 0 1 1, Switch 3 = 0 1 0 1 1, Switch 2 = 0 0 1 0 1, Switch 4 = 0 0 0 0 0. Press Switch 1 → 10110 XOR 10011 = 00101; Switch 3's pivot column needs 0, so 「そのままにする」 and the target stays 00101; press Switch 2 → 00101 XOR 00101 = 00000 → 「目標達成可能！」; Switch 4's row is entirely zero, so either choice of it works.
- **Complexity:** Not stated on the slides.
- **Author's takeaway / typical pattern (典型):** XOR ⇒ think of F₂ linear algebra: 「XOR の問題は、（有限体 F₂ 上の）掃き出し法で解けることがあります」. 掃き出し法 is first-year university linear algebra, so many people do not know it, but it is worth having as a tool — the slide lists 「逆行列を求める」「連立方程式を解く」「全域木の個数を数える」 as other uses.
- **Related problems (類題):** ZONE エナジー 2021 問題 F 「出会いと別れ」, CodeFlyer 2018 本選 問題 D 「数列 XOR」, ABC 141-F 「Xor Sum 3」.
- **Flags:** (1) The bijection 「2^N 通りのスイッチの押し方が、一対一に変換されている」 is justified only by the 4-case table for a single (i, j); that the operation is an involution on the 2^N patterns — and therefore preserves the *number* of solutions, not merely the size of the set — is asserted, not proved. (2) 「答えが 2^(全部 0 の行の数)」 is stated without the rank–nullity argument: the all-zero rows are the free switches, and the formula only makes sense after the greedy pass has confirmed consistency; the slide never says in so many words that an inconsistent system gives 0. (3) The answer must be printed mod 998244353 (the statement says so), but the slide's formula omits the modulus — with N ≤ 300, 2^300 does not fit in 64 bits. (4) Row swaps change which switch each row represents, yet the reduced matrix is shown with permuted labels (Switch 1, 3, 2, 4): the slide does not say that the permutation must be tracked, or that the chosen rows are the switches to report. (5) The elimination step says 「それ以外で A[q][k] = 1 であるもの全部」 — it must exclude the pivot row p itself, or the pivot is destroyed; the phrase is easy to misread. (6) Boundaries: a column k with no pivot (rank deficient → free row, or inconsistent), N ≠ M (both up to 300), and S = 0…0 (the empty press set always works, so the count is 2^(N−rank) ≥ 1).

## Author's Reference Solution
`057.cpp` — Builds the switch-by-panel matrix, runs Gaussian elimination over GF(2) with row swaps that carry the whole row and the right-hand side, then prints `2^(number of free switches)` mod 998244353 when the reduced right-hand side is all zeros, and `0` otherwise.

```cpp
#include <vector>
#include <iostream>
using namespace std;
int main() {
	cin.tie(0);
	ios_base::sync_with_stdio(false);
	int N, M;
	cin >> N >> M;
	vector<vector<int> > D(N, vector<int>(M, 0));
	for (int i = 0; i < N; ++i) {
		int t, x;
		cin >> t;
		for (int j = 0; j < t; ++j) {
			cin >> x;
			D[i][--x] = 1;
		}
	}
	vector<int> S(M);
	for (int i = 0; i < M; ++i) {
		cin >> S[i];
	}
	int pos = 0;
	for (int i = 0; i < M; ++i) {
		bool found = false;
		for (int j = pos; j < N; ++j) {
			if (D[j][i] == 1) {
				if (j != pos) {
					swap(D[j], D[pos]);
				}
				found = true;
				break;
			}
		}
		if (found) {
			for (int j = 0; j < N; ++j) {
				if (j != pos && D[j][i] == 1) {
					for (int k = i; k < M; ++k) {
						D[j][k] ^= D[pos][k];
					}
				}
			}
			if (S[i] == 1) {
				for (int j = i; j < M; ++j) {
					S[j] ^= D[pos][j];
				}
			}
			++pos;
		}
	}
	if (S == vector<int>(M, 0)) {
		int ans = 1;
		for (int i = pos; i < N; ++i) {
			ans = ans * 2 % 998244353;
		}
		cout << ans << endl;
	}
	else {
		cout << 0 << endl;
	}
	return 0;
}
```
