## Statement (English translation)
There are N mountains made of white stones and blue stones, lined up from left to right. The i-th mountain from the left initially has W[i] white stones and B[i] blue stones.

You and E869120 play the following game using these stone mountains:

> On each turn, choose one mountain and perform exactly one of operations [A] or [B] on it.
>
>     [A] Add w blue stones to the chosen mountain and remove 1 white stone.
>     [B] Choose an integer k with 1 ≤ k ≤ floor(b/2) and remove k blue stones from the chosen mountain.
>
> However, [A] can be performed only when w ≥ 1, and [B] only when b ≥ 2.
> Here w is the number of white stones currently on the chosen mountain and b is the number of blue stones currently on it.

The player who cannot make a move when their turn comes loses. To win, should you choose to go first or second?

## Constraints

```
・0 ≦ W[i] ≦ 50
・0 ≦ B[i] ≦ 50
・(W[i], B[i]) ≠ (0, 0)
・入力はすべて整数
```

## Author's Editorial — Concept & Essence
- **Keyword (キーワード):** Grundy 数を知っていますか？
- **Core idea:** The game is an impartial game on N independent mountains, so by the Sprague–Grundy theorem the position is a losing one for the player to move iff the XOR of the Grundy numbers of all mountains is 0. Each mountain's state is (white, blue), and its Grundy number can be precomputed by mex over all legal moves. Because the constraints on (W[i], B[i]) are tiny (≤ 50), the whole Grundy table can be enumerated directly, after which the answer is a single XOR over the N mountains.
- **Editorial steps:**
  - **Definition of Grundy number:** In general, when the state transitions of a game form a directed acyclic graph (DAG), the Grundy number of each state is defined as follows. Suppose the Grundy numbers of all states reachable in one move from state A (vertex A) have already been computed and are c_1, c_2, …, c_p; then the Grundy number of vertex A is mex({c_1, c_2, …, c_p}). Here mex means the smallest non-negative integer not contained in the set. If the Grundy number is 0 the position is a win for the second player, and if it is 1 or more the first player wins.
  - **Worked example:** Consider a game with N stones where one can take 1–3 stones at a time. The state transitions to consider are as in the figure. It turns out that the Grundy number is 0 exactly when N is a multiple of 4, i.e. when N ≡ 0 (mod 4) the second player wins.
  - **Solution to this problem:** First consider the Grundy number for N = 1. It is good to compute states in increasing order of the number of white stones. Note that the number of blue stones is at most B_i + W_i(W_i+1)/2. When memoizing in an array Grundy[white][blue], the array must have size at least 51 × 1326.
  - Computing mex naively over every state transition costs O(P^5) where P = max(W_i, B_i) = 50; the constant factor is small, so it fits in time. When N ≥ 2, precompute the Grundy numbers and then simply test whether the XOR of grundy[W_i][B_i] over all i is 0.
- **Complexity:** O(N + max(W_i, B_i)^5). The editorial notes the constant factor is light and that C++ runs in about 0.1 s.
- **Author's takeaway / typical pattern (典型):** Using Grundy numbers solves this in O(N + max(W_i, B_i)^5). Grundy numbers are useful not only when "the constraints are small enough to enumerate every state", but also when "the winning-strategy law is unclear, so you want to experiment on small cases."

## Author's Reference Solution
`code/031.cpp` — Precomputes a Grundy table over states (white ≤ 50, blue ≤ ~1500) using mex over the two move types, then XORs grundy[W_i][B_i] over all mountains and prints `First` iff the XOR is non-zero.

```cpp
#include <iostream>
using namespace std;
#pragma warning (disable: 4996)

int N;
int A[1 << 18], B[1 << 18];

int grundy[55][1555];

void init() {
	for (int i = 0; i <= 50; i++) {
		for (int j = 0; j <= 1500; j++) {
			int mex[1555];
			for (int k = 0; k < 1555; k++) mex[k] = 0;
			if (i >= 1) {
				mex[grundy[i - 1][j + i]] = 1;
			}
			if (j >= 2) {
				for (int k = 1; k <= (j / 2); k++) mex[grundy[i][j - k]] = 1;
			}
			for (int k = 0; k < 1555; k++) {
				if (mex[k] == 0) { grundy[i][j] = k; break; }
			}
		}
	}
}

int main() {
	// Step #1. Input
	cin >> N;
	for (int i = 1; i <= N; i++) cin >> A[i];
	for (int i = 1; i <= N; i++) cin >> B[i];

	// Step #2. Initialize
	init();

	// Step #3. Get Answer
	int sum_xor = 0;
	for (int i = 1; i <= N; i++) {
		if (i == N) {
			i += 0;
		}
		sum_xor ^= grundy[A[i]][B[i]];
	}

	// Step #4. Output
	if (sum_xor != 0) cout << "First" << endl;
	if (sum_xor == 0) cout << "Second" << endl;
	return 0;
}
```
