# 066 — Various Arrays (Expected Number of Inversions)

## Statement (original Japanese)
```
数列屋の高橋くんは長さ N の数列 A を作っています。数列 A の i 番目の要素 A[i] の値は、L[i] ≦ A[i] ≦ R[i] を満たす整数から一様ランダムに選ぶことで決定されます。

このようにしてできた数列 A の転倒数の期待値を求めてください。

なお、長さが M である数列 X の「転倒数」とは、i < j かつ X[i] > X[j] であるような (i, j) (1 ≦ i, j ≦ M) の個数を指します。
```

## Statement (English translation)
Takahashi-kun of the Sequence Shop is building a sequence A of length N. The value of the i-th element A[i] of the sequence A is determined by choosing, uniformly at random, an integer satisfying L[i] ≦ A[i] ≦ R[i].

Find the expected value of the inversion number of the sequence A obtained in this way.

Here, the "inversion number" of a sequence X of length M means the number of pairs (i, j) (1 ≦ i, j ≦ M) such that i < j and X[i] > X[j].

## Constraints
```
【制約】
- 1 ≦ N ≦ 100
- 1 ≦ L[i] ≦ R[i] ≦ 100
- 入力は全て整数で与えられる

※絶対誤差または相対誤差 10^{-7} 以下で AC
```

## Author's Editorial — Concept & Essence
- **Keyword (キーワード):** 期待値の線形性 (linearity of expectation)
- **Core idea:** The inversion count is a sum of indicators, one per pair i < j: [A_i > A_j]. The expectation of a sum is the sum of the expectations, with no independence requirement, so the answer is Σ_{i<j} E_{i,j} with E_{i,j} = P(A_i > A_j). Each E_{i,j} is computed by enumerating all |range_i| × |range_j| value pairs, which is cheap because the values are ≤ 100.
- **Editorial steps:**
  - **Step 1 (what linearity of expectation says):** Die 1 shows (12,18,24,30,36,42) with equal probability, die 2 shows (4,18,32,46,60,74) with equal probability; their expectations (average outcomes) are 27 and 39. Enumerating all 6 × 6 = 36 outcome pairs gives E[X+Y] = 66, and indeed (expectation of X) + (expectation of Y) = (expectation of X+Y). This is 期待値の線形性. Generalised to n variables: for random variables X_1, X_2, …, X_n, (expectation of X_1) + … + (expectation of X_n) = (expectation of X_1 + … + X_n), i.e. 「和の期待値は期待値の和」. It holds even when the random variables are not independent (the slide flags this explicitly).
  - **Step 2 (apply to inversion counts):** Let E_{i,j} = P(X_i > X_j). Then the expected contribution of the pair X_i, X_j to the inversion count (its 貢献度の期待値) is exactly E_{i,j}. Hence Answer = (E_{1,2} + E_{1,3} + … + E_{N−1,N}) = Σ_{i=1}^{N} Σ_{j=i+1}^{N} E_{i,j}. The constraints are small, so each E_{i,j} is obtained by brute-force enumeration of all value patterns.
  - **Step 3 (worked example):** N = 3, L = (1,2,1), R = (3,4,2). A_1 > A_2 holds in 1 of the 3 × 3 = 9 patterns, namely (A_1,A_2) = (3,2), so E_{1,2} = 1/9. A_1 > A_3 holds in 3 of the 3 × 2 = 6 patterns, (A_1,A_3) = (2,1),(3,1),(3,2), so E_{1,3} = 3/6. A_2 > A_3 holds in 5 of the 3 × 2 = 6 patterns, (A_2,A_3) = (2,1),(3,1),(3,2),(4,1),(4,2), so E_{2,3} = 5/6. The expected inversion number is 1/9 + 3/6 + 5/6 = 13/9, matching the result of trying all 3 × 3 × 2 = 18 arrays.
- **Complexity:** O(N² · max({L_i, R_i})²) (「全体計算量 O(N^2 · max({L_i,R_i})^2)」): every pair of indices times every pair of values; with N ≤ 100 and values ≤ 100 this is affordable. Memory not stated on the slides.
- **Author's takeaway / typical pattern (典型):** Linearity of expectation is the same technique as 貢献度を考える (account for each pair's contribution separately, ▶典型 039) and is very general, so it is worth internalising. Contrast: 「積の期待値 = 期待値の積」 holds only when the variables are independent (▶典型 052), while linearity needs no independence.
- **Related problems (類題):** ABC154-D 「Dice in Line」, ABC194-D 「Journey」, SoundHound2018-C 「Ordinary Beauty」, ABC008-C 「コイン」, 第6回ドワンゴからの挑戦状-B 「Fusing Slimes」.
- **Flags:** (1) The displayed sum reads 「E_{1,1} + E_{1,2} + E_{1,3} + … + E_{N−1,N}」 — E_{1,1} is a typo for E_{1,2}; the Σ printed beneath it runs over i < j. (2) The third bullet of the worked example prints 「E_{1,2} = 5/6」 where it must be E_{2,3} = 5/6 (the same slide has E_{1,2} = 1/9) — an internal contradiction, so the value 13/9 is right only with the correction. (3) Using E_{i,j} = (#value pairs with k > l)/(|range_i|·|range_j|) implicitly assumes A_i and A_j are independent (true by construction); the slide does not say it. (4) The bound max({L_i,R_i})² measures against the largest coordinate rather than the range widths (the reference uses (maxR − minL)²), so it is loose but safe.

## Author's Reference Solution
- `066a.cpp` — Enumerates every value pair for every index pair and accumulates the probability that the left value exceeds the right one.
- `066b.cpp` — Splits both ranges into segments, counts the ordered and unordered segment pairs, and accumulates the resulting probabilities.

```cpp
// Time Complexity: O(N^2 * (maxR - minL)^2)

#include <vector>
#include <iostream>
using namespace std;
int main() {
	int N;
	cin >> N;
	vector<int> L(N), R(N);
	for (int i = 0; i < N; ++i) {
		cin >> L[i] >> R[i];
	}
	double expsum = 0.0;
	for (int i = 0; i < N; ++i) {
		for (int j = i + 1; j < N; ++j) {
			int cnt = 0, all = 0;
			for (int k = L[i]; k <= R[i]; ++k) {
				for (int l = L[j]; l <= R[j]; ++l) {
					if (k > l) ++cnt;
					++all;
				}
			}
			expsum += double(cnt) / all;
		}
	}
	cout.precision(15);
	cout << fixed << expsum << endl;
	return 0;
}
```

```cpp
// Time Complexity: O(N^2)

#include <vector>
#include <iostream>
#include <algorithm>
using namespace std;
double calc(int la, int ra, int lb, int rb) {
	++ra; ++rb;
	vector<int> sep = { la, ra, lb, rb };
	sort(sep.begin(), sep.end());
	sep.erase(unique(sep.begin(), sep.end()), sep.end());
	long long all = 0, cnt = 0;
	for (int i = 0; i < 3; ++i) {
		for (int j = 0; j < 3; ++j) {
			if (la <= sep[i] && sep[i + 1] <= ra && lb <= sep[j] && sep[j + 1] <= rb) {
				all += 1LL * (sep[i + 1] - sep[i]) * (sep[j + 1] - sep[j]);
				if (i > j) {
					cnt += 1LL * (sep[i + 1] - sep[i]) * (sep[j + 1] - sep[j]);
				}
				else if (i == j) {
					cnt += 1LL * (sep[i + 1] - sep[i]) * (sep[i + 1] - sep[i] - 1) / 2;
				}
			}
		}
	}
	return double(cnt) / all;
}
int main() {
	int N;
	cin >> N;
	vector<int> L(N), R(N);
	for (int i = 0; i < N; ++i) {
		cin >> L[i] >> R[i];
	}
	double expsum = 0.0;
	for (int i = 0; i < N; ++i) {
		for (int j = i + 1; j < N; ++j) {
			expsum += calc(L[i], R[i], L[j], R[j]);
		}
	}
	cout.precision(15);
	cout << fixed << expsum << endl;
	return 0;
}
```
