# 049 — Flip Digits 2 (Buy Interval-Flips that Span All Bit Strings)

## Statement (original Japanese)
```
E869120 君は、長さ N のビット列 S を持っています。最初、S の全ての文字は 0 です。

ABC 商店には M 個のアイテムが売られており、1 から M までの番号がついています。アイテム i の価格は C[i] で、これを使うと、
S の L[i] ~ R[i] 文字目が反転します。すなわち、S の L[i] ~ R[i] 文字目のうち、0 であったものは 1 に、
1 であったものは 0 に変化します。

E869120 君は、M 個のアイテムのいくつかを選んで買うことで、次の条件が満たされるようにしたいです。

・条件 : 長さ N の任意のビット列 T （全部で 2^N 通りあります）に対して、「買ったアイテムから一つを選んで使う」行為を好きな回数（$0$ 回でもよい）することで、S を T に一致させることができる。

条件を満たすために、E869120 君が買う必要のあるアイテムの合計額の最小値を求めてください。

ただし、全てのアイテムを買っても条件を満たせない場合は、その旨を報告してください。

【制約】
・1 ≦ N ≦ 10^5
・1 ≦ M ≦ 10^5
・1 ≦ C[i] ≦ 10^9
・1 ≦ L[i] ≦ R[i] ≦ N
・入力は全て整数
```

## Statement (English translation)
E869120 has a bit string S of length N. Initially, every character of S is 0.

ABC shop sells M items numbered 1 through M. Item i has price C[i], and using it flips characters L[i] through R[i] of S. That is, among the L[i]-th through R[i]-th characters of S, 0 becomes 1 and 1 becomes 0.

E869120 wants to buy some of the M items so that the following condition is satisfied.
- Condition: For every bit string T of length N (there are 2^N of them), by choosing one of the purchased items and using it any number of times (0 times is allowed), S can be made equal to T.

Find the minimum total price of the items E869120 needs to buy. If the condition cannot be satisfied even by buying all items, report that fact.

## Constraints

```
【制約】
・1 ≦ N ≦ 10^5
・1 ≦ M ≦ 10^5
・1 ≦ C[i] ≦ 10^9
・1 ≦ L[i] ≦ R[i] ≦ N
・入力は全て整数
```

## Author's Editorial — Concept & Essence
- **Keyword (キーワード):** 条件の言い換え ／ 最小全域木を求めよう (rephrase the condition / find a minimum spanning tree)
- **Core idea:** Replace S and T by their difference arrays d[i] = "s_i and s_{i+1} differ" for 0 ≤ i ≤ N (with sentinels s_0 = s_{N+1} = "0"). Flipping the interval [l, r] then touches exactly two entries of d — it flips d[l−1] and d[r] simultaneously — which is an *edge* (l−1, r) whose use flips the colours of its two endpoints. So the purchased items form an (N+1)-vertex, M-edge graph; operations only flip colours along edges, hence the parity of the number of white vertices in each connected component is invariant, and 2^N of the 2^{N+1} colourings are reachable iff the graph is connected. The condition therefore becomes "the graph is connected", and the cheapest item set making it connected is a minimum spanning tree.
- **Editorial steps:**
  - **Step 1 (the graph formulation):** 「まず、買ったアイテムが {a[1], a[2], …, a[P]} であるとき、条件を満たす必要十分条件は次の通りになります。」 Consider the N+1 vertices {0, 1, 2, …, N}, where edge i (1 ≤ i ≤ P) directly joins vertex L[a[i]] − 1 and vertex R[a[i]]. 「そこで、グラフが連結であれば条件を満たす」.
  - **Step 2 (why — the difference array):** 「なぜそうなるのでしょうか。まず、0 ≤ i ≤ N に対して「s の i 文字目と i+1 文字目が同じか」を d[i] としましょう。例えば s = "101111" の場合 d = (1,1,1,0,0,0,1) となります。（便宜上 s の 0, N+1 文字目を '0' とします）」 Then: 「そのとき、「l〜r 文字目を反転させる操作」は次のように言い換えられます。● d[l−1] と d[r] を同時に反転させる」 — flipping an interval only changes the two boundary differences.
  - **Step 3 (colouring, parity, and the 2^N count):** Vertices are coloured black/white with d as the colouring, so 「「買ったアイテムを使う操作」は「辺で隣接する頂点の色を同時に反転させる」ことに対応します。さて、「白色頂点の個数の偶奇」は変わらないので、操作によって 2^{N+1} 通り中 2^N 通りの「頂点の色の状態」が実現できれば、すべてのビット列 T に対して S = T にできます」. Connected case: 「グラフが連結の場合、全域木を 1 つ取って葉から順に操作すれば、根以外の頂点の色を自由に決定できるので、2^N 通りの状態に到達できる」 (the figure shows a 5-vertex weighted graph and the spanning tree selected from it). Disconnected case: 「各連結成分について「白色頂点の個数の偶奇」が変わらないので、連結成分数を F とするとき、到達できる状態の数は 2^{N+1−F} 通りです。このような考察により、連結であることが必要十分条件だと分かります」.
  - **Step 4 (Step 2 on the slide — reduce to MST):** 「ここまで長々と証明を書きましたが、結局は緑色部分の考察より、答えは以下の通りであることが分かります。以下の N+1 頂点 M 辺のグラフを考える。● 辺 i は頂点 L[i] − 1 と R[i] を結ぶ、重さ c[i] の辺である。そのとき、このグラフの最小全域木の重さ合計が答えである。」 「なお、最小全域木は Union-Find を用いたクラスカル法によって求められます。紙面の都合上、アルゴリズムの解説は省略しますが、是非調べてください」.
- **Complexity:** O(M log M) via Kruskal — 「クラスカル法により O(M log M) で解くことができました」. Memory: not stated on the slides (Union-Find over N+1 vertices plus the edge list).
- **Author's takeaway / typical pattern (典型):** 「このように、適切に条件を言い換えて最小全域木の問題に帰着でき、クラスカル法により O(M log M) で解くことができました。ステップ 1 は少し難しく思えるかもしれませんが、「条件の言い換え」は ARC/AGC でも使える汎用的なテクニックなので出題されます」. The transferable move is the whole chain: interval flip → two endpoints of a difference array → edge → connectivity → MST.
- **Related problems (類題):** 典型アルゴリズム問題集-F「最小全域木問題」, ARC 029-C「高橋君と国家」(最小全域木), ABC 065-D「Built?」(最小全域木), ARC 119-C「ARC Wrecker 2」(条件の言い換え), AGC 025-B「RGB Coloring」(条件の言い換え), ARC 117-D「Miracle Tree 2」(条件の言い換え)
- **Flags:** (1) **The slide's definition of d contradicts its own example.** The text says d[i] records whether s's i-th and (i+1)-th characters are the same (「同じか」), but s = "101111" with s_0 = s_7 = "0" yields (1,1,1,0,0,0,1) only if d[i] = 1 means they DIFFER, and the key equivalence (flipping [l, r] flips d[l−1] and d[r]) also forces the difference convention. The intended object is the difference (XOR) array; the wording is wrong and any re-derivation must fix it. (2) The step 2^{N+1} → 2^N is asserted with a one-line justification (spanning tree, operate leaf-first) and the disconnected count 2^{N+1−F} is stated without derivation; both need the parity invariant per component plus the leaf-order reachability argument. (3) The slide jumps from "connected ⇔ condition" to "MST weight is the answer" without stating that a spanning tree exists iff the graph is connected, i.e. that "disconnected" is exactly the −1 case; `049.cpp` prints −1 iff Kruskal accepted fewer than N edges. (4) Boundaries the slide never mentions: L = R is allowed and gives the edge (L−1, L) (never a self-loop since L ≤ R); duplicate intervals give parallel edges (Kruskal copes); N = 1 needs the single edge (0,1); and the initial state is d ≡ 0, which is why reaching 2^N states from one specific state suffices. (5) Items may be used any number of times (0 allowed), so only parities matter — used implicitly, never stated.

## Author's Reference Solution
`049.cpp`

```cpp
#include <iostream>
#include <vector>
#include <tuple>
#include <algorithm>
using namespace std;

class UnionFind {
public:
	vector<int> par;

	void init(int sz) {
		par.resize(sz, -1);
	}
	int root(int pos) {
		if (par[pos] == -1) return pos;
		par[pos] = root(par[pos]);
		return par[pos];
	}
	void unite(int u, int v) {
		u = root(u); v = root(v);
		if (u == v) return;
		par[u] = v;
	}
	bool same(int u, int v) {
		if (root(u) == root(v)) return true;
		return false;
	}
};

long long N, M;
long long C[1 << 19], L[1 << 19], R[1 << 19];

int main() {
	// Step #1. 入力
	cin >> N >> M;
	for (int i = 1; i <= M; i++) {
		cin >> C[i] >> L[i] >> R[i];
	}

	// Step #2. ソート
	vector<tuple<long long, int, int>> tup;
	for (int i = 1; i <= M; i++) tup.push_back(make_tuple(C[i], L[i] - 1, R[i]));
	sort(tup.begin(), tup.end());

	// Step #3. 最小全域木を求める
	long long cnt1 = 0, cnt2 = 0;
	UnionFind UF;
	UF.init(N + 2);
	for (int i = 0; i < tup.size(); i++) {
		int u = get<1>(tup[i]);
		int v = get<2>(tup[i]);
		if (UF.same(u, v) == false) {
			UF.unite(u, v);
			cnt1 += get<0>(tup[i]);
			cnt2 += 1;
		}
	}

	// Step #4. 出力
	if (cnt2 != N) cout << "-1" << endl;
	else cout << cnt1 << endl;
	return 0;
}
```
