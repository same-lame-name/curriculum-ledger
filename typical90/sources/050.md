# 050 — Stair Jump (Stair Climbing with 1 or L Steps)

**Difficulty:** ★×3 (author's star rating)
**Link:** https://atcoder.jp/contests/typical90/tasks/typical90_ax
**Source:** AtCoder Typical90 #050 — official statement and samples; editorial essence distilled from the official Japanese slides.

## Statement (original Japanese)
```
E869120 君は、N 段の階段を登ろうとしています。彼は、一歩で 1 段か L 段を登ることができます。
0 段目から出発し、N 段目にたどり着くまでの移動方法が何通りあるかを求め、10^9 + 7 で割った余りを出力してください。

【制約】
・2 ≦ N ≦ 10^5
・2 ≦ L ≦ 10^5
```

## Statement (English translation)
E869120 is trying to climb a staircase with N steps. In one step he can climb 1 step or L steps.
Find the number of ways to get from step 0 to step N, modulo 10^9 + 7.

## Constraints
```
【制約】
・2 ≦ N ≦ 10^5
・2 ≦ L ≦ 10^5
```

## Author's Editorial — Concept & Essence
- **Keyword (キーワード):** 漸化式を立てて DP をしよう (set up a recurrence and do DP)
- **Core idea:** Let dp[i] = the number of ways to reach step i. The last move into step i is either a 1-step (from i−1) or an L-step (from i−L), so dp[i] = dp[i−1] + dp[i−L] once i ≥ L, and dp[i] = dp[i−1] below that because an L-step landing on i < L would have started at a negative step. With dp[0] = 1, one left-to-right pass gives dp[N] mod 10^9+7 in O(N).
- **Editorial steps:**
  - **Step 1 (state and recurrence):** 「まず、「i 段目に到達するまでの移動方法の数」を dp[i] としましょう。そのとき、次の漸化式が成り立ちます。」 dp[i] = 1 (i = 0); dp[i] = dp[i−1] (1 ≤ i < L); dp[i] = dp[i−1] + dp[i−L] (i ≥ L).
  - **Step 2 (implementation):** 「したがって、以下のように実装することで、計算量 O(N) で解けます」 — `dp[0] = 1; for (int i = 1; i <= N; i++) { if (i < L) dp[i] = dp[i-1]; else dp[i] = (dp[i-1] + dp[i-L]) % 1000000007; } cout << dp[N] << endl;`.
  - **Step 3 (concrete trace, N = 10, L = 3):** The staircase figure labels steps 一…十 with their counts 1, 1, 2, 3, 4, 6, 9, 13, 19, 28, drawing the 1-step moves as green arrows and the 3-step moves as orange arrows; i.e. dp[0..10] = 1, 1, 1, 2, 3, 4, 6, 9, 13, 19, 28. Why 28: 「10 段目に行く方法は「9 段目から一歩で 1 段上る」「7 段目から一歩で 3 段上る」の 2 通りありますが、9 段目まで上る方法が 19 通り、7 段目まで上る方法が 9 通りなので、答えは 19 + 9 = 28 通りになります。他の段についても同様に計算できます」.
  - **Step 4 (naming the technique):** 「このように、漸化式を立てて移動方法の総数を計算すると、全体計算量 O(N) でこの問題を解くことができます。なお、今回のように、複数の部分問題に分解して漸化式を立てることで答えを出す手法を、動的計画法（DP）といいます」.
- **Complexity:** O(N) time, as stated. Memory: not stated on the slides (the reference keeps dp[0..N], i.e. O(N); only dp[i−1] and dp[i−L] are ever read, so a rolling window of the last L+1 values would suffice).
- **Author's takeaway / typical pattern (典型):** 「漸化式を立てて DP をしよう」 — decompose the count by the *last* move, write one recurrence, fill it left to right; the cases are indexed by "which step did I jump from", which is the standard stair-climbing / grid-path counting pattern.
- **Related problems (類題):** ABC 129-C「Typical Stairs」, JOI 2007 予選 6「通学経路」, JOI 2011 予選 4「一年生」, EDPC-A「Frog 1」
- **Flags:** (1) The branch dp[i] = dp[i−1] (1 ≤ i < L) is stated with no explanation; what it encodes is that step i < L cannot be the target of an L-jump (the jump would start at i−L < 0), so only the 1-step move lands there. Boundary: L > N — then no L-jump is ever usable and dp[N] = 1 (the reference's `if (i < L)` branch covers every i); also L = 2 with N = 2 gives 2. (2) The modulo 10^9+7 required by the statement appears only inside the code line and never in the recurrence as printed; the recurrence itself is stated over the integers. (3) The justification is by example (N = 10, L = 3): the slide never argues that the two cases (came from i−1 / came from i−L) are disjoint and exhaustive — the trace stands in for the proof. Boundary worth testing: L = 1 is excluded by the constraints, but with L = 1 the two cases would coincide and the recurrence would double count. (4) dp[0] = 1 is the base case encoding "one empty way to stand at step 0", and the numbering of the trace starts at step 一; the slide states dp[0] only in the recurrence, never explains it.

## Author's Reference Solution
`050.cpp`

```cpp
#include <iostream>
using namespace std;

int mod = 1000000007;
int N, L, dp[100009];

int main() {
	// Step #1. 入力
	cin >> N >> L;

	// Step #2. 動的計画法
	dp[0] = 1;
	for (int i = 1; i <= N; i++) {
		if (i < L) dp[i] = dp[i - 1];
		else dp[i] = (dp[i - 1] + dp[i - L]) % mod;
	}

	// Step #3. 出力
	cout << dp[N] << endl;
	return 0;
}
```
