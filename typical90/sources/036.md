# 036 — Max Manhattan Distance (45° Rotation)

**Difficulty:** ★×5 (author's star rating)
**Link:** https://atcoder.jp/contests/typical90/tasks/typical90_aj
**Source:** AtCoder Typical90 #036 — official statement and samples; editorial essence distilled from the official Japanese slides.

## Statement (original Japanese)
二次元座標平面上に相異なる N 個の点 P[1], P[2], ..., P[N] があり、点 P[i] の座標は (x[i], y[i]) です。

以下の Q 個のクエリを順に処理してください。
・i (1 ≦ i ≦ Q) 番目のクエリでは、整数 q[i] が与えられるので、点 P[q[i]] と N 個の点の間のマンハッタン距離の最大値を出力する。
・つまり、点 P[s] と P[t] のマンハッタン距離を dist(P[s], P[t]) とするとき、max⁡(dist(P[q[i]], P[1]), dist(P[q[i]], P[2]), …, dist(P[q[i]], P[N])) の値を出力する。

## Statement (English translation)
There are N distinct points P[1], P[2], ..., P[N] on the two-dimensional coordinate plane, and the coordinates of point P[i] are (x[i], y[i]).

Process the following Q queries in order.
・In the i-th query (1 ≦ i ≦ Q), an integer q[i] is given, so output the maximum value of the Manhattan distance between point P[q[i]] and the N points.
・In other words, letting the Manhattan distance between point P[s] and P[t] be dist(P[s], P[t]), output the value of max⁡(dist(P[q[i]], P[1]), dist(P[q[i]], P[2]), …, dist(P[q[i]], P[N])).

## Constraints
【制約】
・2 ≦ N ≦ 100000
・1 ≦ Q ≦ 100000
・|x[i]|, |y[i]| ≦ 10^9
・(x[i], y[i]) ≠ (x[j], y[j]) [i ≠ j]
・1 ≦ q[i] ≦ N
・q[i] ≠ q[j] (i ≠ j)
・入力はすべて整数

## Author's Editorial — Concept & Essence
- **Keyword (キーワード):** マンハッタン距離は 45 度回転 (a Manhattan distance is a 45-degree rotation).
- **Core idea:** The set of points at Manhattan distance at most K from P(x,y) is a diamond (a square standing on its corner). Mapping every point by X' = x − y, Y' = x + y turns that diamond into an axis-aligned square, and in the new coordinates the Manhattan distance becomes max(|Δx|, |Δy|). Therefore the farthest point from a query point is found from only four values: the minimum and maximum of each rotated coordinate over all points.
- **Editorial steps:**
  - **Step 1 (重要な性質 — the diamond becomes a square):** The region whose Manhattan distance from P(x,y) is at most K is the diamond drawn on the left of the slide. So rotate every point's coordinates by 45 degrees as X' = x − y, Y' = x + y. Then the region whose Manhattan distance from P(X',Y') is at most K is a square (the right figure), which is easier to handle.
  - **Step 2 (解法 — the rotated distance formula):** For two points whose rotated coordinates are (x1,y1) and (x2,y2), the Manhattan distance between them equals max(|x1 − x2|, |y1 − y2|). Consequently, after rotating all points first, either by experimenting with the picture of the square regions or by staring at the rotated distance formula, one notices that the maximum distance from a point (X,Y) is max(|X − x1|, |Y − y1|, …, |X − xN|, |Y − yN|) (X, Y, x_i, y_i here are rotated coordinates). The slide draws the same point set before and after the rotation so the square region is visible.
  - **Step 3 (性質① — four extremes suffice):** Let x_min/x_max be the minimum/maximum of the rotated x over all points and y_min/y_max the minimum/maximum of the rotated y. Then the answer is max(|X − x_min|, |X − x_max|, |Y − y_min|, |Y − y_max|). This holds because the maximum over i of max(a_i, b_i) is the maximum of (max over i of a_i) and (max over i of b_i), so only the extremes of each coordinate are needed. These four values should be computed before answering the queries.
- **Complexity:** O(N + Q) overall — one O(N) pass computes the four extremes and each query is O(1) (「45 度回転を使うと全体計算量 O(N + Q) で問題を解くことができました」). Memory not stated on the slide (the reference code keeps the two coordinate arrays).
- **Author's takeaway / typical pattern (典型):** 45-degree rotation is the standard transformation that turns Manhattan-distance regions into axis-aligned boxes, so that the maximum distance becomes a matter of four extremes. The slide adds, as an unrelated remark, that in problems dealing with Manhattan distance the technique 「x, y を独立に考える」 (treat x and y independently) can also be used.
- **Related problems (類題):** ABC 178-E「Dist Max」, ABC 018-C「菱形カウント」, JOI 2010 本選 4「博展会」.
- **Flags:** (1) The map (x − y, x + y) is a 45-degree rotation composed with a scaling by √2, not a pure rotation; the slide never mentions the factor, so the identity "distance = max(|Δx|, |Δy|)" holds only in these scaled coordinates — the boundary is that a "pure rotation" reading (dividing by √2) would be wrong; the slide's formulas use the scaled coordinates consistently, so the answer is unaffected. (2) The step from max_i max(|X − x_i|, |Y − y_i|) to "the four extremes" is compressed into one line; the subtlety is that x_min, x_max, y_min, y_max may belong to four different points, so they cannot be recombined into a single point — only the maximum can be taken. (3) Overflow: rotated coordinates reach 2 × 10^9 in absolute value and the answer 4 × 10^9 (sample 3), past 32-bit — the slide does not mention 64-bit arithmetic. (4) The statement guarantees the points are distinct, but nothing in the argument uses that.

## Author's Reference Solution
`036.cpp` — Rotates every point by 45 degrees, keeps the minimum and maximum of each rotated coordinate, and answers each query from the four extreme distances.

```cpp
#include <iostream>
#include <cmath>
#include <algorithm>
using namespace std;

long long N, X[1 << 18], Y[1 << 18];
long long Q, T[1 << 18];
long long min_X = (1LL << 60), max_X = -(1LL << 60);
long long min_Y = (1LL << 60), max_Y = -(1LL << 60);

int main() {
	// Step #1. 入力
	cin >> N >> Q;
	for (int i = 1; i <= N; i++) cin >> X[i] >> Y[i];
	for (int i = 1; i <= Q; i++) cin >> T[i];

	// Step #2. 45 度回転
	for (int i = 1; i <= N; i++) {
		long long p1 = X[i] + Y[i];
		long long p2 = Y[i] - X[i];
		X[i] = p1;
		Y[i] = p2;
		min_X = min(min_X, X[i]);
		max_X = max(max_X, X[i]);
		min_Y = min(min_Y, Y[i]);
		max_Y = max(max_Y, Y[i]);
	}

	// Step #3. クエリに答える
	for (int i = 1; i <= Q; i++) {
		long long ret1 = abs(X[T[i]] - min_X);
		long long ret2 = abs(X[T[i]] - max_X);
		long long ret3 = abs(Y[T[i]] - min_Y);
		long long ret4 = abs(Y[T[i]] - max_Y);
		cout << max({ ret1, ret2, ret3, ret4 }) << endl;
	}
	return 0;
}
```
