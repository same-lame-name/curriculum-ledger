# 014 — Matching Children to Schools (Sort and Greedy)

**Difficulty:** ★×3 (author's star rating)
**Link:** https://atcoder.jp/contests/typical90/tasks/typical90_n
**Source:** AtCoder Typical90 #014 — official statement and samples; editorial essence distilled from the official Japanese slides.

## Statement (original Japanese)
AGC 街道には N 人の小学生が住んでおり、小学生 i の家は位置 A[i] にあります。
また、小学校は N 校建てられており、小学校 j は位置 B[j] にあります。

AGC 街道に住む小学生は性格が悪く、どの人同士も険悪な関係になっているため、全員が別の学校に通うようにしたいです。
また、不便さは次のように定義されます。
・小学生 i にとっての家から学校までの距離を E[i] とするとき、不便さは距離の総和、すなわち E[1] + E[2] + ... + E[N] である。
・ただし、位置 u から位置 v までの距離は |u-v|

そこで、どの生徒も別の学校に通うという条件下における、不便さとして考えられる最小値を求めてください。

## Statement (English translation)
On AGC street live N elementary school students; student i's house is at position A[i].
Also, N elementary schools have been built, and school j is at position B[j].

The students on AGC street have bad personalities and every pair of them is on bad terms, so we want every student to attend a different school.
Inconvenience is defined as follows.
・Let E[i] be the distance from student i's house to their school; the inconvenience is the sum of distances, i.e. E[1] + E[2] + ... + E[N].
・Here the distance between position u and position v is |u-v|.

Under the condition that every student attends a different school, find the minimum possible inconvenience.

## Constraints
【制約】
・1 ≦ N ≦ 100000
・0 ≦ A[i] ≦ 10^9
・0 ≦ B[i] ≦ 10^9
・A[1], A[2], ..., A[N] は相異なる
・B[1], B[2], ..., B[N] は相異なる
・入力はすべて整数

## Author's Editorial — Concept & Essence
- **Keyword (キーワード):** ソートして貪欲法 (Sort and greedy)
- **Core idea:** Sort both the students' homes and the schools by position, then match the i-th smallest home with the i-th smallest school. Any crossing pair of matching segments can be uncrossed to reduce (never increase) the total distance, so the sorted matching is optimal. The answer is the sum of absolute differences of the two sorted arrays.
- **Editorial steps:**
  - **解法:** As in the figure, for each i = 1, 2, ..., N, matching the i-th student from the left with the i-th school from the left is necessarily optimal. Therefore, letting (a_1, a_2, ..., a_N) be array A sorted and (b_1, b_2, ..., b_N) be array B sorted, the answer is |a_1 - b_1| + |a_2 - b_2| + ... + |a_N - b_N|. In C++ this can be done with `std::sort`.
  - **証明:** Draw the students' homes as one layer and the schools as one layer. If there is a place where two segments cross, swapping the two destinations reduces the inconvenience (this holds in every case). Hence, letting p_i be the (sorted) index of the school that the i-th student from the left attends (p = (1, 2, ..., N)), there must exist a place where p_i > p_{i+1} causing a crossing. Therefore the sorted matching is optimal.
  - Footnote (青字部分): terms frequently used in contests; look them up if unknown.
- **Complexity:** O(N log N)
- **Author's takeaway / typical pattern (典型):** "Sort and greedy" — sorting first makes an exchange/crossing argument possible, and the matching that preserves order is optimal for minimizing a sum of absolute distances.
- **Related problems (類題):** ABC 091-C「2D Plane 2N Points」, ABC 131-D「Megalomania」, CODE FESTIVAL 2016 Grand Final A「1D Matching」
- **Flags:** The crossing-elimination proof is sketched ("swapping reduces the inconvenience (whatever the case)") rather than proven case-by-case; the four possible relative orders of the two homes and two schools are not enumerated.

## Author's Reference Solution
- **014.cpp** — Sort A and B ascending, then sum |A[i] - B[i]|.

```cpp
#include <iostream>
#include <cmath>
#include <algorithm>
using namespace std;

long long N;
long long A[100009];
long long B[100009];

int main() {
	// Step #1. 入力
	cin >> N;
	for (int i = 1; i <= N; i++) cin >> A[i];
	for (int i = 1; i <= N; i++) cin >> B[i];

	// Step #2. ソート
	sort(A + 1, A + N + 1);
	sort(B + 1, B + N + 1);

	// Step #3. 答えを出力
	long long Answer = 0;
	for (int i = 1; i <= N; i++) Answer += abs(A[i] - B[i]);
	cout << Answer << endl;
	return 0;
}
```
