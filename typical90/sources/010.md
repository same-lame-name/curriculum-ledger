# 010 — Score Sum Queries (Per-Class Prefix Sums)

**Difficulty:** ★×2 (author's star rating)
**Link:** https://atcoder.jp/contests/typical90/tasks/typical90_j
**Source:** AtCoder Typical90 #010 — official statement and samples; editorial essence distilled from the official Japanese slides.

## Statement (original Japanese)
```
ABC 大学には N 人の一年生が在籍しています。
クラスは 2 つあり、学籍番号 i 番の生徒のクラスは C[i] 組です。
今日は期末試験が返却され、学籍番号 i 番の生徒の点数は P[i] 点でした。

以下の形式の質問が Q 個与えられるので、答えてください。
・学籍番号 L[i] ～ R[i] の 1 組生徒における、期末試験点数の合計
・学籍番号 L[i] ～ R[i] の 2 組生徒における、期末試験点数の合計
・これら 2 つをそれぞれ求めよ。
```

## Statement (English translation)
ABC University has N first-year students enrolled.
There are 2 classes, and the class of the student with student ID number i is class C[i].
Today the final exams were returned, and the score of the student with student ID number i was P[i] points.

Q queries of the following form are given, so answer them.
・The sum of the final exam scores of the class-1 students with student ID numbers L[i] to R[i]
・The sum of the final exam scores of the class-2 students with student ID numbers L[i] to R[i]
・Find each of these two

## Constraints
```
【制約】
・1 ≦ N ≦ 10^5
・1 ≦ C[i] ≦ 2
・0 ≦ P[i] ≦ 100
・1 ≦ Q ≦ 10^5
・1 ≦ L[i] ≦ R[i] ≦ N
・入力はすべて整数
```

## Author's Editorial — Concept & Essence
- **Keyword (キーワード):** 区間の総和は累積和 (the sum over an interval is a prefix sum)
- **Core idea:** Precompute a prefix sum per class: S_i = total score of the class-1 students with student number ≤ i (and T_i for class 2). Then the class-1 total over IDs L…R is S_R − S_(L−1) and the class-2 total is T_R − T_(L−1), so each query is O(1) and the whole problem is O(N + Q) after O(N) preprocessing.
- **Editorial steps:**
  - **Step 1 (the naive idea):** for each query, loop x from L[i] to R[i] and add the score when the class is 1. This needs O(NQ) in total and TLEs. The slide's snippet: `int Answer1 = 0, Answer2 = 0; for (int x = L[i]; x <= R[i]; x++) { if (C[i] == 1) Answer1 += A[i]; }`.
  - **Step 2 (prefix sums):** memorize in advance 「1 組生徒のうち、学籍番号 i 番までの合計得点 S_i」 — this is called 累積和 (prefix sums). Then the wanted value 「学籍番号 L 番から R 番までの 1 組生徒の合計得点」 is computed as S_R − S_(L−1). The same is done for class 2 with T_i.
  - **Step 3 (numeric trace, sample 2):** the seven students are 1組 72, 2組 89, 2組 94, 1組 23, 1組 40, 2組 78, 1組 75. The table's 得点 row is 72 89 94 23 40 78 75 and the class-1 prefix sums are S = 0, 72, 72, 72, 95, 135, 135, 210 for indices 0…7 (index 0 is 0). For L = 2, R = 6 the class-1 total is S_6 − S_1 = 135 − 72 = 63, which is indeed the correct answer (23 + 40).
  - **Step 4 (total):** prefix sums for both classes → O(N + Q).
- **Complexity:** O(N + Q) — 「累積和を予めメモしておくことにより全体計算量 O(N+Q) でこの問題を解くことができました」.
- **Author's takeaway / typical pattern (典型):** 累積和 (prefix sums) — 「累積和を予めメモしておく」; the slide notes that prefix-sum problems appear not only in AtCoder Beginner Contest but several times in JOI.
- **Related problems (類題):** JOI 2007 本選1 「最大の和」, JOI 2010 本選1 「旅人」, ABC177-C 「Sum of product of pairs」, ABC182-D 「Wandering」
- **Flags:** (1) The snippet is mis-indexed: it loops over x but tests `C[i]` and adds `A[i]`; the statement names the score array P (the slide calls it A), so the intended body is `if (C[x] == 1) Answer1 += P[x];`, and `Answer2` is declared but never updated. (2) The table's 得点 row lists all seven scores, not only the class-1 ones, so only the S row is the class-1 prefix sum — the table invites the misreading that S sums every score. (3) The L = 1 boundary is never written out; it is covered only implicitly by the index-0 entry S_0 = 0. (4) The slide never shows the class-2 array T_i beyond saying to do the same thing.

## Author's Reference Solution
`010.cpp` — Builds a separate prefix sum for class 1 and for class 2, then answers each query with `Sum[R] - Sum[L-1]` for both classes.

```cpp
#include <iostream>
using namespace std;

// 入力
int N;
int C[100009], P[100009];
int Q;
int L[100009], R[100009];

// 累積和
int Sum1[100009];
int Sum2[100009];

int main() {
	// Step #1. 入力
	cin >> N;
	for (int i = 1; i <= N; i++) cin >> C[i] >> P[i];
	cin >> Q;
	for (int i = 1; i <= Q; i++) cin >> L[i] >> R[i];

	// Step #2. 1 組・2 組それぞれの累積和を取る
	for (int i = 1; i <= N; i++) {
		Sum1[i] = Sum1[i - 1];
		Sum2[i] = Sum2[i - 1];
		if (C[i] == 1) Sum1[i] += P[i];
		if (C[i] == 2) Sum2[i] += P[i];
	}

	// Step #3. クエリに答える
	for (int i = 1; i <= Q; i++) {
		int Answer1 = Sum1[R[i]] - Sum1[L[i] - 1];
		int Answer2 = Sum2[R[i]] - Sum2[L[i] - 1];
		cout << Answer1 << " " << Answer2 << endl;
	}
	return 0;
}
```
