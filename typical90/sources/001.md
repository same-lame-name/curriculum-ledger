```
長さ L [cm] のようかんがあります。
N 個の切れ目が付けられており、左から i 番目の切れ目は左から A[i] [cm] の位置にあります。

```

## Statement (English translation)
There is a bar of youkan (sweet bean jelly) of length L [cm]. N cuts are marked on it, and the i-th cut from the left is at position A[i] [cm] from the left.

You will choose K of the N cuts and divide the youkan into K+1 pieces. The score is defined as follows:
- The length of the shortest of the K+1 pieces.

Find the score obtained when the youkan is divided so that the score is maximized.

## Constraints
```
【制約】
・1 ≦ K ≦ N ≦ 10^5
・0 < A[1] < A[2] < ... < L ≦ 10^9
・入力はすべて整数
```

## Author's Editorial — Concept & Essence
- **Keyword (キーワード):** 答えで二分探索
- **Core idea:** Instead of directly maximizing the shortest piece, ask the yes/no question "can the answer be at least M?". That predicate is monotone in M, so binary search over M finds the largest feasible value. The feasibility check is a left-to-right greedy scan: cut as soon as the current piece reaches length M (and only if the remaining bar can still supply a piece of length M).
- **Editorial steps:**
  - **ステップ 1:** First consider the question "is the answer at least M?" (i.e. "can we divide into K+1 or more pieces each of length at least M?"). Repeatedly halving the range of the answer like this is called 二分探索 (binary search) / 二分法. Since the answer is between 0 and L, it can be found exactly in O(log L) steps. (Example: "is the answer 4 or more? → No, answer is in 0〜3", etc.)
  - **ステップ 2:** To decide "can we divide into K+1 pieces each of length at least M?", greedily cut at the first position where the piece length becomes M or more while scanning from the left (the final interval is the exception). This is O(N). The figure shows the case M = 10. (Footnote: it may cut correctly, but if the final interval has length less than 10 it fails, so the final interval is the exception.)
- **Complexity:** O(N log L)
- **Author's takeaway / typical pattern (典型):** This kind of "binary search on the answer" is a typical idea that reduces the problem to O(N log L). Problems of the form "maximize the minimum" (「最小値の最大化」) can often be solved by binary search on the answer.
- **Related problems (類題):** ABC023-D 射撃王, s8pc #5-B Emblem
- **Flags:** The slide states the greedy and the "final interval exception" but does not spell out why this greedy is optimal. The sample code makes the exception explicit by requiring both `A[i] - pre >= M` and `L - A[i] >= M` (so the suffix is always able to form a piece of length ≥ M).

## Author's Reference Solution
`001.cpp` — Binary search on the answer M (meguru-style: `left = -1`, `right = L+1`). The predicate `solve(M)` scans cuts left to right and counts a cut whenever both the piece since the previous cut and the remaining suffix are at least M; it returns true iff at least K cuts can be made.

```cpp
#include <iostream>
using namespace std;

long long N, K, L;
long long A[1 << 18];

bool solve(long long M) {
    long long cnt = 0, pre = 0;
    for (int i = 1; i <= N; i++) {
        if (A[i] - pre >= M && L - A[i] >= M) {
            cnt += 1;
            pre = A[i];
        }
    }
    if (cnt >= K) return true;
    return false;
}

int main() {
    // Step #1. 入力
    cin >> N >> L;
    cin >> K;
    for (int i = 1; i <= N; i++) {
        cin >> A[i];
    }

    // Step #2. 答えで二分探索（めぐる式二分探索法）
    // https://qiita.com/drken/items/97e37dd6143e33a64c8c
    long long left = -1;
    long long right = L + 1;
    while (right - left > 1) {
        long long mid = left + (right - left) / 2;
        if (solve(mid) == false) right = mid;
        else left = mid;
    }
    cout << left << endl;
    return 0;
}
```
