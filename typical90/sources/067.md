# 067 — Base 8 to 9 (Repeated Base Conversion)

**Difficulty:** ★×2 (author's star rating)
**Link:** https://atcoder.jp/contests/typical90/tasks/typical90_bo
**Source:** AtCoder Typical90 #067 — official statement and samples; editorial essence distilled from the official Japanese slides.

## Statement (original Japanese)
```
黒板に 8 進法の整数 N が書かれています。
あなたは以下の操作を K 回行います。
・黒板の整数を 9 進法に直し、ここに現れる数字「8」を「5」に書き直す（書き直した後の数は 8 進数とみなされる）
操作を K 回行った後にできる数を 8 進法で出力してください。
```

## Statement (English translation)
An integer N written in base 8 is on the blackboard.
You perform the following operation K times.
・Rewrite the integer on the blackboard into base 9, then rewrite every digit "8" appearing there into "5" (the number after rewriting is regarded as a base-8 number).
Output, in base 8, the number that results after performing the operation K times.

## Constraints
```
【制約】
・0 ≦ N < 8^20
・1 ≦ K ≦ 100
・N は 8 進法で表される整数
・入力は全て整数
```

## Author's Editorial — Concept & Essence
- **Keyword (キーワード):** N 進法展開を理解しよう (understand base-N expansion)
- **Core idea:** Converting a base-8 numeral directly into base 9 is hard, so simulate in two steps: base 8 → base 10 → base 9. The first is evaluating Σ S_i · 8^i; the second repeatedly takes N mod 9 as the next digit and replaces N by N ÷ 9. Each operation is O(log N) and is repeated K times; the slide explicitly skips the easy "rewrite digit 8 as 5" part as ABC-B level.
- **Editorial steps:**
  - **Step 1 (base 8 → base 10):** For S = S_{N−1}…S_1 S_0 written in base 8, the value is ans = Σ_{i=0}^{N−1} (S_i · 8^i). Read S as a string and accumulate from the right with a running power x (x ← 8x), as in the slide's `base8_to_long`: `ans += 1LL*(N[i]-'0')*x; x *= 8LL;`. The slide notes that S is at most about 20 digits, which is large, so S itself cannot be received directly in a long long variable.
  - **Step 2 (base 10 → base 9, worked trace):** Convert 2021: 2021 ÷ 9 = 224 remainder 5, so the lowest digit is 5 ("???5"); 224 ÷ 9 = 24 remainder 8, so the second digit is 8 ("??85"); 24 ÷ 9 = 2 remainder 6, so the third digit is 6 ("?685"); 2 ÷ 9 = 0 remainder 2, so the fourth digit is 2 ("2685"). Thus 2021 is 2685 in base 9. In general, repeat "prepend N mod 9 to the string" and "N ← N ÷ 9" until N becomes 0; the green part (268) of the trace is the base-9 expansion of 224. The slide states that a number's base-9 digit count is ⌊log_9 N⌋, hence O(log N) per conversion.
  - **Step 3 (the K repetitions):** Wrap the two conversions in a loop of K iterations; after each base-9 conversion, rewrite every digit '8' as '5' and regard the result as the next base-8 numeral. The slide omits this rewrite from the explanation (「「8」を「5」に直す部分は ABC-B レベルの簡単なので」); the reference code performs it as a character loop.
- **Complexity:** O(K log N) overall (「計算量 O(K log N)」): the base-9 expansion has O(log N) digits and is done K times. Memory not stated on the slides.
- **Author's takeaway / typical pattern (典型):** N 進法展開 (base-N expansion) also underlies bit enumeration (bit 全探索, ▶典型 002) and bit DP (▶典型 045). Beware corner cases such as N = 0 (▶典型 033): forgetting the case distinction makes the base-9 conversion produce an empty string, which goes badly.
- **Related problems (類題):** ABC186-C 「Unlucky 7」, ABC171-C 「One Quadrillion and One Dalmatians」, ABC105-C 「Base -2 Number」.
- **Flags:** (1) The 8→5 rewrite is deliberately not explained; a reader must supply it, and it is also what guarantees that the next base-8 reading only sees digits 0–7 (so `N[i]-'0'` is a valid digit). (2) 「9 進法での桁数は [log_9 N]」 should be ⌊log_9 N⌋ + 1; as written it is off by one. (3) The slide's `long_to_base9` snippet has no N = 0 branch, so it returns the empty string; the reference adds `if (N == 0) return "0";` — N = 0 is explicitly the boundary to test. (4) The slide says S has at most 20 digits but never states that a long long accumulator is safe (N < 8^20 ≈ 1.15×10^18 < 2^63); the extreme allowed input is 77777777777777777777 in base 8.

## Author's Reference Solution
`067.cpp` — Repeats K times: read the current string as a base-8 number, write it in base 9, then replace every digit '8' by '5'.

```cpp
#include <string>
#include <iostream>
using namespace std;
long long base8_to_long(string N) {
	long long res = 0;
	for (int i = 0; i < N.size(); ++i) {
		res = res * 8 + int(N[i] - '0');
	}
	return res;
}
string long_to_base9(long long N) {
	if (N == 0) {
		return "0";
	}
	string res;
	while (N > 0) {
		res = char(N % 9 + '0') + res;
		N /= 9;
	}
	return res;
}
int main() {
	string N; int K;
	cin >> N >> K;
	for (int i = 0; i < K; ++i) {
		N = long_to_base9(base8_to_long(N));
		for (int j = 0; j < N.size(); ++j) {
			if (N[j] == '8') {
				N[j] = '5';
			}
		}
	}
	cout << N << endl;
	return 0;
}
```
