## Statement (English translation)
There is a cake in the shape of a rectangular parallelepiped with width A, depth B, and height C.
You may perform the following operation on the cake:
・Cut it in a direction parallel to some face.
・However, the cake must not be moved (when it is divided into several pieces, they cannot be deformed or cut separately).

(The slide continues: "What is the minimum number of operations needed to make all pieces cubes?")

(Note: the statement text file writes 「ある円に平行な方向に切断する」 — a typo for 「ある面」 ("some face"); the slide reads 「ある面に平行な方向に切る」. The text file also omits the actual question sentence, which appears on the slide.)

## Author's Editorial — Concept & Essence
- **Keyword (キーワード):** 最大公約数はユークリッドの互除法
- **Core idea:** An r×r×r cube can be produced exactly when r divides all of A, B, and C. Larger r means fewer cuts, so the optimal r is gcd(A, B, C). Each axis of length a is split into a/r segments requiring a/r − 1 cuts, so the answer is (A/r − 1) + (B/r − 1) + (C/r − 1). The gcd is computed with the Euclidean algorithm.
- **Editorial steps:**
  - ステップ1: An r×r×r cube can be made iff ① width a is divisible by r, ② depth b is divisible by r, and ③ height c is divisible by r. To minimize the number of cuts, take the largest possible r, which must be r = gcd(a, b, c) (the gcd of the three). Write gcd(x, y) for the gcd of x and y; then gcd(a, b, c) = gcd(a, gcd(b, c)).
  - Example on the slide: for 20, 24, 30, the overall gcd is gcd(20, 6) = 2, and the number of cuts is 9 + 11 + 14 = 34. In general the number of cuts is (a/r − 1) + (b/r − 1) + (c/r − 1).
  - ステップ2: Compute the gcd by the Euclidean algorithm: while neither x nor y is 0, ① if x ≥ y replace x by x mod y; ② if x < y replace y by y mod x. Its complexity is O(log(x + y)). (In C++ one may use `__gcd(x, y)`.)
- **Complexity:** O(log(A + B + C))
- **Author's takeaway / typical pattern (典型):** Computing the gcd lets the whole problem be solved in O(log(A + B + C)); C++'s `__gcd` computes it for you (note: it is unavailable in Visual Studio).

## Author's Reference Solution
`022.cpp` — compute S = gcd(A, gcd(B, C)) with a recursive Euclidean algorithm and print (A/S − 1) + (B/S − 1) + (C/S − 1).

```cpp
#include <iostream>
using namespace std;

long long gcd(long long a, long long b) {
	if (b == 0) return a;
	return gcd(b, a % b);
}

long long A, B, C;

int main() {
	cin >> A >> B >> C;
	long long S = gcd(A, gcd(B, C));
	cout << (A / S - 1LL) + (B / S - 1LL) + (C / S - 1LL) << endl;
	return 0;
}
```
