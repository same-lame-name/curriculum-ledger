# 069 — Colorful Blocks 2 (Counting Colorings of a Row of Blocks)

**Difficulty:** ★×3 (author's star rating)
**Link:** https://atcoder.jp/contests/typical90/tasks/typical90_bq
**Source:** AtCoder Typical90 #069 — official statement and samples; editorial essence distilled from the official Japanese slides.

## Statement (original Japanese)
```
N 個のブロックが横一列に並んでいます。このブロックの列に色を塗ります。以下では左から i 番目のブロックのことをブロック i と呼ぶことにします。

2 つのブロックの列の塗り方が異なるとは、ある 1 以上 N 以下の整数 i が存在して、ブロック i について異なる色で塗られていることと定義します。

次の条件を満たすブロック列の塗り方が何通りあるか求めてください。
・各ブロックを色 1 からブロック K までのいずれか一色で塗る。使わない色があってもよい。
・ブロック i とブロック j について, |i-j|≦2 ならば、ブロック i とブロック j で塗られている色は異なる。
ただし、答えは非常に大きくなる可能性があるので、 10^9+7 で割った余りを出力してください。
```

## Statement (English translation)
N blocks are lined up in a single row. We paint this row of blocks. Below, the i-th block from the left is called block i.

Two colorings of the row of blocks are defined to be different when there exists an integer i with 1 ≦ i ≦ N such that block i is painted in a different color.

Find the number of colorings of the row of blocks satisfying the following conditions.
・Paint each block in exactly one of the colors 1 through K. There may be colors that are not used.
・For blocks i and j, if |i-j| ≦ 2, then the colors painted on block i and block j are different.
However, the answer may become extremely large, so output it modulo 10^9+7.

## Constraints
```
【制約】
・1 ≦ N ≦ 10^{18}
・1 ≦ K ≦ 10^9
・入力は全て整数である。
```

## Author's Editorial — Concept & Essence
- **Keyword (キーワード):** a^b mod m は繰り返し二乗法 (a^b mod m is computed by repeated squaring)
- **Core idea:** Colour the blocks from left to right. Block 1 has K choices, block 2 has K−1, and every later block forbids exactly two colours — those of the two preceding blocks — which are always distinct, so it has K−2 choices. The answer is the closed form K(K−1)(K−2)^{N−2}, evaluated modulo 10^9+7 by binary exponentiation in O(log N).
- **Editorial steps:**
  - **Step 1 (count block by block; A[i] is the colour of block i):** Block 1: no restriction, so K ways. Block 2: only colour A[1] is unavailable, so K−1 ways. Block 3: only colours A[1] and A[2] are unavailable, and A[1] ≠ A[2] always holds, so exactly two distinct colours are excluded and there are K−2 ways. Block 4: only colours A[2], A[3] are unavailable, and A[2] ≠ A[3], so K−2 ways. … Block N: only colours A[N−2], A[N−1] are unavailable, and A[N−2] ≠ A[N−1], so K−2 ways.
  - **Step 2 (multiply the choices):** K × (K−1) × (K−2) × (K−2) × … × (K−2) = K(K−1)(K−2)^{N−2}, where the factor (K−2) occurs N−2 times (the slide's brace spans blocks 3 through N).
  - **Step 3 (repeated squaring for (K−2)^{N−2} mod 10^9+7):** Since N ≤ 10^18, direct multiplication TLEs. Compute the table a^1, a^2, a^4, a^8, a^16, a^32, … (mod m) by squaring each entry; a^b is the product of the entries selected by the binary expansion of b (2 進数, ▶典型 067). Worked example 3^14 mod 100: 3^1 ≡ 3, 3^2 ≡ 3^1 × 3^1 ≡ 3 × 3 ≡ 9, 3^4 ≡ 3^2 × 3^2 ≡ 9 × 9 ≡ 81, 3^8 ≡ 3^4 × 3^4 ≡ 81 × 81 ≡ 61 (all mod 100); because 14 = 2 + 4 + 8, 3^14 ≡ 3^2 × 3^4 × 3^8 ≡ 9 × 81 × 61 = 44469 ≡ 69 (mod 100).
- **Complexity:** O(log N) (「計算量 O(log N)」; the slide also says O(log b) for the exponentiation), comfortably within the limits. Memory not stated on the slides.
- **Author's takeaway / typical pattern (典型):** First do the mathematical case analysis and reduce the problem to as simple a form as possible (a power, a binomial coefficient), then apply repeated squaring; simplifying the problem as far as possible is itself one of the important competitive-programming techniques.
- **Related problems (類題):** ABC178-C 「Ubiquity」, JSC2021-D 「Nowhere P」, ARC116-B 「Products of Min-Max」, AGC017-A 「Biscuits」.
- **Flags:** (1) The closed form is given without its boundary cases: for N = 1 the exponent N−2 = −1 is meaningless, and for K = 1 the factor K−2 = −1 is not a count (reducing it mod p gives the wrong sign); for K = 2, N ≥ 3 the formula correctly yields 0. The reference code therefore special-cases K = 1, N = 1 and N = 2, none of which appears on the slide. (2) The crucial 「絶対に A[i−2] ≠ A[i−1] が成り立つ」 follows from the condition |i−j| ≤ 2, but the slide does not spell out that this is exactly why the two forbidden colours are distinct for every block from 3 onward. (3) The slide writes the modulus only as 10^9+7 in Step 2; with K ≤ 10^9 the factors K and K−1 must be reduced mod p before multiplying (the reference does), which the slide leaves implicit. (4) The corner N = 1 is not tested by the samples: sample 1 has N = 2 and sample 2 has K = 2, N = 10, so a reader following the slide alone would miss that K(K−1)(K−2)^{N−2} cannot be evaluated as written for N = 1.

## Author's Reference Solution
`069.cpp` — Handles K = 1, N = 1 and N = 2 separately, and otherwise prints K·(K−1)·(K−2)^(N−2) modulo 10^9+7.

```cpp
#include <vector>
#include <iostream>
#include <algorithm>
using namespace std;
const int mod = 1000000007;
int binpower(int a, long long b) {
	int ans = 1;
	while (b != 0) {
		if (b % 2 == 1) {
			ans = (long long)(ans)*a % mod;
		}
		a = (long long)(a)*a % mod;
		b /= 2;
	}
	return ans;
}
int main() {
	long long N; int K;
	cin >> N >> K;
	if (K == 1) {
		cout << (N == 1 ? 1 : 0) << endl;
	}
	else if (N == 1) {
		cout << K % mod << endl;
	}
	else if (N == 2) {
		cout << (long long)(K) * (K - 1) % mod << endl;
	}
	else {
		cout << (long long)(K) * (K - 1) % mod * binpower(K - 2, N - 2) % mod << endl;
	}
	return 0;
}
```

> DATA NOTE: the statement reads 「各ブロックを色 1 からブロック K までのいずれか一色で塗る。」 — 「ブロック K」 is plainly a typo for 「色 K」; copied verbatim as-is.
