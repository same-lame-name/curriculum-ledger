# 015 — Counting Subsets with Pairwise Gap at Least k

**Difficulty:** ★×6 (author's star rating)
**Link:** https://atcoder.jp/contests/typical90/tasks/typical90_o
**Source:** AtCoder Typical90 #015 — official statement and samples; editorial essence distilled from the official Japanese slides.

## Statement (original Japanese)
整数 1, 2, 3, ..., N が書かれているボールが 1 個ずつ、合計 N 個あります。
k = 1, 2, 3, ..., N それぞれについて、以下の質問に答えてください。
　・1 個以上のボールを選ぶ方法は 2^N-1 通り存在するが、その中で次の条件を満たす選び方は何通りあるか。
　　□どの選んだ 2 つのボールについても、書かれている整数の差が k 以上となる。
　・ただし、答えは非常に多くなることがあるので、10^9+7 で割った余りを出力すること。

## Statement (English translation)
There are N balls in total, one each labeled with the integers 1, 2, 3, ..., N.
For each k = 1, 2, 3, ..., N, answer the following question.
　・There are 2^N-1 ways to choose one or more balls; among them, how many choices satisfy the following condition?
　　□For every two chosen balls, the difference of the written integers is at least k.
　・However, the answer can become very large, so output it modulo 10^9+7.

## Constraints
【制約】
・1 ≦ N ≦ 100000
・N は整数

## Author's Editorial — Concept & Essence
- **Keyword (キーワード):** 調和級数は O(N log N) (A harmonic series is O(N log N))
- **Core idea:** For a fixed k, the maximum number of balls you can choose is about N/k, so only small "choose counts" a matter for large k. The number of ways to choose a balls whose values differ pairwise by at least k is C(N - (k-1)(a-1), a) (choose a positions, then insert k-1 forbidden balls between consecutive chosen ones). Summing this over a = 1, 2, ..., ≈ N/k costs O(N/k) per k, and the total over all k is a harmonic sum O(N log N).
- **Editorial steps:**
  - **Step 1:** Consider each k = 1, 2, ..., N separately. Looking at the samples, when k is large the number of balls you can choose is small. Example N = 103, k = 37: ① choose 1 ball (10 C_1 = ... ways), ② choose 2 balls (g_2 C_2 ways), ③ choose 3 balls (g_1 C_3 ways). Generalizing, the maximum number of balls chosen is about N/k. Then an important property holds — use the harmonic series: N + N/2 + N/3 + ... + N/N = N(1 + 1/2 + 1/3 + ... + 1/N) = N × O(log N) = O(N log N). Therefore, once the number a of chosen balls is given, the number of ways to choose a balls with pairwise difference ≥ k can be computed in O(1), and the total complexity is O(N log N).
  - **Step 2:** For difference ≥ k, how many ways are there to choose a balls? The conclusion is C(N - (k-1)(a-1), a). In fact this reduces to choosing a balls from N - (k-1)(a-1) balls. Concretely, with (N, k, a) = (9, 3, 3): choosing balls (1, 3, 5) corresponds to, after the chosen ball p, not being able to choose p+1, ..., p+k-1, so we insert a-1 gray balls (that may not be chosen) after the green balls. Example: green balls 1, 5, 9 with gray balls 2,3 / 6,7 inserted → total 9 positions; choosing a = 3 green balls from the 9 - (k-1)(a-1) = 9 - 2·2 = 5 "slots". This covers all choices with difference ≥ k. nCr can be computed fast using modular inverses.
  - Footnote: If you do not know how to compute nCr, read「アルゴリズム・AtCoderのための数学の記事」前編 3-10節 / 3-11節.
- **Complexity:** O(N log N)
- **Author's takeaway / typical pattern (典型):** Using the property of the harmonic series to count. Also, the identity N + N/2 + ... + N/N = O(N log N) is left as an exercise to the reader to prove.
- **Related problems (類題):** ABC134-D「Preparing Boxes」, ARC067-E「Grouping」, ARC068-E「Snuke Line」
- **Flags:** The proof that the harmonic series is O(N log N) is explicitly left as an exercise ("証明は読者の課題としています"). The nCr identity is stated and illustrated by example rather than fully derived.

## Author's Reference Solution
- **015.cpp** — Precomputes factorials and inverse factorials mod 1e9+7 (via Fermat's little theorem), defines `ncr`, and for each k sums `ncr(N-(k-1)*(i-1), i)` for i = 1 .. N/k + 1.

```cpp
#include <iostream>
using namespace std;

long long modpow(long long a, long long b, long long m) {
	// a^b mod m を求める
	long long p = 1, q = a;
	for (int i = 0; i < 30; i++) {
		if ((b & (1LL << i)) != 0) {
			p *= q; p %= m;
		}
		q *= q; q %= m;
	}
	return p;
}

long long Div(long long a, long long b, long long m) {
	// a÷b の mod m での逆元を求める
	return (a * modpow(b, m - 2, m)) % m;
}

// 変数
long long mod = 1000000007;
long long N;
long long fact[200009];
long long factinv[200009];

void init() {
	fact[0] = 1;
	for (int i = 1; i <= 200000; i++) fact[i] = (1LL * i * fact[i - 1]) % mod;
	for (int i = 0; i <= 200000; i++) factinv[i] = Div(1, fact[i], mod);
}

long long ncr(int n, int r) {
	if (n < r || r < 0) return 0;
	return (fact[n] * factinv[r] % mod) * factinv[n - r] % mod;
}

long long query(int K) {
	long long ret = 0;
	// 「N 個中何個選ぶか」を全探索
	// そもそも K が大きいと 1 個か 2 個しか選べないので、そこに着目する
	for (int i = 1; i <= N / K + 1; i++) {
		int s1 = N - (K - 1) * (i - 1);
		int s2 = i;
		ret += ncr(s1, s2);
		ret %= mod;
	}
	return ret;
}

int main() {
	// Step #1. 入力
	cin >> N;

	// Step #2. nCr を求めるために必要な値をメモ（fact / factinv など）
	init();

	// Step #3. 出力
	for (int k = 1; k <= N; k++) {
		long long Answer = query(k);
		cout << Answer << endl;
	}
	return 0;
}
```
