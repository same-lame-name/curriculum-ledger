## Statement (original Japanese)
```
N 個の都市があり、それぞれ 1, 2, 3, ..., N と番号付けられています。
また、N-1 本の道路があり、i 本目の道路は都市 A[i] と都市 B[i] を双方向に結んでいます。
どの都市の間も、いくつかの道路を通って移動可能なものとなっています。

さて、あなたは整数 u, v (1 ≦ u < v ≦ N) を自由に選び、都市 u と v を双方向に結ぶ道路を 1 本だけ新設することができます。
そこで、以下で定められる値をスコアとします。
・同じ道を 2 度通らずにある都市から同じ都市まで戻ってくる経路における、通った道の本数 (この値はただ一つに定まる)
スコアとして考えられる最大の値を出力してください。
```

## Statement (English translation)
There are N cities, numbered 1, 2, 3, ..., N.
There are also N−1 roads, and the i-th road connects city A[i] and city B[i] bidirectionally.
It is possible to travel between any cities by passing through some roads.

Now, you may freely choose integers u, v (1 ≦ u < v ≦ N), and you can construct exactly one new road that connects city u and city v bidirectionally.
Then, let the following value be the score.
・The number of roads passed through on a route that starts from some city and comes back to the same city without passing the same road twice (this value is uniquely determined)
Output the maximum possible score.

## Constraints
```
【制約】
・1 ≦ N ≦ 100000
・1 ≦ A[i] < B[i] ≦ N
・どの都市の間も、いくつかの道路を通って移動可能
・入力はすべて整数
```

## Author's Editorial — Concept & Essence
- **Keyword (キーワード):** 木の直径は最短距離計算を 2 回やる (the tree diameter is obtained by doing the shortest-distance computation twice)
- **Core idea:** The input is a connected graph with N vertices and N−1 edges, i.e. a tree. In a tree the simple path between any two vertices is unique, so adding the single new edge u–v creates exactly one cycle, of length (length of the u→v simple path) + 1. The score is therefore 1 + the maximum simple-path length, which is the tree diameter E (木の直径). E is computed in O(N) by two traversals: BFS/DFS from vertex 1 to find the farthest vertex u, then BFS/DFS from u — the largest distance seen in the second pass is E.
- **Editorial steps:**
  - **Step 1 (reduction to a tree):** The problem reduces to a problem on a connected graph with N vertices and N−1 edges (「この問題は N 頂点 N−1 辺の連結なグラフの問題に帰着できます」). Such a graph is called 木構造 (tree structure) and has special properties, e.g.: (i) the 単純パス (simple path) from vertex u to vertex v exists and is unique; (ii) when one edge joining u and v bidirectionally is added, exactly one 閉路 (cycle) appears, and its length is (length of the simple path u→v) + 1. The figure shows a path of length 3 and, after adding the dashed edge, a cycle of length 4.
  - **Step 2 (the score is the diameter + 1):** By Step 1 the task reduces to finding E = the maximum simple-path length (= maximum shortest distance); E is called the tree diameter (※1: 「この問題で求めるべき答えは E+1 になります」). Naively trying every start vertex and running DFS or BFS to get shortest paths costs O(N²) and TLEs (※2: DFS = depth-first search, BFS = breadth-first search).
  - **Step 3 (O(N) diameter algorithm):** Use the algorithm that finds the tree diameter in O(N): (1) compute the shortest distance from vertex 1 to every vertex; (2) let u be a vertex with the maximum such distance and compute shortest distances from u — the maximum distance that appears then is E. In the figure, pass 1 from vertex 1 gives distances 0,1,2,2 and the green vertex at distance 2 is u; pass 2 from u gives maximum distance 3, so E = 3.
- **Complexity:** O(N) overall (「全体計算量 O(N) で問題を解くことができました」) — two BFS/DFS passes over the tree. Memory not stated on the slide (the reference code keeps adjacency lists and one distance array).
- **Author's takeaway / typical pattern (典型):** Knowing a structural algorithm for trees lets you solve the whole problem in O(N); problems that exploit the special properties of 木構造 are set often, so get used to them (「木構造の特殊な性質を使う問題は他にもたくさん出題されています。慣れていきましょう」).
- **Related problems (類題):** ABC014-D 閉路 (30点解法), ABC019-D 高橋君と木の直径
- **Flags:** The two-pass diameter algorithm is stated as a recipe with no proof — in particular the unproven claim that the vertex farthest from an arbitrary start is an endpoint of some diameter, and that the second pass therefore returns E. The reduction "score = E + 1" is likewise only a footnote; the boundaries to test are u and v already adjacent (the single new edge then runs parallel to an existing edge, so the closed route has length 2 in a multigraph view — the slide assumes one cycle of length ≥ 3) and N = 1 (the statement allows it although u < v cannot be chosen; the reference code prints 0 + 1 = 1).

## Author's Reference Solution
`003.cpp` — Builds the tree, runs BFS from vertex 1 to find the farthest vertex, runs BFS again from that vertex to get the tree diameter, and prints the diameter plus 1.

```cpp
#include <iostream>
#include <vector>
#include <queue>
using namespace std;

// 入力
int N;
int A[1 << 18], B[1 << 18];

// グラフ
const int INF = (1 << 29);
vector<int> G[1 << 18];
int dist[1 << 18];

void getdist(int start) {
	// 幅優先探索（BFS）により、最短距離を計算
	for (int i = 1; i <= N; i++) dist[i] = INF;

	queue<int> Q;
	Q.push(start);
	dist[start] = 0;

	while (!Q.empty()) {
		int pos = Q.front(); Q.pop();
		for (int to : G[pos]) {
			if (dist[to] == INF) {
				dist[to] = dist[pos] + 1;
				Q.push(to);
			}
		}
	}
}

int main() {
	// Step #1. 入力
	cin >> N;
	for (int i = 1; i <= N - 1; i++) {
		cin >> A[i] >> B[i];
		G[A[i]].push_back(B[i]);
		G[B[i]].push_back(A[i]);
	}

	// Step #2. 頂点 1 からの最短距離を求める
	// maxid1: 頂点 1 から最も離れている（最短距離が長い）頂点
	getdist(1);
	int maxn1 = -1, maxid1 = -1;
	for (int i = 1; i <= N; i++) {
		if (maxn1 < dist[i]) {
			maxn1 = dist[i];
			maxid1 = i;
		}
	}

	// Step #3. 頂点 maxid1 からの最短距離を求める
	// maxn2: 木の直径（最短距離の最大値）
	getdist(maxid1);
	int maxn2 = -1;
	for (int i = 1; i <= N; i++) {
		maxn2 = max(maxn2, dist[i]);
	}

	// Step #4. 出力
	cout << maxn2 + 1 << endl;
	return 0;
}
```
