# 028 — Area Covered by Exactly k Rectangles

**Difficulty:** ★×4 (author's star rating)
**Link:** https://atcoder.jp/contests/typical90/tasks/typical90_ab
**Source:** AtCoder Typical90 #028 — official statement and samples; editorial essence distilled from the official Japanese slides.

## Statement (original Japanese)
二次元平面上に N 枚の長方形の紙があります。
全ての紙は辺が x 軸または y 軸に平行になるように配置されており、i 枚目の紙の左下角の座標は (lx[i], ly[i])、右上角の座標は (rx[i], ry[i]) です。

k = 1, 2, 3, ..., N それぞれについて、次の値を求めてください。
・神がちょうど k 枚重なっている部分の面積

## Statement (English translation)
There are N rectangular sheets of paper on a two-dimensional plane.
All sheets are placed so that their sides are parallel to the x-axis or y-axis; the coordinates of the lower-left corner of the i-th sheet are (lx[i], ly[i]), and the coordinates of its upper-right corner are (rx[i], ry[i]).

For each k = 1, 2, 3, ..., N, find the following value:
・The area of the part where exactly k sheets overlap.

(Note: the Japanese text literally says 「神がちょうど k 枚重なっている部分の面積」; 「神」 appears to be a typo for 「紙」 ("sheets"). The intended meaning is "the part where exactly k sheets overlap".)

## Constraints
・1 ≦ N ≦ 10^5
・0 ≦ lx[i] < rx[i] ≦ 1000
・0 ≦ ly[i] < ry[i] ≦ 1000
・入力はすべて整数

## Author's Editorial — Concept & Essence
- **Keyword (キーワード):** 領域加算は二次元いもす法
- **Core idea:** Adding 1 to the whole rectangle [lx, rx) × [ly, ry) can be done in O(1) with a 2D difference array (2D imos): add 1 at the two corners and subtract 1 at the other two. Then take prefix sums horizontally and vertically; each cell then holds the number of sheets covering it. Count cells by coverage to get the area for each k.
- **Editorial steps:**
  - Think of adding 1 to the rectangular region with (lx, rx) on the left and (ly, ry) on the right, and perform the following on the array a[i][j] (the top-left is (i, j), the bottom-right is (i+1, j+1)) which records how many sheets overlap each part:
    - ステップ1: add 1 to a[lx][ly] and a[rx][ry]; subtract 1 from a[lx][ry] and a[rx][ly].
    - Example: for (lx, ly) = (1, 1), (rx, ry) = (3, 4), the array becomes a 1 at (1,1), a −1 at (1,4), a −1 at (4,1), and a 1 at (4,4).
    - ステップ2: next, take the cumulative sum in the horizontal direction.
    - ステップ3: next, take the cumulative sum in the vertical direction.
  - This is surprisingly simple, and it lets us add 1 over a rectangular region. This method is called 2D imos; afterwards, taking the prefix sums and adding up the N rectangles at the "step 1" stage works well.
- **Complexity:** O(N + HW), where H and W are the maximum x- and y-coordinates (here H, W = 1000), so AC is easy with room to spare.
- **Author's takeaway / typical pattern (典型):** The imos method is used very often, both in 1D and 2D. It appears not only at AtCoder but also in JOI, so get used to it.

## Author's Reference Solution
`028.cpp` — 2D imos with the four corner updates, horizontal prefix sums, vertical prefix sums, then `Answer[cnt[i][j]]++` over all cells; output Answer[1..N].

```cpp
#include <iostream>
using namespace std;

// Input
int N;
int lx[1 << 18], ly[1 << 18], rx[1 << 18], ry[1 << 18];

// Count Number
int cnt[1009][1009];
int Answer[1 << 18];

int main() {
	// Step #1. Input
	cin >> N;
	for (int i = 1; i <= N; i++) cin >> lx[i] >> ly[i] >> rx[i] >> ry[i];

	// Step #2. Imos Method in 2D
	for (int i = 1; i <= N; i++) {
		cnt[lx[i]][ly[i]] += 1;
		cnt[lx[i]][ry[i]] -= 1;
		cnt[rx[i]][ly[i]] -= 1;
		cnt[rx[i]][ry[i]] += 1;
	}
	for (int i = 0; i <= 1000; i++) {
		for (int j = 1; j <= 1000; j++) cnt[i][j] += cnt[i][j - 1];
	}
	for (int i = 1; i <= 1000; i++) {
		for (int j = 0; j <= 1000; j++) cnt[i][j] += cnt[i - 1][j];
	}

	// Step #3. Count Number
	for (int i = 0; i <= 1000; i++) {
		for (int j = 0; j <= 1000; j++) {
			if (cnt[i][j] >= 1) Answer[cnt[i][j]] += 1;
		}
	}

	// Step #4. Output The Answer
	for (int i = 1; i <= N; i++) cout << Answer[i] << endl;
	return 0;
}
```
