## Statement (original Japanese)
```
ABC 陸上部には N 人の駅伝選手がいます。
駅伝では 1 人の選手が 1 つの区を担当して走ります。
複数の選手が 1 つの区を担当することや 1 人の選手が複数の区を担当することはできません。
駅伝コースは第 1 区から第 N 区まであり、選手 i が第 j 区を走るのにかかる時間は A[i][j] です。

駅伝は第 1 区、第 2 区、…、第 N 区の順にその区間を担当する選手が走ります。
第 j 区 (1 ≦ j ≦ N-1) を走り終わった選手は第 j+1 区を走る選手にタスキを渡さなければなりません。
このとき、タスキの受け渡しにかかる時間は十分短いため無視できます。最後にタスキを受け取った選手が第 N 区を走りゴールとなります。

さて、ABC 陸上部には M 個の噂があります。i 番目の噂は 「選手 X[i] と Y[i] は仲が悪い」 というものです。
噂をされている選手同士ではタスキの受け渡しができません。つまり、選手 X[i] の直後に選手 Y[i] が走ることも、選手 Y[i] の直後に選手 X[i] が走ることもできません。

ABC 陸上部が駅伝をゴールするのにかかる時間の最小値を求めてください。
ただし、どうやってもゴールできない場合、−1 と出力してください。
```

## Statement (English translation)
The ABC track club has N relay-race runners. In a relay, one runner covers one leg, and no two runners may cover the same leg and no runner may cover more than one leg. The course has legs 1 through N, and the time for runner i to run leg j is A[i][j].

The relay proceeds in order: leg 1, leg 2, …, leg N. A runner who finishes leg j (1 ≤ j ≤ N−1) must hand the sash to the runner of leg j+1. The hand-off time is negligible. The runner who finally receives the sash runs leg N and finishes.

The club has M rumors; the i-th rumor is "runner X[i] and runner Y[i] dislike each other." Runners who are the subject of a rumor cannot hand the sash to each other: runner X[i] cannot run immediately before runner Y[i], nor can runner Y[i] run immediately before runner X[i].

Find the minimum total time for the club to finish the relay. If finishing is impossible no matter what, output −1.

## Constraints
```
・1 ≦ N ≦ 10
・1 ≦ A[i][j] ≦ 1000
・0 ≦ M ≦ N(N-1)/2
・1 ≦ X[i] < Y[i] ≦ N
・(X[i], Y[i]) ≠ (X[j], Y[j]) [i ≠ j]
・入力はすべて整数
```

## Author's Editorial — Concept & Essence
- **Keyword (キーワード):** 小さい制約は順列全探索
- **Core idea:** Since N ≤ 10, the number of possible running orders is only N! (= 3,628,800), so every permutation can be tried. For each permutation, check in O(N) whether it violates any "dislike" adjacency and compute its total time; take the minimum over valid permutations. A precomputed boolean table `kenaku[x][y]` makes the adjacency check O(1).
- **Editorial steps:**
  - The constraint N ≤ 10 is small, so all N! running orders can be brute-forced. Indeed 10! = 3628800, and considering that a computer performs roughly 10^8–10^9 operations per second, this is sufficiently small.
  - How should one judge whether an order P_1 → P_2 → … → P_N is valid? Pre-record in a boolean array `kenaku[x][y]` whether runners x and y dislike each other, then the check is O(N).
  - Therefore the total complexity is O(N! × N).
  - In C++, `next_permutation` makes this easy to implement. In Python and other languages it can be implemented with recursion, for example.
  - **Reader's exercise (読者への課題):** Think of an algorithm that solves N ≤ 18 as well.
- **Complexity:** O(N! × N)
- **Author's takeaway / typical pattern (典型):** By using permutation brute force, the problem can be solved in O(N! × N). When the constraint is very small such as N ≤ 8, permutation brute force is often the intended solution, so it is important to predict the solution from the constraints. Also, C++'s `next_permutation` function appears frequently, so learn it on this occasion.

## Author's Reference Solution
`code/032.cpp` — Builds the identity permutation, marks disliked pairs, then iterates over all permutations with `next_permutation`, rejecting orders with a disliked adjacent pair and minimizing the total A[order[i]][i+1]; prints −1 if no valid order exists.

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

// Input
int N, M;
int A[12][12];
int X[1 << 18], Y[1 << 18];

// Other Variables
bool kenaku[12][12];
int Answer = (1 << 30);

int main() {
	// Step #1. Input
	cin >> N;
	for (int i = 1; i <= N; i++) {
		for (int j = 1; j <= N; j++) cin >> A[i][j];
	}
	cin >> M;
	for (int i = 1; i <= M; i++) cin >> X[i] >> Y[i];

	// Step #2. Init
	vector<int> vec;
	for (int i = 1; i <= N; i++) vec.push_back(i);
	for (int i = 1; i <= M; i++) {
		kenaku[X[i]][Y[i]] = true;
		kenaku[Y[i]][X[i]] = true;
	}

	// Step #3. Brute Force
	do {
		bool flag = true;
		int sum = 0;
		for (int i = 0; i < N - 1; i++) {
			if (kenaku[vec[i]][vec[i + 1]] == true) flag = false;
		}
		for (int i = 0; i < N; i++) sum += A[vec[i]][i + 1];
		if (flag == true) Answer = min(Answer, sum);

	} while (next_permutation(vec.begin(), vec.end()));

	// Step #4. Output The Answer
	if (Answer == (1 << 30)) Answer = -1;
	cout << Answer << endl;
	return 0;
}
```
