# 080 — Let's Share Bit (Counting Values with Non-Zero AND)

**Difficulty:** ★×6 (author's star rating)
**Link:** https://atcoder.jp/contests/typical90/tasks/typical90_cb
**Source:** AtCoder Typical90 #080 — official statement and samples; editorial essence distilled from the official Japanese slides.

## Statement (original Japanese)
```
N 個の非負整数 A[1], A[2], ..., A[N] があります。
0 以上 2^D 未満の整数 x のうち、i = 1, 2, ..., N すべてについて次の条件を満たすようなものはいくつあるか、求めてください。

・A[i] と x とのビットごとの論理積（ビット単位 AND）は 0 でない。
```

## Statement (English translation)
There are N non-negative integers A[1], A[2], ..., A[N].
Among the integers x with 0 ≦ x < 2^D, find how many satisfy the following condition for every i = 1, 2, ..., N.

・The bitwise logical product (bitwise AND) of A[i] and x is not 0.

## Constraints
```
【制約】
・1 ≦ N ≦ 20
・0 ≦ D ≦ 60
・0 ≦ A[i] < 2^D
・入力はすべて整数
```

## Author's Editorial — Concept & Essence
- **Keyword (キーワード):** 包除原理の活用 (using the principle of inclusion–exclusion)
- **Core idea:** Counting the x that satisfy all N conditions (`A[i] and x ≠ 0`) directly is hard, but counting those that satisfy **none** of them is easy: if every `A[i] and x = 0`, then x may have a 1 only in bit positions where *all* the `A[i]` are 0, so there are `2^E` such x, where E is the number of all-zero positions among the D bits. So count the complement and apply inclusion–exclusion over the N conditions: `Answer = Σ_{D ⊆ {1,…,N}} (−1)^{|D|} f(D)`, where `f(D)` = number of x satisfying none of the conditions in D. Since `N ≦ 20`, enumerate all `2^N` subsets by bit brute force.
- **Editorial steps:**
  - **Step 1 (why count the complement):** 「この問題では、直接「条件 1 / 条件 2 / … / 条件 N すべてを満たす場合の数」を高速に求めるのは難しいです。一方、以下の値を求めるのは簡単です」 — the blue box asks: 「条件 1 / 条件 2 / … / 条件 N いずれも満たさない x は何個か？ つまり 1 ≦ i ≦ N 全てについて A[i] and x = 0 となるのは何通り？」
  - **Step 2 (turn the bit condition into a counting formula):** 「A[i] and x = 0」 is rephrased as 「x について、A[i] を 2 進数で表したとき 1 となる桁はすべて 0 である」. The slide's illustration: `A[1] = 100110`, `X = 0??00?`, and `A[1] and X = 000000`. Therefore, for all N conditions to fail, x may set 1 only in the digits where every `A[1], …, A[N]` is 0; with E the number of such digits, the number of x is `2^E`.
  - **Step 3 (numeric example):** for `D = 6, N = 2, A = (6, 19)`, i.e. `A[1] = 000110` and `A[2] = 010011`, the only freely choosable bits are the 4th and 6th from the bottom (bits 3 and 5), so the count is `2^2 = 4`.
  - **Step 4 (inclusion–exclusion over the N conditions):** `N = 1`: `2^D −` (number of x failing condition 1). `N = 2`: `2^D −` (fails 1) `−` (fails 2) `+` (fails 1 and 2) — 「ベン図を書くと理解しやすいと思います」. `N = 3`, with `f(D)` = 「集合 D に含まれる条件をいずれも満たさないような x の個数」: `2^D − f({1}) − f({2}) + f({1,2}) − f({3}) + f({1,3}) + f({2,3}) − f({1,2,3})`. For `N ≧ 4` the same reasoning gives: consider every subset D of `{1, 2, 3, …, N}`; if `|D|` is odd, subtract `f(D)` from Answer, if even, add `f(D)` — 「このようなものを包除原理といいます」 (`f(∅) = 2^D` is the even, added term).
  - **Step 5 (implementation and its cost):** this is implementable with bit brute force (bit 全探索). A naive implementation costs `O(2^N · N · D)` and may TLE, so bit operations (computing the OR of a subset in machine words) are used to speed it up to `O(2^N (N + D))`.
- **Complexity:** `O(2^N (N + D))` (right column: 「全体計算量 O(2^N (N + D)) で本問題を解くことができました」). Memory `O(2^N)` if the subset ORs are precomputed (as in `080b.cpp`); the slide does not state memory.
- **Author's takeaway / typical pattern (典型):** inclusion–exclusion is the tool for cases where 「全条件を満たす個数は難しいが、全条件を満たさない個数は簡単」. The slide used bit brute force here, but the technique is often combined with DP — 包除 DP.
- **Related problems (類題):** yukicoder No.894「二種類のバス」, ABC178-C「Ubiquity」, ABC152-F「Tree and Constraints」, EDPC-Y「Grid 2」, ABC020-D「LCM Rush」
- **Flags:** (1) The slide only writes the single-condition count `2^E`; to apply the subset rule one needs `f(D) = 2^(number of positions where the OR of A[i] over i ∈ D is 0)`, which the slide never states — the same argument applied to the OR, but a reader must supply it. (2) Inclusion–exclusion is named and illustrated for `N = 1, 2, 3` and then generalized in one sentence; the alternating-sum identity is asserted, never proved. (3) The `O(2^N (N + D))` bound silently assumes the D-bit masks fit in one machine word (D ≤ 64; here D ≤ 60), which the slide does not say — for arbitrary D the argument would not hold. (4) The answer is at most `2^D ≦ 2^60`, so it fits in a signed 64-bit integer; the slide does not mention this, yet the reference code relies on it (`1LL << free_digits`). (5) Boundaries to test: `D = 0` (only `x = 0` is allowed and no `A[i] and x ≠ 0` can hold, so the answer is 0), `A[i] = 0` for some i (that condition can never be satisfied, answer 0), `N = 1` (`2^D − 2^(number of zero bits)`), and all `A[i] = 2^D − 1` (answer `2^D − 1`). (6) The bit illustration `A[1] = 100110`, `X = 0??00?` is a different instance from the numeric example `A = (6,19)` where `A[1] = 000110`; both are internally consistent, but they are not the same instance.

## Author's Reference Solution
- `080a.cpp` — Enumerates all subsets of the A[i], ORs them together, and adds or subtracts 2 raised to the number of zero bits by inclusion–exclusion.
- `080b.cpp` — Performs the same inclusion–exclusion but precomputes the subset popcount and the OR of every subset.

```cpp
#include <vector>
#include <iostream>
using namespace std;
int main() {
	int N, D;
	cin >> N >> D;
	vector<long long> A(N);
	for (int i = 0; i < N; ++i) {
		cin >> A[i];
	}
	long long answer = 0;
	for (int i = 0; i < (1 << N); ++i) {
		long long bit = 0;
		int conditions = 0;
		for (int j = 0; j < N; ++j) {
			if ((i >> j) & 1) {
				bit |= A[j];
				++conditions;
			}
		}
		int free_digits = 0;
		for (int j = 0; j < D; ++j) {
			if (((bit >> j) & 1) == 0) {
				++free_digits;
			}
		}
		if (conditions % 2 == 0) {
			answer += (1LL << free_digits);
		}
		else {
			answer -= (1LL << free_digits);
		}
	}
	cout << answer << endl;
	return 0;
}
```

```cpp
#include <vector>
#include <iostream>
using namespace std;
int main() {
	int N, D;
	cin >> N >> D;
	vector<long long> A(N);
	for (int i = 0; i < N; ++i) {
		cin >> A[i];
	}
	vector<int> pop(1 << N);
	vector<long long> bit(1 << N);
	for (int i = 1; i < (1 << N); ++i) {
		pop[i] = pop[i >> 1] + (i & 1);
	}
	for (int i = 0; i < N; ++i) {
		for (int j = 0; j < (1 << i); ++j) {
			bit[j + (1 << i)] = bit[j] | A[i];
		}
	}
	long long answer = 0;
	for (int i = 0; i < (1 << N); ++i) {
		int free_digits = D - __builtin_popcountll(bit[i]);
		if (pop[i] % 2 == 0) {
			answer += (1LL << free_digits);
		}
		else {
			answer -= (1LL << free_digits);
		}
	}
	cout << answer << endl;
	return 0;
}
```
