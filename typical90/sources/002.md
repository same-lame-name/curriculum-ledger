# 002 — Enumerate All Valid Bracket Sequences

**Difficulty:** ★×3 (author's star rating)

**Source:** AtCoder Typical90 #002 — official statement and samples; editorial essence distilled from the official Japanese slides.

## Statement (original Japanese)
```
長さ N の正しいカッコ列をすべて、辞書順に出力してください。
ただし、正しいカッコ列とは以下のことを指すものとします。
・"()" は正しいカッコ列である
・S が正しいカッコ列であるとき、文字列 "(" + S + ")" は正しいカッコ列である
・S, T が正しいカッコ列であるとき、文字列 S+T は正しいカッコ列である
また、')' より '(' の方が辞書順で早いものとする。
```

## Statement (English translation)
Output all valid bracket sequences of length N, in lexicographic order.
Here, a valid bracket sequence is defined as follows:
- "()" is a valid bracket sequence.
- If S is a valid bracket sequence, then the string "(" + S + ")" is a valid bracket sequence.
- If S and T are valid bracket sequences, then the string S+T is a valid bracket sequence.
Also, '(' comes earlier than ')' in lexicographic order.

## Constraints
```
【制約】
・1 ≦ N ≦ 20
・N は整数
```

## Author's Editorial — Concept & Essence
- **Keyword (キーワード):** 小さい制約は全探索を考えよう
- **Core idea:** A valid bracket sequence is just a string of '(' and ')' of length N, so there are only 2^N candidates; N ≤ 20 makes exhaustive enumeration feasible. Enumerate the 2^N bit patterns, map each bit to a bracket, then test validity by the two classic conditions (equal counts, and every prefix has at least as many '(' as ')').
- **Editorial steps:**
  - **ステップ 1:** Clearly, valid bracket sequences consist of the two characters '(' and ')'. Therefore for length N there are 2^N candidate sequences to check. Rather than writing N nested `for` loops, use the technique of **bit 全探索 (bit brute force)**: loop `i = 0, 1, ..., 2^N − 1`; if the j-th bit (counting from the top) of the binary representation of `i` is 0, the j-th character is '(', and if it is 1, the j-th character is ')'. (Table for N = 3 is shown.)
  - **ステップ 2:** How to judge whether a bracket sequence is valid? This is classic knowledge: the following two conditions together are necessary and sufficient: (1) the numbers of '(' and ')' are equal; (2) for every i (1 ≤ i ≤ N), at the point of the i-th character from the left, the number of '(' is at least the number of ')'. This can be computed by accumulating (number of '(' − number of ')') as a graph, in O(N).
- **Complexity:** O(2^N × N)
- **Author's takeaway / typical pattern (典型):** By bit brute force the problem can be solved in O(2^N × N). Under the constraint N ≤ 20, besides exhaustive search one may also use bit DP. The condition for a valid bracket sequence appears often in competitive programming, so it is good to know it.
- **Related problems (類題):** ABC190-C Bowls and Dishes, ABC197-C ORXOR, ABC064-D Insertion (カッコ列)
- **Flags:** none

## Author's Reference Solution
`002.cpp` — Enumerate all `i` from 0 to 2^N−1. Reading the bits of `i` from the top, a 0-bit emits '(' and a 1-bit emits ')'; since '(' < ')', this yields dictionary order. `hantei` checks validity by tracking the running depth and requiring it never goes negative and ends at 0.

```cpp
#include <iostream>
#include <string>
using namespace std;

bool hantei(string S) {
	int dep = 0;
	for (int i = 0; i < S.size(); i++) {
		if (S[i] == '(') dep += 1;
		if (S[i] == ')') dep -= 1;
		if (dep < 0) return false;
	}
	if (dep == 0) return true;
	return false;
}

int main() {
	int N;
	cin >> N;
	for (int i = 0; i < (1 << N); i++) {
		string Candidate = "";
		for (int j = N - 1; j >= 0; j--) {
			// メモ : (i & (1 << j)) = 0 というのは、i の j ビット目（2^j の位）が 0 であるための条件。
			// 　　　頻出なので知っておくようにしましょう。
			if ((i & (1 << j)) == 0) {
				Candidate += "(";
			}
			else {
				Candidate += ")";
			}
		}
		bool I = hantei(Candidate);
		if (I == true) cout << Candidate << endl;
	}
	return 0;
}
```
