# 081 — Maximum Team Size with Height/Weight Spread ≤ K

**Difficulty:** ★×5 (author's star rating)
**Link:** https://atcoder.jp/contests/typical90/tasks/typical90_cc
**Source:** AtCoder Typical90 #081 — official statement and samples; editorial essence distilled from the official Japanese slides.

## Statement (original Japanese)
典型高校には N 人の生徒がおり、各生徒には 1 から N までの番号が付けられています。生徒 i の身長は A[i]、体重は B[i] です。

N 人の生徒から 1 人以上を選び、次の条件をすべて満たすようにチームを作ります。

・チーム内のどの 2 人も、身長の差の絶対値が K 以下である
・チーム内のどの 2 人も、体重の差の絶対値が K 以下である

チームの人数としてありうる最大の値を求めてください。

## Statement (English translation)
Typical High School has N students, each numbered 1 through N. Student i has height A[i] and weight B[i].

We form a team by choosing one or more of the N students so that all of the following conditions hold:

- For any two members of the team, the absolute difference of their heights is at most K.
- For any two members of the team, the absolute difference of their weights is at most K.

Find the maximum possible number of team members.

## Constraints
・1 ≦ N ≦ 2 × 10^5
・1 ≦ K ≦ 5000
・1 ≦ A[i], B[i] ≦ 5000
・入力はすべて整数

## Author's Editorial — Concept & Essence
- **Keyword (キーワード):** データを二次元にプロット／二次元累積和 (Plot data in 2D / 2D prefix sums)
- **Core idea:** Instead of attacking the condition directly, plot each student as a point (A[i], B[i]) on a 2D grid. Any valid team is exactly the set of students inside an axis-aligned K×K square, so the answer is the maximum number of points in any such square. A 2D prefix sum lets each square be counted in O(1), and all squares are enumerated over the bounded value range.
- **Editorial steps:**
  - 解法: そのままの形で解くのは難しいので、生徒の情報を二次元座標または二次元のマス目にプロットしてみましょう。
  - チーム中の最小の身長を a、最小の体重を b とします。そのとき、チームに含まれる全ての生徒は「身長が a 以上 a+K 以下である」「体重が b 以上 b+K 以下である」を満たさなければなりません。
  - 当然、条件を満たす全ての生徒を選ぶのが最適なので、選べる人数は a ≦ A[i] ≦ a+K かつ b ≦ B[i] ≦ b+K となる i の個数、つまり長方形領域の総和となります（(a,b) = (2,2,2) の例）。
  - この総和は二次元累積和を使うと O(1) で計算できます。マス (a,b) の値が「身長 a 以下かつ体重 b 以下の生徒の人数」となります。
  - 長方形領域の総和は包除原理 (典型080) 的に、P[rx][ry] − P[lx][ry] − P[rx][ly] + P[lx][ly] で求まります。
  - 最後に 1 ≦ a, b ≦ 5000 の範囲で (a,b) を全探索すれば、最終的な答えを出すことができます。
- **Complexity:** O(N + maxA · maxB)
- **Author's takeaway / typical pattern (典型):** 二次元累積和を使うことで本問題を計算量 O(N + maxA·maxB) で解くことができます。累積和 (典型010)、imos 法 (典型028) は過去に出題されましたが、これらは二次元や三次元にも拡張できます。また、データを二次元にプロットして考えるテクニックも典型です。これは典型017のようなデータ構造を扱う問題や、たくさんのクエリを処理する問題でも有効です。

## Author's Reference Solution
`081.cpp` — Builds a 2D prefix-sum grid over (height, weight), then slides a (K+1)×(K+1) square across the value range and takes the maximum count.

```cpp
#include <vector>
#include <iostream>
#include <algorithm>
using namespace std;
int main() {
	int N, K;
	cin >> N >> K;
	vector<int> A(N), B(N);
	for (int i = 0; i < N; ++i) {
		cin >> A[i] >> B[i];
	}
	int R = max(*max_element(A.begin(), A.end()), K) + 1;
	int C = max(*max_element(B.begin(), B.end()), K) + 1;
	vector<vector<int> > sum(R + 1, vector<int>(C + 1));
	for (int i = 0; i < N; ++i) {
		++sum[A[i] + 1][B[i] + 1];
	}
	for (int i = 1; i <= R; ++i) {
		for (int j = 1; j <= C; ++j) {
			sum[i][j] += sum[i - 1][j];
		}
	}
	for (int i = 1; i <= R; ++i) {
		for (int j = 1; j <= C; ++j) {
			sum[i][j] += sum[i][j - 1];
		}
	}
	int answer = 0;
	for (int i = 0; i <= R - K - 1; ++i) {
		for (int j = 0; j <= C - K - 1; ++j) {
			answer = max(answer, sum[i][j] + sum[i + K + 1][j + K + 1] - sum[i][j + K + 1] - sum[i + K + 1][j]);
		}
	}
	cout << answer << endl;
	return 0;
}
```
