# 041 — Enclose All Points (Convex Hull + Pick's Theorem)

**Difficulty:** ★×7 (author's star rating)
**Link:** https://atcoder.jp/contests/typical90/tasks/typical90_ao
**Source:** AtCoder Typical90 #041 — official statement and samples; editorial essence distilled from the official Japanese slides.

## Statement (original Japanese)
AtCoder 農園には N 個の杭があり、i 個目の杭は座標 (X[i], Y[i]) に打たれています。

あなたはすべての杭を囲む塀を作り、塀の周上または内側にある全ての格子点に杭を打ちたいと思っています。長い塀を作るのは疲れるので、すべての杭を囲むような塀のうち最も周の長さが短いものを作ります。

あなたが新しく打つ必要がある杭の本数を求めてください。
ただし、杭の大きさや塀の厚さは無視できるものとします。

## Statement (English translation)
There are N stakes in the AtCoder farm, and the i-th stake is driven at coordinates (X[i], Y[i]).

You will build a fence enclosing all the stakes, and you want to drive a stake at every lattice point on or inside the fence. Since building a long fence is tiring, among the fences that enclose all the stakes you build the one with the shortest perimeter.

Find the number of stakes you must newly drive.
However, the size of the stakes and the thickness of the fence may be ignored.

## Constraints
【制約】
・3 ≦ N ≦ 10^5
・0 ≦ X[i], Y[i] ≦ 10^9
・(X[i], Y[i]) ≠ (X[j], Y[j]) [i ≠ j]
・入力はすべて整数


【小課題】
1. (2 点) N = 3, X[i] ≦ 1000, Y[i] ≦ 1000
2. (2 点) X[i] ≦ 1000, Y[i] ≦ 1000
3. (3 点) 追加の制約はない

## Author's Editorial — Concept & Essence
- **Keyword (キーワード):**
  - P1: 「凸包を求めるアルゴリズムを理解しよう」(Understand the algorithm that finds the convex hull)
  - P2: 「x ÷ y の切り上げは ⌈(x + y − 1) ÷ y⌉」(The ceiling of x ÷ y is ⌈(x + y − 1) ÷ y⌉)
  - P3: 「ピックの定理による数え上げ」(Counting via Pick's theorem)
- **Core idea:** The shortest fence enclosing all points is exactly the convex hull. The points to be counted are the lattice points inside/on this convex hull; since the N existing stakes are already among them, the answer is (#lattice points in hull) − N. Compute the convex hull in O(N log N) with a monotone-chain stack, then count interior lattice points either by an x-sweep over the hull's lower/upper chains (subtask 2, using ceiling/floor of the line's y at each integer x) or, for the full constraints, by Pick's theorem: S = i + b/2 − 1, where S is the polygon area (shoelace) and b is the number of lattice points on the boundary (Σ gcd(|Δx|,|Δy|)).
- **Editorial steps:**
  - **P1 (凸包):** The wall enclosing the farm is the convex hull of the N points. Compute it in O(N log N):
    1. Prepare a stack s.
    2. Process the points sorted in ascending x. Let the top two points of s be P1, P2 and the current point be P3; if P1P2P3 is not clockwise (時計回りでない), pop from s. Repeat this; the same operation done in reverse (mirror) yields the lower hull.
    - Whether P1→P2→P3 is clockwise is decided in O(1) by the sign of the cross product of P1P2 and P2P3.
    - This alone does not yet solve subtask 2; the next page explains the computation after the hull is found.
  - **P2 (subtask 2):** Because the constraint is 0 ≤ x_i ≤ 1000, we can compute l_i and r_i for every i ≤ 1000 and thereby count lattice points inside the hull:
    - l_i := among lattice points inside the hull with x-coordinate i, the one with the smallest y; r_i := the one with the largest y. (Slide text labels both as 最小, but r_i must be the maximum.)
    - Example: (l_1,…,l_7) = (3,1,2,2,3,3,3), (r_1,…,r_7) = (3,3,4,4,4,5,3).
    - For a segment (xa,ya)–(xb,yb) with xa < xb, its y at x = i is (ya(bx−i) + yb(i−xa)) / (xb−xa). Since l_i is the ceiling: l_i = ⌈(ya(bx−i)+yb(i−xa))/(xb−xa)⌉ = ⌊(ya(bx−i)+yb(i−xa)+(xb−xa)−1)/(xb−xa)⌋.
    - Do this for i = xa, xa+1, …, xb for every segment of the lower hull. The upper hull is computed the same way, but r_i is floored (切り捨て), not ceiled.
    - Beware of a segment with xa = xb (parallel to the y-axis): division by 0 causes RE (runtime error).
    - Complexity: O(N log N + max(x_1,…,x_N)).
  - **P3 (subtask 3, full):** Pick's theorem: for a polygon with area S, b lattice points on the boundary, and i lattice points in the interior, S = i + b/2 − 1.
    - Example in the slide: S = 14, b = 6, i = 12.
    - Area: S = (1/2)|Σ_{i=1}^{N} (x_i − x_{i+1})(y_i + y_{i+1})|, with (x_{N+1}, y_{N+1}) = (x_1, y_1). (See AtCoder「アルゴリズムのための数学」2-9 節 for the Σ notation.)
    - Number of lattice points on a segment (ax,ay)–(bx,by) is gcd(|xb−xa|, |yb−ya|) + 1 (including endpoints). E.g. segment (0,0)–(120,160): gcd(120,160) = 40, so 41 lattice points.
    - Then i = S − b/2 + 1. The answer may not fit in 32 bits, so use long long (64-bit).
    - Complexity: the convex-hull part dominates, O(N log N).
    - The slide also notes the problem can be reduced to fast floor-sum evaluation: floor_sum(n,m,a,b) = Σ_{i=0}^{n−1} ⌊(a×i+b)/m⌋, implementable easily with ACL's `floor_sum`.
- **Complexity:** O(N log N) for the full solution (convex hull + Pick's theorem); the subtask-2 sweep is O(N log N + max x_i).
- **Author's takeaway / typical pattern (典型):** Learn (a) the convex-hull construction with a stack and cross products, (b) ceiling division ⌈x/y⌉ = ⌊(x+y−1)/y⌋ and its use for line/lattice intersection, and (c) Pick's theorem for counting lattice points inside a lattice polygon. The slide stresses understanding "the convex hull algorithm" and "the intersection of a straight line with x = t" as geometry fundamentals.
- **Related problems (類題):**
  - P2: ZONE2021-B 「友好の印」 (intersection of lines) · ABC200-A 「Century」 (rounding up fractions) · AGC021-B 「Holes」 (find the convex hull)
  - P3: AtCoder Library Practice Contest C 「Floor Sum」 · 東京海上日動プログラミングコンテスト2020-F 「Triangles」 · Code Festival Team Relay 2018-G 「バス停と凸包」
- **Flags:** In 041-02 the slide describes both l_i and r_i as "y 座標最小のもの", which is an inconsistency/typo — r_i is the maximum. The slide's subtask-2 sweep is only valid because x_i ≤ 1000 (the sample note says example 4 satisfies subtasks 2 and 3); it does not directly scale to the full constraints, which is why P3 introduces Pick's theorem. The example 4 note ("※小課題 2, 3 の制約のみを満たします") is a statement/format artifact.

## Author's Reference Solution
The repo ships four solutions: `041-01a.cpp` (O(N²)-ish sweep for N=3 / x≤1000, using only 3 candidate points), `041-01b.cpp` (O(1000²) point-in-triangle test for N=3), `041-02.cpp` (convex hull + per-x lower/upper sweep, subtask 2), and `041-03.cpp` (convex hull + Pick's theorem, full).

**041-01a.cpp** — assumes the hull is determined by the first three points after sorting; builds a per-x bottom/top from the triangle and sums lattice points, then subtracts N.
```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

struct Point {
	long long px, py;
};

Point operator+(const Point& a1, const Point& a2) {
	return Point{ a1.px + a2.px, a1.py + a2.py };
}

Point operator-(const Point& a1, const Point& a2) {
	return Point{ a1.px - a2.px, a1.py - a2.py };
}

bool operator<(const Point& a1, const Point& a2) {
	if (a1.px < a2.px) return true;
	if (a1.px > a2.px) return false;
	if (a1.py < a2.py) return true;
	return false;
}

// 点 p1 と p2 の外積を求める
long long crs(Point p1, Point p2) {
	return p1.px * p2.py - p1.py * p2.px;
}

long long N;
long long ly[100009], ry[100009];
Point G[100009];
vector<Point> V;

int main() {
	// Step #1. 入力
	cin >> N;
	for (int i = 1; i <= N; i++) cin >> G[i].px >> G[i].py;
	sort(G + 1, G + N + 1);
	V.push_back(G[1]);
	V.push_back(G[2]);
	V.push_back(G[3]);

	// Step #2. 各 x に対する下端と上端を求める
	for (int i = 0; i <= 1000; i++) { ly[i] = (1LL << 30); ry[i] = -(1LL << 30); }
	for (int i = 0; i < V.size(); i++) {
		long long ax = V[(i + 0) % V.size()].px, ay = V[(i + 0) % V.size()].py;
		long long bx = V[(i + 1) % V.size()].px, by = V[(i + 1) % V.size()].py;
		if (ax > bx) { swap(ax, bx); swap(ay, by); }
		if (ax == bx) {
			ly[ax] = min({ ly[ax], ay, by });
			ry[ax] = max({ ry[ax], ay, by });
		}
		else {
			for (int i = ax; i <= bx; i++) {
				long long v1 = (ay * (bx - i) + by * (i - ax)) / (bx - ax);
				long long v2 = (ay * (bx - i) + by * (i - ax) + (bx - ax) - 1LL) / (bx - ax);
				ly[i] = min(ly[i], v2);
				ry[i] = max(ry[i], v1);
			}
		}
	}

	// Step #3. 答えを求める
	long long Answer = 0;
	for (int i = 0; i <= 1000; i++) {
		if (ly[i] <= ry[i]) Answer += (ry[i] - ly[i] + 1);
	}
	cout << Answer - N << endl;
	return 0;
}
```

**041-01b.cpp** — for N = 3, tests every lattice point in the 0..1000 box with a point-in-triangle orientation test, handling the collinear (area 0) case via gcd.
```cpp
#include <iostream>
#include <algorithm>
using namespace std;

struct Point {
	long long px, py;
};

Point operator+(const Point& a1, const Point& a2) {
	return Point{ a1.px + a2.px, a1.py + a2.py };
}

Point operator-(const Point& a1, const Point& a2) {
	return Point{ a1.px - a2.px, a1.py - a2.py };
}

// 点 p1 と p2 の外積を求める
long long crs(Point p1, Point p2) {
	return p1.px * p2.py - p1.py * p2.px;
}

// 点 p1, p2, p3 が時計回りか反時計回りか
int ccw(Point p1, Point p2, Point p3) {
	Point va = p2 - p1;
	Point vb = p3 - p1;
	if (crs(va, vb) > 0) return 1;
	if (crs(va, vb) < 0) return -1;
	return 0;
}

long long gcd(long long a, long long b) {
	if (b == 0) return a;
	return gcd(b, a % b);
}

long long N, Answer = 0;
Point G[10];

int main() {
	// Step #1. 入力
	cin >> N;
	for (int i = 1; i <= N; i++) cin >> G[i].px >> G[i].py;

	// Step #2. コーナーケース
	if (crs(G[2] - G[1], G[3] - G[1]) == 0) {
		long long cl = min({ G[1].px, G[2].px, G[3].px });
		long long cr = max({ G[1].px, G[2].px, G[3].px });
		long long dl = min({ G[1].py, G[2].py, G[3].py });
		long long dr = max({ G[1].py, G[2].py, G[3].py });
		long long ret = gcd(cr - cl, dr - dl);
		cout << ret - 2 << endl;
		return 0;
	}

	// Step #3. 答えの計算
	for (int i = 0; i <= 1000; i++) {
		for (int j = 0; j <= 1000; j++) {
			Point H = Point{ i, j };
			int cnt = 0;
			if (ccw(G[1], H, G[2]) == ccw(G[1], H, G[3])) cnt++;
			if (ccw(G[2], H, G[3]) == ccw(G[2], H, G[1])) cnt++;
			if (ccw(G[3], H, G[1]) == ccw(G[3], H, G[2])) cnt++;
			if (cnt == 0) Answer += 1;
		}
	}

	// Step #4. 出力
	cout << Answer << endl;
	return 0;
}
```

**041-02.cpp** — builds the convex hull (monotone chain) and then sweeps each integer x from 0 to 1000 to find the lowest/highest hull y, counting lattice points; subtracts N. Subtask 2.
```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

struct Point {
	long long px, py;
};

Point operator+(const Point& a1, const Point& a2) {
	return Point{ a1.px + a2.px, a1.py + a2.py };
}

Point operator-(const Point& a1, const Point& a2) {
	return Point{ a1.px - a2.px, a1.py - a2.py };
}

bool operator<(const Point& a1, const Point& a2) {
	if (a1.px < a2.px) return true;
	if (a1.px > a2.px) return false;
	if (a1.py < a2.py) return true;
	return false;
}

// 点 p1 と p2 の外積を求める
long long crs(Point p1, Point p2) {
	return p1.px * p2.py - p1.py * p2.px;
}

long long N;
long long ly[100009], ry[100009];
Point G[100009];

int main() {
	// Step #1. 入力
	cin >> N;
	for (int i = 1; i <= N; i++) cin >> G[i].px >> G[i].py;
	sort(G + 1, G + N + 1);

	// Step #2. 凸包を求める
	vector<Point> G1, G2, Totsuhou;
	G1.push_back(G[1]); G2.push_back(G[1]);
	G1.push_back(G[2]); G2.push_back(G[2]);
	for (int i = 3; i <= N; i++) {
		while (G1.size() >= 2 && crs(G1[G1.size() - 1] - G1[G1.size() - 2], G[i] - G1[G1.size() - 1]) <= 0) G1.pop_back();
		while (G2.size() >= 2 && crs(G2[G2.size() - 1] - G2[G2.size() - 2], G[i] - G2[G2.size() - 1]) >= 0) G2.pop_back();
		G1.push_back(G[i]);
		G2.push_back(G[i]);
	}
	for (int i = 0; i < G1.size(); i++) Totsuhou.push_back(G1[i]);
	for (int i = (int)G2.size() - 2; i >= 1; i--) Totsuhou.push_back(G2[i]);

	// Step #3. 各 x に対する下端と上端を求める
	for (int i = 0; i <= 1000; i++) { ly[i] = (1LL << 30); ry[i] = -(1LL << 30); }
	for (int i = 0; i < Totsuhou.size(); i++) {
		long long ax = Totsuhou[(i + 0) % Totsuhou.size()].px, ay = Totsuhou[(i + 0) % Totsuhou.size()].py;
		long long bx = Totsuhou[(i + 1) % Totsuhou.size()].px, by = Totsuhou[(i + 1) % Totsuhou.size()].py;
		if (ax > bx) { swap(ax, bx); swap(ay, by); }
		if (ax == bx) {
			ly[ax] = min({ ly[ax], ay, by });
			ry[ax] = max({ ry[ax], ay, by });
		}
		else {
			for (int i = ax; i <= bx; i++) {
				long long v1 = (ay * (bx - i) + by * (i - ax)) / (bx - ax);
				long long v2 = (ay * (bx - i) + by * (i - ax) + (bx - ax) - 1LL) / (bx - ax);
				ly[i] = min(ly[i], v2);
				ry[i] = max(ry[i], v1);
			}
		}
	}

	// Step #4. 答えを求める
	long long Answer = 0;
	for (int i = 0; i <= 1000; i++) {
		if (ly[i] <= ry[i]) Answer += (ry[i] - ly[i] + 1);
	}
	cout << Answer - N << endl;
	return 0;
}
```

**041-03.cpp** — builds the convex hull, counts boundary lattice points via gcd, computes twice the area via the shoelace sum, applies Pick's theorem, and subtracts N. Full solution.
```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

struct Point {
	long long px, py;
};

Point operator+(const Point& a1, const Point& a2) {
	return Point{ a1.px + a2.px, a1.py + a2.py };
}

Point operator-(const Point& a1, const Point& a2) {
	return Point{ a1.px - a2.px, a1.py - a2.py };
}

bool operator<(const Point& a1, const Point& a2) {
	if (a1.px < a2.px) return true;
	if (a1.px > a2.px) return false;
	if (a1.py < a2.py) return true;
	return false;
}

// 点 p1 と p2 の外積を求める
long long crs(Point p1, Point p2) {
	return p1.px * p2.py - p1.py * p2.px;
}

long long gcd(long long a, long long b) {
	if (b == 0) return a;
	return gcd(b, a % b);
}

long long N;
Point G[100009];

int main() {
	// Step #1. 入力
	cin >> N;
	for (int i = 1; i <= N; i++) cin >> G[i].px >> G[i].py;
	sort(G + 1, G + N + 1);

	// Step #2. 凸包を求める
	vector<Point> G1, G2, Totsuhou;
	G1.push_back(G[1]); G2.push_back(G[1]);
	G1.push_back(G[2]); G2.push_back(G[2]);
	for (int i = 3; i <= N; i++) {
		while (G1.size() >= 2 && crs(G1[G1.size() - 1] - G1[G1.size() - 2], G[i] - G1[G1.size() - 1]) <= 0) G1.pop_back();
		while (G2.size() >= 2 && crs(G2[G2.size() - 1] - G2[G2.size() - 2], G[i] - G2[G2.size() - 1]) >= 0) G2.pop_back();
		G1.push_back(G[i]);
		G2.push_back(G[i]);
	}
	for (int i = 0; i < G1.size(); i++) Totsuhou.push_back(G1[i]);
	for (int i = (int)G2.size() - 2; i >= 1; i--) Totsuhou.push_back(G2[i]);

	// Step #3. 辺上の格子点の数を求める
	long long EdgePoint = Totsuhou.size();
	for (int i = 0; i < Totsuhou.size(); i++) {
		long long ax = Totsuhou[(i + 0) % Totsuhou.size()].px, ay = Totsuhou[(i + 0) % Totsuhou.size()].py;
		long long bx = Totsuhou[(i + 1) % Totsuhou.size()].px, by = Totsuhou[(i + 1) % Totsuhou.size()].py;
		long long vx = abs(bx - ax);
		long long vy = abs(by - ay);
		long long r = gcd(vx, vy);
		EdgePoint += (r - 1LL);
	}

	// Step #4. 多角形の面積（を 2 倍した値）を求める
	long long Area = 0;
	for (int i = 0; i < Totsuhou.size(); i++) {
		long long ax = Totsuhou[(i + 0) % Totsuhou.size()].px, ay = Totsuhou[(i + 0) % Totsuhou.size()].py;
		long long bx = Totsuhou[(i + 1) % Totsuhou.size()].px, by = Totsuhou[(i + 1) % Totsuhou.size()].py;
		Area += (bx - ax) * (by + ay);
	}
	Area = abs(Area);

	// Step #5. 答えを求める
	long long Answer = Area + EdgePoint + 2LL;
	cout << (Answer / 2LL) - N << endl;
	return 0;
}
```
