# 013 — Passing Through a Vertex (Two Dijkstras)

**Difficulty:** ★×5 (author's star rating)
**Link:** https://atcoder.jp/contests/typical90/tasks/typical90_m
**Source:** AtCoder Typical90 #013 — official statement and samples; editorial essence distilled from the official Japanese slides.

## Statement (original Japanese)
AGC 王国には N 個の交差点があり、それぞれ 1, 2, 3, ..., N と番号付けられています。
また M 本の道路があり、道路 i は交差点 A[i] と交差点 B[i] を双方向に結び、交差点間の移動にかかる時間は C[i] 秒です。

今日から数えて i (1≦i≦N) 日目には交差点 i でイベントが開催されるため、移動の際には交差点 i を経由しなければなりません、
i = 1, 2, 3, ..., N それぞれについて、i 日目に交差点 1 から交差点 N まで移動するのにかかる時間の最小値を求めてください。

## Statement (English translation)
The AGC kingdom has N intersections, numbered 1, 2, 3, ..., N.
There are M roads; road i bidirectionally connects intersection A[i] and intersection B[i], and the travel time between the intersections is C[i] seconds.

An event is held at intersection i on the i-th day counting from today (1 ≤ i ≤ N), so when moving you must pass through intersection i.
For each i = 1, 2, 3, ..., N, find the minimum time needed on day i to travel from intersection 1 to intersection N.

## Constraints
【制約】
・2 ≦ N ≦ 100000　←　こっちが正しいです！
・1 ≦ M ≦ 100000
・1 ≦ A[i] < B[i] ≦ N
・(A[i], B[i]) ≠ (A[j], B[j]) [i ≠ j]
・1 ≦ C[i] ≦ 10000
・いくつかの道路を通って、都市 1 から都市 N までたどり着ける
・入力はすべて整数

## Author's Editorial — Concept & Essence
- **Keyword (キーワード):** 各頂点への最短経路はダイクストラ (Shortest paths to every vertex are Dijkstra)
- **Core idea:** The required route is 1 → i → N, so the answer for each i is (shortest path 1↔i) + (shortest path i↔N). Run Dijkstra once from vertex 1 and once from vertex N; then each answer is just dist1[i] + distN[i]. Combining shortest-path computations from both endpoints is a standard trick.
- **Editorial steps:**
  - **Step 1:** Dijkstra's algorithm: given a start vertex s, find the shortest path to every vertex. It is well known as a method for shortest paths with non-negative edge weights, and it can compute all shortest paths from s at once in O((N + M) log N).
  - **Step 2:** We must find the shortest path of the route intersection 1 → intersection i → intersection N, i.e. (shortest path 1↔i) + (shortest path i↔N). Using Step 1: compute the shortest path from intersection 1 to every vertex, and from intersection N to every vertex; then for each i the answer can be found immediately as the sum. (Figure shows the two Dijkstra runs from vertex 1 and from vertex 7.)
- **Complexity:** O((N + M) log N)
- **Author's takeaway / typical pattern (典型):** Combining computations from both ends — computing left-end/right-end results first and then combining them — is a technique frequently asked in contests.
- **Related problems (類題):** ABC 160-D「Line++」, TPC 追いコン 2016 問題A「不完全迷路」, ARC 070-D「No Need」
- **Flags:** none

## Author's Reference Solution
- **013.cpp** — Runs Dijkstra from vertex 1 and from vertex N, stores `dist1` and `distN`, and prints `dist1[i] + distN[i]` for each i.

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <algorithm>
#include <functional>
using namespace std;

// 入力
long long N, M;
long long A[100009], B[100009], C[100009];

// グラフ・最短距離
long long dist[100009];
long long dist1[100009];
long long distN[100009];
vector<pair<int, long long>> G[100009];

void dijkstra(int stt) {
	priority_queue<pair<long long, int>, vector<pair<long long, int>>, greater<pair<long long, int>>> Q;
	for (int i = 1; i <= N; i++) dist[i] = (1LL << 60);
	dist[stt] = 0;
	Q.push(make_pair(0, stt));

	while (!Q.empty()) {
		int pos = Q.top().second; Q.pop();
		for (int i = 0; i < G[pos].size(); i++) {
			int to = G[pos][i].first;
			long long cost = G[pos][i].second;
			if (dist[to] > dist[pos] + cost) {
				dist[to] = dist[pos] + cost;
				Q.push(make_pair(dist[to], to));
			}
		}
	}
}

int main() {
	// Step #1. 入力
	cin >> N >> M;
	for (int i = 1; i <= M; i++) {
		cin >> A[i] >> B[i] >> C[i];
		G[A[i]].push_back(make_pair(B[i], C[i]));
		G[B[i]].push_back(make_pair(A[i], C[i]));
	}

	// Step #2. 頂点 1 からの最短距離を求める
	dijkstra(1);
	for (int i = 1; i <= N; i++) dist1[i] = dist[i];

	// Step #3. 頂点 N からの最短距離を求める
	dijkstra(N);
	for (int i = 1; i <= N; i++) distN[i] = dist[i];

	// Step #4. 出力
	for (int i = 1; i <= N; i++) {
		long long Answer = dist1[i] + distN[i];
		cout << Answer << endl;
	}
	return 0;
}
```
