# 084 — Intervals Containing Both 'o' and 'x'

**Difficulty:** ★×3 (author's star rating)
**Link:** https://atcoder.jp/contests/typical90/tasks/typical90_cf
**Source:** AtCoder Typical90 #084 — official statement and samples; editorial essence distilled from the official Japanese slides.

## Statement (original Japanese)
'o' と 'x' からなる長さ N の文字列 S が与えられます。

以下の条件をすべて満たす整数の組 (l, r) の個数を求めてください。

・1 ≦ l ≦ r ≦ N
・S の l 文字目から r 文字目までの区間に、'o' と 'x' 両方が含まれる

## Statement (English translation)
You are given a string S of length N consisting of 'o' and 'x'.

Find the number of integer pairs (l, r) satisfying all of the following conditions:

- 1 ≦ l ≦ r ≦ N
- The interval from the l-th to the r-th character of S contains both 'o' and 'x'.

## Constraints
・1 ≦ N ≦ 10^6
・S は 'o', 'x' からなる長さ N の文字列である

## Author's Editorial — Concept & Essence
- **Keyword (キーワード):** ランレングス圧縮 (Solution 1) ／ 累積的に計算しよう (Solution 2)
- **Core idea:** Solution 1 counts the complement: subtract intervals consisting of only 'o' or only 'x' (each maximal run of equal characters contributes d(d+1)/2) from the total N(N+1)/2. Solution 2 instead scans r left to right, tracking the most recent positions of 'o' and 'x'; the number of valid l for a given r is the smaller of those two positions, and the answer is their sum.
- **Editorial steps:**
  - **解法1:** 「o と x が両方含まれている区間 [l,r] の個数」を求めるのは少し難しいので、以下の余事象 (典型017 小課題2) を考える：「o だけしか含まれない区間」と「x だけしか含まれない区間」の合計個数を ret とする。ret の値を求める。
  - 区間 [l,r] の選び方の数（条件を満たさないものも含む）は、r=1 のとき 1 通り、r=2 のとき 2 通り、…、r=N のとき N 通りとなるので、等差数列の和の公式 (典型082) より 1+2+3+…+N = N(N+1)/2。したがって求めるべき答えは N(N+1)/2 − ret となり、ret の値が分かれば良い。
  - 文字列 S をランレングス圧縮する。例えば S = "oooooxxxxxoo" は (c₁,d₁)=("o",5), (c₂,d₂)=("x",4), (c₃,d₃)=("o",2) と圧縮される。
  - 「区間 [l,r] が o と x のうち片方しか含まない」は「区間 [l,r] が単一のグループの中に入っている」と言い換えられる。グループ i の中に入っている区間の個数は 1+2+…+d_i = d_i(d_i+1)/2 であるため、ret = d₁(d₁+1)/2 + d₂(d₂+1)/2 + … + d_K(d_K+1)/2 と求まる。
  - 例: S="oooooxxxxxoo" のとき ret = (5·6/2)+(4·5/2)+(3·4/2) = 15+10+6 = 31。区間 [l,r] の選び方の個数は 12·13/2 = 78 であるため、答えは 78 − 31 = 47。全体計算量 O(N)。
  - **解法2:** 余事象を使わない別の解法もある。r の値が決まっている場合を考える。そのとき、l の値が「ある一定以下」であるときに限り、区間 [l,r] に o と x が両方含まれている。そこで、ある一定以下の値 z_r は次の通り：「r 文字目までで最後に現れる o の位置を A_r、x の位置を B_r（文字列に存在しない場合は A_r = B_r = 0）とするとき、z_r = min(A_r, B_r)」である。
  - 例: S="oooooxxxxxoo" で r=8 の場合、A_r=5, B_r=8 であるため z_r=min(5,8)=5 ですから、確かに区間 [6,8],[7,8],[8,8] は o, x のうち片方しか含まない一方、区間 [1,8],[2,8],[3,8],[4,8],[5,8] は o, x 両方含みます。このように考えると、求める答えは z₁+…+z_N となります。
  - A = (A₁,…,A_N), B = (B₁,…,B_N) は次のように累積的に計算できる。まず仮に A₀=0, B₀=0 とする。i=1,2,3,…,N の順に、[1] S の i 文字目が 'o' である場合 A_i=i, B_i=B_{i−1} となる。[2] S の i 文字目が 'x' である場合 A_i=A_{i−1}, B_i=i となる。全体計算量 O(N)。
- **Complexity:** O(N)
- **Author's takeaway / typical pattern (典型):** ランレングス圧縮を使うと全体計算量 O(N) で答えを出すことができます。なお「条件を満たす個数」よりも「条件を満たさない個数」の方が数えやすい場合、余事象を考えるテクニックが有効です。また、最後に現れる o, x の位置を累積的に計算する考え方は累積和 (典型010) や動的計画法 (典型050) などにも応用できます。

## Author's Reference Solution
`084-01.cpp` — Run-length compression; subtract the number of single-character intervals from N(N+1)/2.

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

long long N;
string S;
vector<pair<char, long long>> vec;

int main() {
	cin >> N >> S;

	long long cnt = 0;
	for (int i = 0; i < S.size(); i++) {
		cnt++;
		if (i == (int)S.size() - 1 || S[i] != S[i + 1]) {
			vec.push_back(make_pair(S[i], cnt));
			cnt = 0;
		}
	}

	long long ret = 0;
	for (int i = 0; i < vec.size(); i++) {
		ret += 1LL * vec[i].second * (vec[i].second + 1LL) / 2LL;
	}
	cout << N * (N + 1) / 2LL - ret << endl;
	return 0;
}
```

`084-02.cpp` — Cumulative positions: for each i, track last positions A[i] of 'o' and B[i] of 'x', add min(A[i], B[i]) to the answer.

```cpp
#include <iostream>
#include <string>
#include <algorithm>
using namespace std;

long long N, A[1 << 20], B[1 << 20];
string S;

int main() {
	cin >> N >> S;
	for (int i = 1; i <= N; i++) {
		if (S[i - 1] == 'o') { A[i] = i; B[i] = B[i - 1]; }
		if (S[i - 1] == 'x') { A[i] = A[i - 1]; B[i] = i; }
	}

	long long Answer = 0;
	for (int i = 1; i <= N; i++) {
		Answer += 1LL * min(A[i], B[i]);
	}
	cout << Answer << endl;
	return 0;
}
```
