## Statement (original Japanese)
平面 x=0 上に、高さ L の T 分で一周する観覧車があります。
観覧車は円形になっており、次のように一定の速さで動きます。ただし xy 平面が水平方向、z 軸が垂直方向です。
・乗ってから 0 分後には座標 (0, 0, 0) にある
・乗ってから T/4 分後には座標 (0, -L/2, L/2) にある
・乗ってから T/2 分後には座標 (0, 0, L) にある
・乗ってから 3T/4 分後には座標 (0, L/2, L/2) にある

観覧車の名物である「高橋直大像」は座標 (X, Y, 0) に存在します。
以下の形式の質問が Q 個与えられるので、順に答えてください。
・i 個目の質問では、E869120 君が観覧車に乗ってから E[i] 分後における、E869120 君から見た高橋直大像の俯角を求めよ。
・ただし、俯角は 0 度から 90 度までの度数法で出力すること。絶対誤差または相対誤差が 10^{-7} 以内であれば正解となる。

## Statement (English translation)
On the plane x = 0 there is a Ferris wheel with height L that makes one revolution in T minutes.
The Ferris wheel is circular, and it moves at a constant speed as follows. However, the xy-plane is the horizontal direction and the z-axis is the vertical direction.
・0 minutes after boarding, it is at coordinates (0, 0, 0)
・T/4 minutes after boarding, it is at coordinates (0, -L/2, L/2)
・T/2 minutes after boarding, it is at coordinates (0, 0, L)
・3T/4 minutes after boarding, it is at coordinates (0, L/2, L/2)

The "Takahashi Naohiro Statue", which is the specialty of the Ferris wheel, exists at coordinates (X, Y, 0).
Q questions of the following form are given, so answer them in order.
・In the i-th question, find the angle of depression of the Takahashi Naohiro Statue as seen from E869120-kun, E[i] minutes after E869120-kun boarded the Ferris wheel.
・However, output the angle of depression in the degree system from 0 degrees to 90 degrees. It is correct if the absolute error or the relative error is within 10^{-7}.

## Constraints

・2 ≦ T ≦ 10^9
・1 ≦ L, X, Y ≦ 10^9
・0 ≦ E[i] < T
・1 ≦ Q ≦ 1000
・入力はすべて整数

## Author's Editorial — Concept & Essence
- **Keyword (キーワード):** 三角関数を使いこなそう (get comfortable with trigonometric functions)
- **Core idea:** The wheel is a circle of radius L/2 centred at (0, 0, L/2), so after turning θ the rider sits at (0, −(L/2) sin θ, L/2 − (L/2) cos θ); after E_i minutes θ = 360° × E_i / T. The depression angle to the statue is atan2(B, A), where A is the horizontal distance from the rider to the statue and B = sz is the rider's height.
- **Editorial steps:**
  - **Step 1 (rider position):** 「まず、観覧車の中心座標は (0, 0, L/2) なので、θ 度回った時の観覧車の座標は次のようになります」 — x座標: 0, y座標: −L/2 × sin(θ°), z座標: L/2 − L/2 × cos(θ°).
  - **Step 2 (substitute E_i):** after E_i minutes the wheel has already gone E_i ÷ T revolutions, i.e. E_i ÷ T × 360 degrees, so the position is (x, y, z) = (0, −L/2 × sin(360° × E_i/T), L/2 − L/2 × cos(360° × E_i/T)).
  - **Step 3 (radians, not degrees):** in C++ (and other languages) sin and cos take the angle in radians; to get sin of a degrees one must write sin(3.1415... × a / 180.0).
  - **Step 4 (atan2):** atan2(y, x) is a convenient C++ function returning the angle of the vector (x, y) in radians; the slide's example is atan2(1, 1) = 0.785398…, which multiplied by 180/3.14159… gives 45.
  - **Step 5 (the two lengths):** let A be the horizontal distance between the statue and the wheel and B the wheel's height; the required depression angle is atan2(B, A). For the wheel's coordinates (0, sy, sz), 「水平距離・観覧車の高さは次の式で表されます」 — A = √(px² + (sy − py)²),  B = sz (the slide writes the statue's coordinates as (px, py); in the statement they are (X, Y)).
  - **Step 6:** A is computed with the sqrt function; 「この問題では、計算量は特に意識しなくても良いです」.
- **Complexity:** Not stated on the slides beyond 「計算量は特に意識しなくても良いです」; per query the work is O(1) arithmetic (one sin, one cos, one sqrt, one atan2), so O(Q) overall.
- **Author's takeaway / typical pattern (典型):** geometry problems can require 三角関数・逆三角関数 (trigonometric and inverse-trigonometric functions) and also dot/cross products of vectors; 「しっかり押さえておきましょう」.
- **Related problems (類題):** ABC168-C 「Colon」, ABC197-D 「Opposite」, ABC144-D 「Water Bottle」
- **Flags:** (1) The slide never says the final answer must be converted from radians to degrees, nor that the output must be 0…90 degrees with 10^-7 absolute or relative error — the reference code multiplies by 180/π at the very end. (2) The formula uses (px, py) for the statue while the statement uses (X, Y), and (sy, sz) for the rider at x = 0; the correspondence is left implicit. (3) Nothing is said about the E_i/T × 360 formula needing E_i mod T (harmless only because E_i < T), nor about the rider at the bottom (sz = 0) where atan2(0, A) = 0. (4) The atan2 example only shows the radian value 0.785398…; the conversion 「180/3.14159… を掛けると 45 になる」 is stated but never written as part of the formula.

## Author's Reference Solution
`018.cpp` — Places the cabin from E via sine and cosine, then prints the angle of depression of the statue obtained with atan2 for every query.

```cpp
#include <iostream>
#include <cmath>
using namespace std;

int Q;
long double T, L, X, Y, E;
long double PI = 3.14159265358979;

long double query(long double I) {
	long double cx = 0;
	long double cy = -(L / 2.0) * sin(I / T * 2.0 * PI);
	long double cz = (L / 2.0) - (L / 2.0) * cos(I / T * 2.0 * PI);
	long double d1 = sqrt((cx - X) * (cx - X) + (cy - Y) * (cy - Y));
	long double d2 = cz;
	long double kaku = atan2(d2, d1);
	return kaku * 180.0L / PI;
}

int main() {
	cin >> T;
	cin >> L >> X >> Y;
	cin >> Q;
	for (int i = 1; i <= Q; i++) {
		cin >> E;
		printf("%.12Lf\n", query(E));
	}
	return 0;
}
```
