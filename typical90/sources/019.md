# 019 — Pick Two (Pairing Adjacent People)

**Difficulty:** ★×6 (author's star rating)
**Link:** https://atcoder.jp/contests/typical90/tasks/typical90_s
**Source:** AtCoder Typical90 #019 — official statement and samples; editorial essence distilled from the official Japanese slides.

## Statement (original Japanese)
2N 人が一列に並んでおり、左から i 番目の人の身長は A[i] です。

YouTuber である ABC 君はこれからライブショーを行います。ショーでは、以下の操作を N 回行います。
・隣り合う 2 人を選び、列から抜けさせる。一度列から抜けると、もう列に戻ってくることはない。
・このとき、あまりにも 2 人の身長差が大きいと視聴者が引いてしまう。具体的には、2 人の身長を x, y とするとき、低評価が |x-y| 個付く。

彼は低評価の個数を最小化したいです。
最適にショーを行ったとき、低評価の個数として考えられる最小の値はいくつでしょうか？

## Statement (English translation)
2N people are lined up in a row, and the height of the i-th person from the left is A[i].

ABC-kun, a YouTuber, is about to perform a live show. In the show, he performs the following operation N times.
・Choose two adjacent people and remove them from the row. Once they leave the row, they never come back to the row.
・At this time, if the height difference between the two is too large, the viewers will be put off. Concretely, when the heights of the two are x, y, |x-y| dislikes are added.

He wants to minimize the number of dislikes.
When the show is performed optimally, what is the smallest possible value for the number of dislikes?

## Constraints
【制約】
・1 ≦ N ≦ 200
・1 ≦ A[i] ≦ 1000000
・入力はすべて整数

## Author's Editorial — Concept & Essence
- **Keyword (キーワード):** 列の操作は区間 DP (operations on a row are interval DP)
- **Core idea:** Let dp[l][r] be the minimum cost needed for exactly the people l, l+1, …, r to be removed. Fill it in by increasing interval length: either l and r leave last as one pair (everything strictly inside already gone), or the interval splits into two independently solved intervals. The answer is dp[1][2N].
- **Editorial steps:**
  - **Step 1 (the definition):** 「それぞれの区間に対する最適な値を、区間の長さの小さい順に求めていく DP を、区間 DP といいます」. Here dp[l][r] = the cost needed for exactly persons l, l+1, …, r to be removed. The figure shows heights 3 2 7 4 1 6 2 5 with a bracket over positions 4…7 annotated dp[4][7] = 7 (pairs (4,1) and (6,2), i.e. 3 + 4), captioned 「区間 [l,r] の人が全て抜けるのに必要なコスト dp[l][r]」.
  - **Step 2 (two patterns):** the operation reaching dp[l][r] is split into two patterns and the cheaper is kept:
    - **[パターン 1] 最後に人 l, r が抜ける場合:** one step before, persons l+1, …, r−1 have already been removed, so dp[l][r] = dp[l+1][r−1] + |A_l − A_r|.
    - **[パターン 2] それ以外の場合:** the operations on [l, r] can be split into two intervals; splitting as [l, k] and [k+1, r] gives dp[l][r] = dp[l][k] + dp[k+1][r].
  - **Step 3 (order):** compute dp[l][r] in increasing interval length, taking the minimum over these options; the final answer dp[1][2N] is then obtained in O(N³).
- **Complexity:** O(N³) — 「最終的な答えである dp[1][2N] は計算量 O(N^3) で求まります」. The slide adds that interval-DP solutions are often O(N²) or O(N³) depending on the problem.
- **Author's takeaway / typical pattern (典型):** 区間 DP — a DP over intervals, filled in by increasing interval length — solves problems about operations on a row efficiently, and is the named pattern for this whole family.
- **Related problems (類題):** AOJ ALDS1-10-B 「連鎖行列積」, JOI 2015 本選 2 「ケーキの切り分け 2」, Typical DP Contest 問題 I 「イウィ」
- **Flags:** (1) The slides never state that only even-length intervals are feasible (a person can only leave together with a neighbour), nor the base case dp[i][i+1] = |A_i − A_{i+1}|; the reference code initialises the 2-element intervals and then loops only over odd lengths (`i += 2`), so the parity restriction is silently assumed. (2) In pattern 1, dp[l+1][r−1] is the empty interval with cost 0 when r = l+1; the slides do not mention this base case. (3) Pattern 2 is described only as 「それ以外の場合」 and needs the reading “l and r are not removed as a pair”; the split point k must also make both halves even-length, which is not stated. (4) The justification that “l and r leave last” plus “split into two intervals” covers every valid removal order is not written on the slide.

## Author's Reference Solution
`019.cpp` — Interval DP over even-length ranges, which either joins two subranges or removes both endpoints as one pair.

```cpp
#include <iostream>
#include <cmath>
#include <algorithm>
using namespace std;

int N;
int A[1 << 18];
int dp[409][409];

int main() {
	// Step #1. Input
	cin >> N;
	for (int i = 1; i <= 2 * N; i++) cin >> A[i];

	// Step #2. Initialize
	for (int i = 1; i <= 2 * N; i++) {
		for (int j = i; j <= 2 * N; j++) dp[i][j] = (1 << 29);
		if (i < 2 * N) dp[i][i + 1] = abs(A[i] - A[i + 1]);
	}

	// Step #3. DP
	for (int i = 3; i <= 2 * N; i += 2) {
		for (int j = 1; j <= 2 * N - i; j++) {
			int cl = j, cr = j + i;
			for (int k = cl; k <= cr - 1; k++) dp[cl][cr] = min(dp[cl][cr], dp[cl][k] + dp[k + 1][cr]);
			dp[cl][cr] = min(dp[cl][cr], dp[cl + 1][cr - 1] + abs(A[cl] - A[cr]));
		}
	}

	// Step #4. Output
	cout << dp[1][2 * N] << endl;
	return 0;
}
```
