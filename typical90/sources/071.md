# 071 — Find K permutations satisfying the precedence constraints

**Difficulty:** ★×7 (author's star rating)
**Link:** https://atcoder.jp/contests/typical90/tasks/typical90_bs
**Source:** AtCoder Typical90 #071 — official statement and samples; editorial essence distilled from the official Japanese slides.

## Statement (original Japanese)
(1, 2, 3, ... , N) の順列 P = P[1], P[2], P[3], ... , P[N]) であって、以下の条件を満たすものを K 個求めてください。 K 個存在しない場合は、そのことを報告してください。

・i = 1, 2, 3, ... , M について、順列 P の中で A[i] は B[i] よりも前にある。

## Statement (English translation)
Find K permutations P = (P[1], P[2], P[3], ..., P[N]) of (1, 2, 3, ..., N) that satisfy the following condition. If K such permutations do not exist, report that fact.

- For i = 1, 2, 3, ..., M, A[i] appears before B[i] in the permutation P.

## Constraints
【制約】
・1 ≦ N ≦ 10^5
・1 ≦ M ≦ 10^5
・1 ≦ K ≦ 10
・1 ≦ A[i] ≦ N
・1 ≦ B[i] ≦ N
・A[i] ≠ B[i]
・i ≠ j ならば (A[i], B[i]) ≠ (A[j], B[j])
・入力はすべて整数

【小課題】
1. (2 点) N ≦ 10^3
2. (3 点) K = 1
3. (2 点) 追加の制約はない

## Author's Editorial — Concept & Essence
- **Keyword (キーワード):** Page P1: グラフに置き換えて考える (think by replacing the problem with a graph) / Page P2: トポロジカルソート (topological sort) / Page P3: DFS で全探索 (exhaustive search with DFS)
- **Core idea:** Model the precedence constraints as a directed graph: N vertices, an edge A_i → B_i for each constraint. A valid permutation is exactly a topological order of this graph. For K = 1 a single topological sort suffices; for general K, run a DFS backtracking that enumerates topological orders and stops as soon as K of them have been collected.
- **Editorial steps:**
  - **P1 — グラフに置き換えて考える.** Replace the problem with a directed graph with N vertices and M edges, edge i going from A_i to B_i. We must assign the numbers 1, 2, ..., N to the vertices so that every edge points from a smaller number to a larger number. This is the famous *topological sort* problem, and it solves the K = 1 case immediately: vertex i gets number i, and the order (P_1, P_2, ..., P_N) is the answer. Worked example N = 7, M = 9 with constraints 1→3, 1→6, 4→1, 4→2, 5→2, 5→7, 6→2, 7→3, 7→6 (notation "x → y" = x must come before y): topological sort yields P = (4, 5, 1, 7, 6, 3, 2). Converting to a graph is an important means of organizing one's thinking; many competitive-programming problems become easier to see as graphs. But how is a topological sort actually computed?
  - **P2 — トポロジカルソート (小課題 2, K = 1).** Greedy algorithm: repeat for i = 1, 2, ..., N: choose one vertex with no incoming edge, assign it number i, then delete it. If at some point no such vertex exists, no topological sort exists. Naively this costs O(NM) and does not meet the time limit, so speed it up with a queue exactly as in typical 062: 1. Let d_i be the number of edges entering vertex i. 2. Put every vertex with d_i = 0 into a queue Q. While Q is not empty: 3. pop a vertex u from Q, assign it the next number k, then decrement d_i for every out-neighbour of u. If Q becomes empty before all vertices are numbered, no topological sort exists. Complexity O(N + M). Topological sort is useful not only in competitive programming but also for real-world job scheduling.
  - **P3 — DFS で全探索 (満点解法).** Subtask 2 wrote the numbers in increasing order; now enumerate all topological sorts that branch when several vertices are simultaneously selectable, using DFS. DFS manages the set of currently selectable vertices and updates it every time a number is written. A naive implementation costs O((N^2 + M) × K), which only passes subtask 1, so exploit the fact that we only ever need to take the first K elements of the queue, reducing the cost to O((N + M) × K). (Alternative: repeatedly build a topological sort choosing a vertex uniformly at random; O((N + M) × 2^K) and correct with high probability.) DFS is often used to enumerate exponential state spaces, but it can also be used to enumerate just K of them; once K are found, stop the DFS.
- **Complexity:** K = 1: O(N + M). Full: O((N + M) × K) (naive DFS O((N^2 + M) × K); randomized alternative O((N + M) × 2^K)).
- **Author's takeaway / typical pattern (典型):** Replacing a problem by a graph makes it easier to reason about, and topological sort is a fundamental tool (also useful for scheduling). DFS backtracking can enumerate the first K solutions of a branching search.

The exact worst-case bound of the reference DFS is the one printed in the source file, O((N + M + K) × K).

## Author's Reference Solution
- `071-02.cpp` — Subtask 2 (K = 1): Kahn's algorithm (queue-based topological sort), O(N + M).
- `071-03.cpp` — Full solution: DFS backtracking over the set of currently selectable vertices, collecting the first K permutations, O((N + M + K) × K).

```cpp
// 071-02.cpp — Subtask: K = 1
// Time Complexity: O(N + M)

#include <queue>
#include <vector>
#include <cassert>
#include <iostream>
using namespace std;
int main() {
	int N, M, K;
	cin >> N >> M >> K;
	assert(K == 1);
	vector<vector<int> > G(N);
	vector<int> deg(N);
	for (int i = 0; i < M; ++i) {
		int a, b;
		cin >> a >> b; --a, --b;
		G[a].push_back(b);
		++deg[b];
	}
	queue<int> que;
	for (int i = 0; i < N; ++i) {
		if (deg[i] == 0) {
			que.push(i);
		}
	}
	vector<int> perm;
	while (!que.empty()) {
		int u = que.front(); que.pop();
		perm.push_back(u);
		for (int i : G[u]) {
			--deg[i];
			if (deg[i] == 0) {
				que.push(i);
			}
		}
	}
	if (perm.size() != N) {
		cout << -1 << endl;
	}
	else {
		for (int i = 0; i < N; ++i) {
			if (i != 0) cout << ' ';
			cout << perm[i] + 1;
		}
		cout << endl;
	}
	return 0;
}
```

```cpp
// 071-03.cpp — Full solution
// Time Complexity: O((N + M + K) * K)

#include <vector>
#include <iostream>
#include <functional>
using namespace std;
int main() {
	cin.tie(0);
	ios_base::sync_with_stdio(false);
	int N, M, K;
	cin >> N >> M >> K;
	vector<vector<int> > G(N);
	vector<int> deg(N);
	for (int i = 0; i < M; ++i) {
		int a, b;
		cin >> a >> b; --a, --b;
		G[a].push_back(b);
		++deg[b];
	}
	vector<int> st;
	vector<int> perm(N, -1);
	vector<vector<int> > answer_list;
	function<bool(int)> dfs = [&](int depth) {
		if (depth == N) {
			answer_list.push_back(perm);
			return true;
		}
		if (st.empty()) {
			return false;
		}
		for (int i = int(st.size()) - 1; i >= 0; --i) {
			if (answer_list.size() == K) {
				break;
			}
			int x = st[i];
			st.erase(st.begin() + i);
			for (int j : G[x]) {
				--deg[j];
				if (deg[j] == 0) {
					st.push_back(j);
				}
			}
			perm[depth] = x;
			bool sign = dfs(depth + 1);
			if (!sign) {
				return false;
			}
			for (int j : G[x]) {
				if (deg[j] == 0) {
					st.pop_back();
				}
				++deg[j];
			}
			st.insert(st.begin() + i, x);
		}
		return true;
	};
	for (int i = 0; i < N; ++i) {
		if (deg[i] == 0) {
			st.push_back(i);
		}
	}
	dfs(0);
	if (answer_list.size() != K) {
		cout << -1 << endl;
	}
	else {
		for (vector<int> v : answer_list) {
			for (int i = 0; i < N; ++i) {
				if (i != 0) cout << ' ';
				cout << v[i] + 1;
			}
			cout << endl;
		}
	}
	return 0;
}
```
