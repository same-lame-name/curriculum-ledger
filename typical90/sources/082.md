# 082 — Counting the Number of Digits Written on the Blackboard

**Difficulty:** ★×3 (author's star rating)
**Link:** https://atcoder.jp/contests/typical90/tasks/typical90_cd
**Source:** AtCoder Typical90 #082 — official statement and samples; editorial essence distilled from the official Japanese slides.

## Statement (original Japanese)
何も書かれていない黒板があります。
x = L, L+1, ..., R の順に、以下の操作を行います。

・黒板に、整数 x を x 回書く。

全ての操作が終了した後、黒板に書かれている 文字 の個数を 10^9+7 で割った余りを求めてください。

ただし、数えるのは整数ではなく文字である事に注意してください。例えば、整数 15 は 2 個の文字として数えます。

## Statement (English translation)
There is a blank blackboard.
For x = L, L+1, ..., R in this order, perform the following operation:

- Write the integer x on the blackboard x times.

After all operations finish, find the number of characters written on the blackboard, modulo 10^9+7.

Note that we count characters, not integers. For example, the integer 15 counts as 2 characters.

## Constraints
・1 ≦ L ≦ R ≦ 10^18
・入力は全て整数

## Author's Editorial — Concept & Essence
- **Keyword (キーワード):** 部分問題に分解する／数列の和の公式 (Decompose into subproblems / formula for the sum of a sequence)
- **Core idea:** Split the count by digit-length. The answer is Σ (number of i-digit integers written) × i. Within each digit-length the integers form a contiguous arithmetic progression, so their sum is computed with the triangular-number formula, handled modulo 10^9+7 via modular inverse (or an overflow-safe parity split).
- **Editorial steps:**
  - まず、問題をそのままの形で解くのは難しいので、以下のように複数の小問題に分解して解いてみましょう。今回の場合、桁ごとに分解します。
  - 「1桁の整数」は何回書かれるか？(E₁)、「2桁の整数」は何回書かれるか？(E₂)、…、「19桁の整数」は何回書かれるか？(E₁₉) に分けます。
  - そのとき、書かれる文字数の合計 Answer は次の通り：Answer = Σ_{i=1}^{19} E_i · i = E₁ + 2E₂ + 3E₃ + … + 19E₁₉。
  - また、書かれる「i 桁の整数」は max(10^{i−1}, L) 以上 min(10^i − 1, R) 以下なので、もし範囲が存在すれば E_i = max(10^{i−1}, L) + … + min(10^i − 1, R) となります。
  - 次に、E_i の値はどう計算すれば良いでしょうか。実は以下の公式が使えます：f(N) = 1 + 2 + 3 + … + N = N(N+1)/2。
  - そして、E_i は max(10^{i−1}, L) から min(10^i − 1, R) の和であるため、E_i = f(min(10^i−1, R)) − f(max(10^{i−1}, L) − 1) となり、見簡単に計算できるように思います。
  - しかし、制約が R ≦ 10^18 と大きいため、単純に f(N) mod (10^9+7) の値を計算するとオーバーフロー (典型038) してしまいます。そこで 10^9+7 が素数であるという性質を生かして、以下の逆元 (典型015) を使いましょう。
  - mod p (p は素数) の世界では、a ÷ b は b·τ ≡ a (mod p) を満たす τ (0 ≦ τ < p) の値である。例えば 1 ÷ 3 = 2 (mod 5) である。また、81 ÷ 3 を 5 で割った余りは mod 5 上での (81 mod 5) ÷ (3 mod 5) の値と一致する。つまり f(N) = N(N+1)/2 の計算も逆元を生かして τ ≡ a · b^{p−2} (mod p) で計算できる。
  - 今回の場合、a = N(N+1) mod (10^9+7)、b = 2 を代入すれば良い。
  - なお、本問題では 10^18 というコーナーケース (典型033) があるため 19 桁の整数を扱う必要があり、long long 型ではオーバーフローします。したがって unsigned long long 型を使い、適切に場合分けする必要があります。
- **Complexity:** O(log R · log(10^9+7))（繰り返し二乗法による逆元計算を含む。082b.cpp の偶奇場合分け版は逆元不要）
- **Author's takeaway / typical pattern (典型):** いくつかの部分問題に分解してから等差数列の和の公式を使うと、本問題を計算量 O(log R · log(10^9+7)) で解くことができます。逆元を詳しく知りたい場合は記事「1000000007 で割ったあまりの求め方を総特集！」を参照。他にも以下の「数列の和」は頻出です：1²+2²+…+N² = N(N+1)(2N+1)/6、2⁰+2¹+…+2^{N−1} = 2^N − 1、1+p+p²+… = 1/(1−p) [0<p<1]。
- **Related problems (類題):**
  - ABC195-C「Comma」
  - ABC189-D「Staircase Sequence」
  - ABC194-D「Journey」
- **Flags:** none (editorial explicitly notes 082b.cpp as a parity-based alternative to avoid the modular inverse / overflow).

## Author's Reference Solution
`082a.cpp` — For each digit-length i, clamps the range [max(L,10^{i−1}), min(R,10^i−1)], sums it with f(X)=X(X+1)/2 using Fermat modular inverse, and accumulates i × sum.

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

long long mod = 1000000007;
unsigned long long L, R;
unsigned long long power10[22];

long long modpow(long long a, long long b, long long m) {
	long long p = 1, q = a;
	for (int i = 0; i < 30; i++) {
		if ((b & (1LL << i)) != 0) { p *= q; p %= m; }
		q *= q; q %= m;
	}
	return p;
}

long long Div(long long a, long long b, long long m) {
	// Get the value of a/b
	return (a * modpow(b, m - 2, m)) % m;
}

void init() {
	// Calculate 10^i
	power10[0] = 1;
	for (int i = 1; i <= 19; i++) power10[i] = (10ULL * power10[i - 1]);
}

long long f(long long X) {
	// Calculate 1 + 2 + ... + X mod 1000000007
	long long v1 = X % mod;
	long long v2 = (X + 1) % mod;
	long long v = v1 * v2 % mod;
	return Div(v, 2, mod);
}

int main() {
	// Step #1. Initialize / Input
	init();
	cin >> L >> R;

	// Step #2. Brute Force by Digit-Size
	long long Answer = 0;
	for (int i = 1; i <= 19; i++) {
		unsigned long long vl = max(L, power10[i - 1]);
		unsigned long long vr = min(R, power10[i] - 1ULL);
		if (vl > vr) continue;
		long long val = (f(vr) - f(vl - 1) + mod) % mod;
		Answer += 1LL * i * val;
		Answer %= mod;
	}

	// Step #3. Output The Answer
	cout << Answer << endl;
	return 0;
}
```

`082b.cpp` — Same digit-length decomposition, but computes f(X)=X(X+1)/2 by splitting on parity so that the division by 2 is exact, avoiding modular inverses entirely.

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

long long mod = 1000000007;
unsigned long long L, R;
unsigned long long power10[22];

void init() {
	// Calculate 10^i
	power10[0] = 1;
	for (int i = 1; i <= 19; i++) power10[i] = (10ULL * power10[i - 1]);
}

long long f(long long X) {
	if (X % 2LL == 0) {
		long long v1 = (X / 2LL) % mod;
		long long v2 = (X + 1LL) % mod;
		return v1 * v2 % mod;
	}
	else {
		long long v1 = ((X + 1LL) / 2LL) % mod;
		long long v2 = X % mod;
		return v1 * v2 % mod;
	}
}

int main() {
	// Step #1. Initialize / Input
	init();
	cin >> L >> R;

	// Step #2. Brute Force by Digit-Size
	long long Answer = 0;
	for (int i = 1; i <= 19; i++) {
		unsigned long long vl = max(L, power10[i - 1]);
		unsigned long long vr = min(R, power10[i] - 1ULL);
		if (vl > vr) continue;
		long long val = (f(vr) - f(vl - 1) + mod) % mod;
		Answer += 1LL * i * val;
		Answer %= mod;
	}

	// Step #3. Output The Answer
	cout << Answer << endl;
	return 0;
}
```
