# 004 — Cross Sum (Row and Column Sums)

**Difficulty:** ★×2 (author's star rating)
**Link:** https://atcoder.jp/contests/typical90/tasks/typical90_d
**Source:** AtCoder Typical90 #004 — official statement and samples; editorial essence distilled from the official Japanese slides.

## Statement (original Japanese)
```
H 行 W 列のマス目があります。上から i (1 ≦ i ≦ H) 行目、左から j (1 ≦ j ≦ W) 列目にあるマス (i, j) には、整数 A[i][j] が書かれています。

すべてのマス (i, j) [1 ≦ i ≦ H, 1 ≦ j ≦ W] について、以下の値を求めてください。
・マス (i, j) と同じ行または同じ列にあるマス（自分自身を含む）に書かれている整数をすべて合計した値
```

## Statement (English translation)
There is a grid with H rows and W columns. In the cell (i, j) at the i-th row from the top (1 ≦ i ≦ H) and the j-th column from the left (1 ≦ j ≦ W), an integer A[i][j] is written.

For every cell (i, j) [1 ≦ i ≦ H, 1 ≦ j ≦ W], find the following value.
・The value obtained by summing all integers written in the cells that are in the same row or the same column as cell (i, j) (including the cell itself)

## Constraints
```
【制約】
・1 ≦ H ≦ 2000
・1 ≦ W ≦ 2000
・1 ≦ A[i][j] ≦ 99
・入力はすべて整数
```

## Author's Editorial — Concept & Essence
- **Keyword (キーワード):** 扱いやすい形にして前計算しよう (reshape it into an easy-to-handle form and precompute)
- **Core idea:** Do not sum the H+W−1 cells of each cross directly. Split the cross into a vertical strip plus a horizontal strip minus the single centre cell, so the answer for (i, j) is Row_i + Column_j − A[i][j], where Row_i is the sum of row i and Column_j the sum of column j. Both are precomputed once in O(HW), after which every cell is O(1) and the whole grid is O(HW).
- **Editorial steps:**
  - **解法 1 (direct summation, TLE):** For each (i, j) the number of cells lying in the same row or the same column is H + W − 1, so summing them directly costs O(H + W) per cell. Since answers are needed for all HW cells, the total is O(HW(H + W)) and TLEs. General remark on judging feasibility: when the number of operations exceeds about 10^8〜10^9, it no longer fits the roughly 2-second time limit (※1) and becomes an incorrect answer (TLE); four alarm-clock icons illustrate the 2 seconds.
  - **解法 2 (decompose the cross):** Transform the shape into something easy to handle, as in the figure: cross = vertical strip + horizontal strip − one small square. Then the sum over the yellow part is obtainable in O(1) once three values are known: 「i 行目の合計」「j 列目の合計」「マス (i,j) の値」. So precompute Row_i = the sum of the integers written in row i, and Column_j = the sum of the integers written in column j, before computing the answers. Memorising in advance the values that are the key to the answer is called 前計算 or 前処理 (precomputation / preprocessing). The resulting formula, filled in by the reference code's Step #3, is Answer[i][j] = Row_i + Column_j − A[i][j].
- **Complexity:** 解法 1: O(HW(H + W)) → TLE. 解法 2: O(HW) in total, after an O(HW) precomputation pass (「全体計算量 O(HW) に高速化することができます」). Memory not stated on the slide.
- **Author's takeaway / typical pattern (典型):** Precomputation (前計算/前処理) turns an O(HW) per-cell recomputation into O(1) per cell. Supplement: expressing the union of two sets A and B by addition and subtraction, as in 解法 2, is called 包除原理 (inclusion–exclusion) and appears frequently in counting problems (※2: precisely, |A∪B| = |A| + |B| − |A∩B|).
- **Related problems (類題):** ABC129-D Lamp (前計算), ARC077-D 11 (包除原理)
- **Flags:** The "10^8〜10^9 operations ≈ 2 seconds" rule is a heuristic asserted without justification (※1 itself concedes limits range from 1 to 10 seconds), so it is a guideline, not a bound. The decomposition relies on the row part and the column part overlapping in exactly the cell (i, j); the slide draws this but does not argue that nothing else is double-counted — that is the claim to check, together with the boundary that A[i][j] must be subtracted exactly once.

## Author's Reference Solution
`004.cpp` — Precomputes the sums of each row and each column, sets each answer cell to `Row[i] + Column[j] - A[i][j]`, and prints the grid.

```cpp
#include <iostream>
using namespace std;
#pragma warning (disable: 4996)

int H, W;
int A[2009][2009];
int Row[2009], Column[2009];
int Answer[2009][2009];

int main() {
	// Step #1. 入力
	cin >> H >> W;
	for (int i = 1; i <= H; i++) {
		for (int j = 1; j <= W; j++) {
			scanf("%d", &A[i][j]);
		}
	}
	
	// Step #2. 前計算
	for (int i = 1; i <= H; i++) {
		for (int j = 1; j <= W; j++) {
			Row[i] += A[i][j];
			Column[j] += A[i][j];
		}
	}

	// Step #3. 答えの計算
	for (int i = 1; i <= H; i++) {
		for (int j = 1; j <= W; j++) {
			Answer[i][j] = Row[i] + Column[j] - A[i][j];
		}
	}

	// Step #4. 出力
	for (int i = 1; i <= H; i++) {
		for (int j = 1; j <= W; j++) {
			if (j >= 2) printf(" ");
			printf("%d", Answer[i][j]);
		}
		printf("\n");
	}
	return 0;
}
```
