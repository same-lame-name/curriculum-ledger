# 052 — Sum of products over all dice outcomes

**Difficulty:** ★×3 (author's star rating)
**Link:** https://atcoder.jp/contests/typical90/tasks/typical90_az
**Source:** AtCoder Typical90 #052 — official statement and samples; editorial essence distilled from the official Japanese slides.

## Statement (original Japanese)
N 個の 6 面体サイコロがあり、1, 2, 3, ..., N と番号付けられています。
サイコロ i の j (1 ≦ j ≦ 6) 番目の面には整数 A[i][j] が書かれています
ここで、それぞれのサイコロについて、書かれている整数は相異なります。

さて、サイコロの出目に対して、次のように得点を定義します。

	得点は N 個のサイコロの出目の総積である。
	つまり、サイコロ i の出目を R[i] としたとき、得点は R[1]×R[2]×⋯×R[N] と計算される。

N 個のサイコロの出目の結果としては 6^N 通り考えられますが、これら全てにおける得点の総和 S を 10^9+7 で割った余りを求めてください。
ただし、それぞれのサイコロは互いに区別できるものとします。

## Statement (English translation)
There are N six-faced dice, numbered 1, 2, 3, ..., N.
On the j-th face (1 ≦ j ≦ 6) of die i, the integer A[i][j] is written. Here, for each die, the integers written on it are distinct.

Now, for the outcomes of the dice, the score is defined as follows.

	The score is the product of the outcomes of the N dice.
	That is, letting R[i] be the outcome of die i, the score is computed as R[1]×R[2]×⋯×R[N].

There are 6^N possible outcomes of the N dice; find the sum S of the scores over all of them, modulo 10^9+7.
However, the dice are considered distinguishable from one another.

## Constraints
・1 ≦ N ≦ 100
・1 ≦ A[i][1] < A[i][2] < A[i][3] < A[i][4] < A[i][5] < A[i][6] ≦ 100
・入力はすべて整数である

## Author's Editorial — Concept & Essence
- **Keyword (キーワード):** 因数分解をしよう (factorize)
- **Core idea:** The sum over all 6^N outcomes of the product of outcomes factorizes: it equals the product over dice of the sum of that die's face values. Expanding the product ∏(A_{i,1}+…+A_{i,6}) distributes into exactly one term per die per outcome, i.e. every outcome's product, so the two expressions are equal.
- **Editorial steps:**
  - **解法 (Solution):** In fact, the answer can be computed as
    Answer = ∏_{i=1}^{N} (A_{i,1} + A_{i,2} + A_{i,3} + A_{i,4} + A_{i,5} + A_{i,6}).
    (Here ∏ b_i = b_1 × b_2 × ⋯ × b_N.) The sample program computes this directly.
  - **なぜそうなるか？ (Why is this so?):** For simplicity, consider N = 2 (considering small cases of a complex problem is an important typical technique). With A_1 = (1,2,4,5,6,8), A_2 = (2,4,5,8,9,12), the sum of products is (1+2+4+5+6+8) × (2+4+5+8+9+12) = 26 × 40 = 1040. In the same way, for N ≥ 3 the answer is obtained by factorizing similarly.
  - (Diagram: a 6×6 table of A_1 × A_2 products; e.g. 2 appears in one cell, 4 appears in two cells, etc.; the sum of all cells equals the product of the two row/column sums.)
- **Complexity:** O(N) — by factorizing the answer expression appropriately, it can be solved in O(N).
- **Author's takeaway / typical pattern (典型):** The factorization technique can also be applied to formulas for the number of divisors / the sum of divisors, so it is worth knowing. Moreover, not only "factorizing the answer directly", but also the technique of "factorizing the condition and computing" is used in some situations.

## Author's Reference Solution
`052.cpp` — multiply the sum of each die's six faces, taking the product modulo 10^9+7.

```cpp
#include <iostream>
using namespace std;

long long mod = 1000000007;
long long N, A[1009][8], Answer = 1;

int main() {
	// Step #1. 入力
	cin >> N;
	for (int i = 1; i <= N; i++) {
		for (int j = 1; j <= 6; j++) cin >> A[i][j];
	}
	
	// Step #2. 答えを求める
	for (int i = 1; i <= N; i++) {
		Answer *= (A[i][1] + A[i][2] + A[i][3] + A[i][4] + A[i][5] + A[i][6]);
		Answer %= mod;
	}
	cout << Answer << endl;
	return 0;
}
```
