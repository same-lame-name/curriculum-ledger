# 025 — Count m in [1, N] with m − f(m) = B

**Difficulty:** ★×7 (author's star rating)
**Link:** https://atcoder.jp/contests/typical90/tasks/typical90_y
**Source:** AtCoder Typical90 #025 — official statement and samples; editorial essence distilled from the official Japanese slides.

## Statement (original Japanese)
関数 f(x) を次のように定義します。
・f(x) = [x の各位の数字の積]
例えば、f(777)=343、f(8691)=432、f(869120)=0 です。

整数 N と B が与えられるので、1 以上 N 以下の整数 m の中で m - f(m) = B となるものの個数を求めてください。

## Statement (English translation)
Define the function f(x) as follows.
・f(x) = [the product of the digits of x]
For example, f(777) = 343, f(8691) = 432, and f(869120) = 0.

Given integers N and B, find the number of integers m with 1 ≦ m ≦ N such that m − f(m) = B.

## Constraints
・1 ≦ N < 10^11
・1 ≦ B < 10^11
・入力はすべて整数

## Author's Editorial — Concept & Essence
- **Keyword (キーワード):** まとめて考える探索／複雑な構造の全探索は再帰関数
- **Core idea:** f(x) depends only on the multiset of digits of x, so all numbers that are permutations of the same digits share one f value. It therefore suffices to enumerate only the digit strings sorted in non-decreasing order. For each such string S, m must equal B + f(S); if the digits of that value sort to S and it is ≤ N, it is a solution. A recursive function enumerates these sorted digit strings.
- **Editorial steps:**
  - A naive scan over x = 1, 2, …, N TLEs, because the constraint is N < 10^11 (about 10^11 ≈ O(√N) is not enough either). But there is no need for a mathematical trick.
  - Search by grouping: it is fine to consider equal values of f(x) together. The following property holds: numbers that are permutations of one another when their digits are sorted (e.g. 427 and 247) have the same f(x) value, so they can be considered together.
  - Therefore it is enough to enumerate the digit strings S obtained by sorting digits. Then an integer T satisfying f(S) + B = T is a solution exactly when T is a permutation of S.
  - The number of strings S is the number of combinations with repetition, about C(20, 10), so there is ample time.
  - But how to enumerate all S? Because the structure is complicated, `for` loops / bit exhaustive search / `next_permutation` cannot implement it; in such a case use a recursive function. Example implementation:
    ```cpp
    void dfs(string str, int nex) {
        if (str.size() == 11) { /* 省略 */ return; }
        for (int i = nex; i <= 9; i++) {
            string str2 = str; str2 += ('0' + i);
            dfs(str2, i);
        }
    }
    ```
  - Also learn the functions `stoi` / `stoll` that convert strings to integers.
- **Complexity:** About C(20, 10) strings (≈ 184756), so the running time is comfortable.
- **Author's takeaway / typical pattern (典型):** Searching by grouping values that share the same answer / function value speeds things up, and a recursive implementation leads to a correct solution. (The problem can be extended to N, B < 10^50 using multiple-precision arithmetic.)
- **Related problems (類題):**
  - PANASONIC2020-D 「String Equivalence」 (再帰関数)
  - ABC196-D 「Hanjo」 (再帰関数)
  - AOJ 1360 「Bringing Order to Disorder」 (まとめて全探索)
- **Flags:** none.

## Author's Reference Solution
`025.cpp` — recursively enumerate non-increasing digit strings (digits 9 down to 1) of lengths 1..11; for each, compute the product `rem` and `goal = rem + B`; if `goal ≤ N` and the digits of `goal` sorted in descending order equal the enumerated string, count it. A final special case adds 1 if B contains a '0' and N ≥ B (numbers containing a zero digit, whose f is 0 and which therefore equal B).

```cpp
#include <iostream>
#include <string>
#include <algorithm>
using namespace std;

long long N, B;
long long Answer = 0;

void dfs(int pos, int last, string str) {
	if (pos == 0) {
		long long rem = 1;
		for (int i = 0; i < str.size(); i++) rem *= (long long)(str[i] - '0');
		long long goal = rem + B;
		if (goal <= N) {
			string goal_str = to_string(goal);
			sort(goal_str.begin(), goal_str.end());
			reverse(goal_str.begin(), goal_str.end());
			if (goal_str == str) {
				Answer += 1;
			}
		}
		return;
	}

	for (int i = last; i >= 1; i--) {
		string str2 = str;
		str2 += ('0' + i);
		dfs(pos - 1, i, str2);
	}
}

int main() {
	cin >> N >> B;
	for (int i = 1; i <= 11; i++) {
		dfs(i, 9, "");
	}

	string V = to_string(B);
	bool flag = false;
	for (int i = 0; i < V.size(); i++) {
		if (V[i] == '0') flag = true;
	}
	if (flag == true && N >= B) Answer += 1;

	cout << Answer << endl;
	return 0;
}
```
