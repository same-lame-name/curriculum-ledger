## Statement (English translation)
N airplanes are navigating the sky, which can be regarded as a two-dimensional coordinate plane.
For i=1,2,...,N, the i-th airplane was at coordinates (AX[i],AY[i]) at time 0.

Every airplane is navigating facing one of the directions 1,2,3,4,5,6,7,8.
An airplane at (x,y) facing direction d at time t is, at time t+1,
・if d=1, at (x+1,y)
・if d=2, at (x+1,y+1)
・if d=3, at (x,y+1)
・if d=4, at (x-1,y+1)
・if d=5, at (x-1,y)
・if d=6, at (x-1,y-1)
・if d=7, at (x,y-1)
・if d=8, at (x+1,y-1).
Also, no airplane changes direction while navigating.

You received the following report from the air traffic controller Takahashi-kun.

・At time T, airplanes were present at the coordinates (BX[1],BY[1]),(BX[2],BY[2]),...,(BX[N],BY[N])

Determine whether there exists a combination of the directions of the N airplanes that does not contradict his report, and if it exists, output one such combination.

## Author's Editorial — Concept & Essence
- **Keyword (キーワード):** P1: 8 進数で bit 全探索 (bit brute force in base 8). P2: 関係性をグラフとして考える (think of the relationships as a graph). P3: 二部マッチングを知っていますか？ (do you know bipartite matching?).
- **Core idea:** An assignment of directions is valid iff the multiset of positions `{A_i + T·(dx,dy)}` equals the reported multiset `{B_j}`. P1 brute-forces all `8^N` direction vectors and compares the two multisets by sorting (subtask 1, `N ≦ 6`). P2 abstracts the assignment structure into a bipartite graph with N red vertices (planes) and N blue vertices (reported positions) and an edge when some direction can carry plane i to position j; in the special case `AY = BY = 0` each component is path-shaped and the answer is Yes exactly when every component has equally many red and blue vertices (subtask 2). P3 observes that the graph problem is nothing but **二部グラフの最大マッチング**, so the general case is solved by max flow (subtask 3 with Ford–Fulkerson `O(N²)`, full marks with Dinic `O(N√N)`).
- **Editorial steps:**
  - **P1 (subtask 1, `O(8^N · N log N)`) — brute force over base-8 numbers:** `N ≦ 6` means at most `8^6 = 8×8×8×8×8×8 = 262144` direction combinations, so enumerate all of them. Implementation: apply ビット全探索 (→典型 002) in base 8 — loop `i = 0, 1, 2, …, 8^N − 1`, write i in base 8 (→典型 067) and let `d[j]` be the j-th digit from the bottom; the direction of plane j is `d[j] + 1`. Example: `(N, i) = (3, 253)`; since `253_(10) = 375_(8)`, `(d[1], d[2], d[3]) = (5, 7, 3)` and the directions of planes 1, 2, 3 are `(6, 8, 4)`. Once the directions are fixed, compute `(p_i, q_i)` = position of plane i after T seconds and check whether the multisets `R = {(p_1,q_1), …, (p_N,q_N)}` and `S = {(BX_1,BY_1), …, (BX_N,BY_N)}` agree. Options listed for the comparison: `std::map` (→典型 027), `std::multiset`, or sort both and compare element by element — the last is shown as `bool check(vector<pair<int,int>> R, vector<pair<int,int>> S) { sort(R.begin(), R.end()); sort(S.begin(), S.end()); for (int i = 0; i < R.size(); i++) if (R[i] != S[i]) return false; return true; }`. The slide stresses that the method is not efficient: with `N = 1000` there would be `8^1000 ≒ 10^903` patterns (「莫大な時間がかかってしまいます」), and notes that bit brute force is not restricted to binary — it extends to base 3 and higher.
  - **P2 (subtask 2, `AY = BY = 0`) — graph of possible assignments:** prepare N red and N blue vertices, numbered (red-1)…(red-N) and (blue-1)…(blue-N). Add an edge between (red-i) and (blue-j) when, exactly T seconds later, plane i cannot be said to definitely not be at position j — i.e. when some direction realises `(AX_i, AY_i) + T·(dx,dy) = (BX_j, BY_j)`. When all y-coordinates are 0 a plane can only move in the +x or −x direction, so each connected component of this graph is path-shaped. Then the condition for being able to assign every plane inside a component is 「連結成分に含まれる赤頂点と青頂点の個数が同じ」; if this holds for every component the answer is Yes. The two pictures show a ○ component where all planes can be assigned (3 red − 3 blue) and a × component where exactly one vertex must be left over (5 red − 4 blue). Implementation: DFS (→典型 026) counts red/blue vertices per component, and assigning greedily from the degree-1 vertices also yields an explicit configuration. Edges: memoise, for each reported coordinate, the index of the position at time T in `std::map` (→典型 027); then the indices of `(AX_i − T, 0)` and `(AX_i + T, 0)` are found in `O(log N)`, so the whole graph is built in `O(N log N)`. The figure is captioned 「T = 7 の場合の例」 and shows seven red vertices in a row above seven blue vertices, edges drawn only between vertices whose x-coordinates differ by exactly T, forming alternating zig-zag paths.
  - **P3 (full solution) — the reduction to bipartite matching:** 「実は、小課題 2 のようにグラフの問題に落とし込むと、解くべき問題は以下の「二部グラフの最大マッチング問題」になっています」 — 「同じ頂点を二度通らない時、最大で何個の（辺で直接結ばれた）ペアができるか？（最大 N 個の場合、この問題の答えは Yes となる）」. Worked example: `(AX_i, AY_i) = (0,2), (0,0), (2,0)`, `(BX_i, BY_i) = (0,1), (1,0), (1,1)`, `T = 1`; the drawn graph admits the pairing 1–3, 2–1, 3–2, which contains every vertex, so the answer is Yes.
  - **P3 (max flow):** transform the bipartite graph by adding a source `s` with capacity-1 edges to all red vertices, a sink `g` with capacity-1 edges from all blue vertices, and the existing bipartite edges (「辺の重みは全部 1」). The number of vertices is `O(N)` and the number of edges `O(N)`, so: **Ford–Fulkerson 法: `O(N²)`** passes subtasks up to 3 (`N ≦ 1000`), while **Dinic 法: `O(N√N)`** passes `N ≦ 20000`, i.e. subtask 4 (full marks). 「一見定数倍が厳しいように思えるかもしれませんが、ACL の MaxFlow を使えば爆速で、407ms で通ります」. Answer reconstruction: after sending the max flow, inspect which edges were used.
- **Complexity:** P1: `O(8^N · N log N)`. P2: `O(N log N)` to build the graph (plus an `O(N)` DFS). P3: `O(N²)` with Ford–Fulkerson and `O(N√N)` with Dinic; the right column states the overall `O(N√N)` for the full solution. Memory not stated on the slides.
- **Author's takeaway / typical pattern (典型):** P2's lesson — 「考察がすぐに見えにくい場合でも、モノとモノの関係性をグラフとして表すことで、一気に考察が見えやすくなる」. P3's lesson — knowing 二部マッチング (and its max-flow reduction) turns an assignment problem into a standard one; matching is useful outside contests too (truck delivery planning, employee shift assignment, social distancing optimisation), and the related topics 最小カット・最小費用流 are also famous.
- **Related problems (類題):** ARC092-C「2D Plane 2N Points」, SoundHound 2018 予選C「広告」, ABC205-F「Grid and Tokens」, ACL Contest 1-C「Moving Pieces」
- **Flags:** (1) P2's per-component "equal red and blue counts ⇒ Yes" is argued only for path-shaped components; the slide neither proves that a path component with equal counts admits a perfect matching (that is where the degree-1 greedy comes in) nor warns that equal counts are *not* sufficient for a general bipartite graph. (2) P2 asserts that components are paths because only ±x moves are possible when `AY = BY = 0`; it does not say why the bipartite graph is a subgraph of a line (each red has at most 2 candidate blues, `AX ± T`, and each blue at most 2 candidate reds) and hence can contain no cycle. (3) P2's edge rule is stated as a double negative (「絶対存在できないとはいえない場合」); the slide never says explicitly that there are exactly 8 candidate destinations per plane and that the edge set is exactly the possible (plane, position) pairs — the natural reading. (4) P3 never derives `O(N√N)`: it is Dinic's bound for unit-capacity networks with `O(N)` vertices and edges, quoted rather than proved; the 407 ms figure is an ACL-specific measurement. (5) P3 states `O(N²)` for Ford–Fulkerson and says it reaches subtask 3 (`N ≦ 1000`), but never mentions that the augmenting-path search has to be restarted up to N times. (6) Boundaries to test: a plane whose T-step in every direction lands outside the reported set (isolated red vertex ⇒ matching < N ⇒ No), duplicate reported positions (excluded by the statement), `T = 1` with `N = 1`, and coordinates where `AX_i ± T` has many candidates (bipartite degree > 2), which is exactly where P2's path argument stops applying.

## Author's Reference Solution
- `077-01.cpp` — Tries all 8^N assignments of directions and checks whether the resulting set of destinations equals the reported set of positions.
- `077-02.cpp` — For the case where every y-coordinate is 0, links the airplanes whose x-coordinates differ by T and checks each connected component, writing direction 1 or 5.
- `077-03.cpp` — Builds a bipartite graph between airplanes and reported positions and tests for a perfect matching with the Ford–Fulkerson algorithm.
- `077-04a.cpp` — Builds the same bipartite graph and computes a maximum flow with Dinic's algorithm.

```cpp
#include <iostream>
#include <vector>
#include <cassert>
#include <algorithm>
using namespace std;

int N, T;
int AX[1 << 18], AY[1 << 18];
int BX[1 << 18], BY[1 << 18];
int power8[12];
int dx[8] = { 1, 1, 0, -1, -1, -1, 0, 1 };
int dy[8] = { 0, 1, 1, 1, 0, -1, -1, -1 };

bool check(vector<pair<int, int>> R, vector<pair<int, int>> S) {
	sort(R.begin(), R.end());
	sort(S.begin(), S.end());
	if (R == S) return true;
	return false;
}

int main() {
	// Step #1. Input
	cin >> N >> T;
	for (int i = 1; i <= N; i++) cin >> AX[i] >> AY[i];
	for (int i = 1; i <= N; i++) cin >> BX[i] >> BY[i];
	assert(N <= 6);

	// Step #2. Bit Zentansaku
	power8[0] = 1;
	for (int i = 1; i <= 11; i++) power8[i] = 8 * power8[i - 1];
	for (int i = 0; i < power8[N]; i++) {
		int bit[12];
		for (int j = 0; j < N; j++) bit[j + 1] = (i / power8[j]) % 8;

		vector<pair<int, int>> R, S;
		for (int j = 1; j <= N; j++) {
			int p = AX[j] + dx[bit[j]] * T;
			int q = AY[j] + dy[bit[j]] * T;
			S.push_back(make_pair(p, q));
			R.push_back(make_pair(BX[j], BY[j]));
		}
		if (check(R, S) == true) {
			cout << "Yes" << endl;
			for (int j = 1; j <= N; j++) {
				if (j >= 2) cout << " ";
				cout << bit[j] + 1;
			}
			cout << endl;
			return 0;
		}
	}

	cout << "No" << endl;
	return 0;
}
```

```cpp
#include <iostream>
#include <vector>
#include <map>
#include <cassert>
using namespace std;

int N, T;
int AX[1 << 18], AY[1 << 18];
int BX[1 << 18], BY[1 << 18];
int Answer[1 << 18], cnta, cntb;
bool used[1 << 18];
vector<int> G[1 << 18];
map<int, int> Map;

void dfs(int pos, int pre) {
	used[pos] = true;
	if (pos <= N) cnta++;
	if (pos > N) {
		cntb++;
		if (AX[pre] < BX[pos - N]) Answer[pre] = 1;
		if (AX[pre] > BX[pos - N]) Answer[pre] = 5;
	}
	for (int i : G[pos]) {
		if (used[i] == true) continue;
		dfs(i, pos);
	}
}

int main() {
	// Step #1. Input
	cin >> N >> T;
	for (int i = 1; i <= N; i++) cin >> AX[i] >> AY[i];
	for (int i = 1; i <= N; i++) cin >> BX[i] >> BY[i];
	for (int i = 1; i <= N; i++) Map[BX[i]] = i;
	for (int i = 1; i <= N; i++) assert(AY[i] == 0);
	for (int i = 1; i <= N; i++) assert(BY[i] == 0);

	// Step #2. Make Graph
	for (int i = 1; i <= N; i++) {
		int idx1 = Map[AX[i] - T];
		int idx2 = Map[AX[i] + T];
		if (idx1 != 0) { G[i].push_back(idx1 + N); G[idx1 + N].push_back(i); }
		if (idx2 != 0) { G[i].push_back(idx2 + N); G[idx2 + N].push_back(i); }
	}

	// Step #3. DFS
	for (int i = 1; i <= N; i++) {
		if (G[i].size() >= 2 || used[i] == true) continue;
		cnta = 0; cntb = 0;
		dfs(i, -1);
		if (cnta != cntb) {
			cout << "No" << endl;
			return 0;
		}
	}

	// Step #4. Output
	cout << "Yes" << endl;
	for (int i = 1; i <= N; i++) {
		if (i >= 2) cout << " ";
		cout << Answer[i];
	}
	cout << endl;
	return 0;
}
```

```cpp
#include <iostream>
#include <map>
#include <vector>
#include <algorithm>
using namespace std;

struct Edge {
	int to, cap, rev;
};

class Ford_Fulkerson {
public:
	int size_ = 1;
	bool used[1 << 18];
	vector<Edge> G[1 << 18];

	void init(int sz) {
		size_ = sz;
	}
	void add_edge(int u, int v, int c) {
		G[u].push_back(Edge{ v, c, (int)G[v].size() });
		G[v].push_back(Edge{ u, 0, (int)G[u].size() - 1 });
	}
	int dfs(int pos, int to, int f) {
		if (pos == to) return f;
		used[pos] = true;
		for (int i = 0; i < G[pos].size(); i++) {
			if (used[G[pos][i].to] == true || G[pos][i].cap == 0) continue;
			int z = dfs(G[pos][i].to, to, min(f, G[pos][i].cap));
			if (z != 0) {
				G[pos][i].cap -= z;
				G[G[pos][i].to][G[pos][i].rev].cap += z;
				return z;
			}
		}
		return 0;
	}
	int max_flow(int s, int t) {
		int ret = 0;
		while (true) {
			for (int i = 0; i <= size_; i++) used[i] = false;
			int f = dfs(s, t, 1000000007);
			if (f == 0) break;
			ret += f;
		}
		return ret;
	}
};

int N, T;
int AX[1 << 18], AY[1 << 18];
int BX[1 << 18], BY[1 << 18];
int dx[8] = { 1, 1, 0, -1, -1, -1, 0, 1 };
int dy[8] = { 0, 1, 1, 1, 0, -1, -1, -1 };

map<pair<int, int>, int> Map;
int Nex[1 << 18][8];
int Answer[1 << 18];
Ford_Fulkerson Z;

int main() {
	// Step #1. Input
	cin >> N >> T;
	for (int i = 1; i <= N; i++) cin >> AX[i] >> AY[i];
	for (int i = 1; i <= N; i++) cin >> BX[i] >> BY[i];
	for (int i = 1; i <= N; i++) Map[make_pair(BX[i], BY[i])] = i;

	// Step #2. Add Edge
	Z.init(2 * N + 5);
	for (int i = 1; i <= N; i++) {
		for (int j = 0; j < 8; j++) {
			int tx = AX[i] + dx[j] * T;
			int ty = AY[i] + dy[j] * T;
			Nex[i][j] = Map[make_pair(tx, ty)];
			if (Nex[i][j] != 0) {
				Z.add_edge(i, N + Nex[i][j], 1);
			}
		}
	}
	for (int i = 1; i <= N; i++) Z.add_edge(2 * N + 1, i, 1);
	for (int i = 1; i <= N; i++) Z.add_edge(i + N, 2 * N + 2, 1);

	// Step #3. Max Flow
	int res = Z.max_flow(2 * N + 1, 2 * N + 2);
	if (res != N) {
		cout << "No" << endl;
		return 0;
	}

	// Step #4. Get Answer
	for (int i = 1; i <= N; i++) {
		for (int j = 0; j < Z.G[i].size(); j++) {
			if (Z.G[i][j].to > 2 * N || Z.G[i][j].cap == 1) continue;
			for (int k = 0; k < 8; k++) {
				if (Nex[i][k] == Z.G[i][j].to - N) Answer[i] = k + 1;
			}
		}
	}

	// Step #5. Output
	cout << "Yes" << endl;
	for (int i = 1; i <= N; i++) {
		if (i >= 2) cout << " ";
		cout << Answer[i];
	}
	cout << endl;
	return 0;
}
```

```cpp
#include <iostream>
#include <map>
#include <queue>
#include <vector>
#include <algorithm>
using namespace std;
#pragma warning (disable: 4996)

struct Edge {
	int to, cap, rev;
};

class Dinic {
public:
	int size_ = 1;
	int level[1 << 18];
	int iter[1 << 18];
	vector<Edge> G[1 << 18];

	void init(int sz) {
		size_ = sz;
	}
	void add_edge(int u, int v, int c) {
		G[u].push_back(Edge{ v, c, (int)G[v].size() });
		G[v].push_back(Edge{ u, 0, (int)G[u].size() - 1 });
	}
	void bfs(int s) {
		for (int i = 0; i <= size_; i++) level[i] = -1;
		queue<int> Q;
		Q.push(s); level[s] = 0;
		while (!Q.empty()) {
			int pos = Q.front(); Q.pop();
			for (int i = 0; i < G[pos].size(); i++) {
				if (G[pos][i].cap == 0 || level[G[pos][i].to] != -1) continue;
				Q.push(G[pos][i].to);
				level[G[pos][i].to] = level[pos] + 1;
			}
		}
	}
	int dfs(int pos, int to, int f) {
		if (pos == to) return f;

		for (int& i = iter[pos]; i < G[pos].size(); i++) {
			if (G[pos][i].cap > 0 && level[pos] < level[G[pos][i].to]) {
				int z = dfs(G[pos][i].to, to, min(f, G[pos][i].cap));
				if (z > 0) {
					G[pos][i].cap -= z;
					G[G[pos][i].to][G[pos][i].rev].cap += z;
					return z;
				}
			}
		}
		return 0;
	}
	int max_flow(int s, int t) {
		int ret = 0;
		while (true) {
			bfs(s);
			if (level[t] == -1) break;
			for (int i = 0; i <= size_; i++) iter[i] = 0;
			while (true) {
				int f = dfs(s, t, 1000000007); if (f == 0) break;
				ret += f;
			}
		}
		return ret;
	}
};

int N, T;
int AX[1 << 18], AY[1 << 18];
int BX[1 << 18], BY[1 << 18];
```
