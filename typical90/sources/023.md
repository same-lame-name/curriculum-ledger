# 023 — Counting Non-Attacking King Placements on a Grid

**Difficulty:** ★×7 (author's star rating)
**Link:** https://atcoder.jp/contests/typical90/tasks/typical90_w
**Source:** AtCoder Typical90 #023 — official statement and samples; editorial essence distilled from the official Japanese slides.

## Statement (original Japanese)
縦 H マス、横 W マスからなるグリッドがあり、上から i 番目・左から j 番目のマスを (i, j) で表します。
各マスには色が塗られており、マス (i, j) の色は C[i][j] = '#' のとき黒、C[i][j] = '.' のとき白です。

あなたはいくつかの白マスを選び（1 つも選ばなくても良い）、キングの駒を置きます。
キング同士が互いに攻撃し合わないような置き方の数を 10^9+7 で割った余りを求めてください。
ただし、ある 2 つの置き方が異なるとは、「ある白マスが存在して、片方ではキングが置かれており、もう片方では置かれていない」ことを言います。

＜キング同士が互いに攻撃し合わない、とは＞
・キングが置かれている任意の異なる 2 マス (i, j) および (k, l) において、|i-k|>1 または |j-l|>1 が成り立つことを言います。

## Statement (English translation)
There is a grid with H rows and W columns, and the cell at the i-th row from the top and j-th column from the left is denoted (i, j).
Each cell is colored: cell (i, j) is black when C[i][j] = '#', and white when C[i][j] = '.'.

You choose some white cells (possibly none) and place king pieces on them.
Find the number of placements in which no two kings attack each other, modulo 10^9+7.
Two placements are considered different when "there is a white cell that has a king in one placement and no king in the other."

<What it means for kings not to attack each other>
・For any two distinct cells (i, j) and (k, l) on which kings are placed, |i−k| > 1 or |j−l| > 1 holds.

## Constraints
・1 ≦ H, W ≦ 24
・H, W は整数
・C[i][j] は '#' または '.'
・少なくとも 1 つの白マスが存在する

【小課題】
1. (1 点) 1 ≦ H, W ≦ 4
2. (1 点) 1 ≦ H, W ≦ 9
3. (2 点) 1 ≦ H, W ≦ 17
4. (3 点) 追加の制約はない

## Author's Editorial — Concept & Essence
The editorial develops four increasingly refined approaches, one per subtask.

### P1 — 小課題 1
- **Keyword (キーワード):** 小さい制約は bit 全探索
- **Core idea:** For H, W ≤ 4, brute force is fine. Number the HW cells and treat each cell as a binary choice (king / no king); there are 2^(HW) = 65536 placements for 4×4. Enumerate all of them with bit exhaustive search and test validity.
- **Editorial steps:**
  - For 小課題 1 the constraint H, W ≤ 4 is very small, so we can simply search all placements.
  - Assign numbers 0 … HW−1 to the cells. Each cell has 2 choices (place / not place), so there are 2^(HW) ways (2^16 = 65536 for 4×4).
  - Loop i = 0, 1, 2, …, 2^(HW)−1; for each i set the state of the cells so that the j-th bit (0 ≤ j ≤ HW−1) being 0 means no king on cell j, and otherwise place a king. Example: i = 21 = 10101₂, and i = 1048 = 10000011000₂.
  - Judge validity of each placement in O(HW), giving total complexity O(2^(HW) × HW).
- **Complexity:** O(2^(HW) × HW)
- **Author's takeaway / typical pattern (典型):** Bit exhaustive search handles tiny constraints; but for H, W ≤ 9 the same method would need about 2^81 × 81 ≈ 10^26 operations, so a faster method is required.
- **Related problems (類題):** ABC190-C 「Bowls and Dishes」, ABC196-D 「Hanjo」

### P2 — 小課題 2
- **Keyword (キーワード):** ビット DP で高速化
- **Core idea:** Decide the board state row by row. Whether a placement is realizable depends only on the previous row, so keep dp[row][state of previous row] = number of ways. Transitions try every placement of the current row (2^W of them).
- **Editorial steps:**
  - Consider deciding the board state one row at a time. Then the following property holds: whether a placement is realizable can be decided from the previous single row alone — no matter what happened two or more rows earlier, the previous row determines it.
  - Define dp[which row][state of previous 1 row] = number of ways. The DP transition tries all placements of the next row, so there are 2^W transitions. Total complexity O(H × 4^W).
  - When implementing, it is convenient to record the previous row's state as a binary (bit) number; this technique is called bit DP. Example: "2¹ = 2 so record 2", "2¹ + 2² + 2³ = 14 so record 14", "nothing placed so record 0".
- **Complexity:** O(H × 4^W)
- **Author's takeaway / typical pattern (典型):** Bit DP speeds things up; but for H, W ≤ 17 the method needs about 4^17 × 17 ≈ 10^11 operations, so a faster method is required.
- **Related problems (類題):** s8pc #1 G 「Revenge of Traveling Salesman Problem」, JOI 2017 予選4 「ぬいぐるみの整理」

### P3 — 小課題 3
- **Keyword (キーワード):** DP の遷移を細かくする
- **Core idea:** Instead of deciding a whole row at once, decide one cell at a time from the top-left. When deciding a cell, the only relevant earlier cells are the most recent W+1 cells (its upper-left neighbourhood). Keep dp[next cell number][state of the previous W+1 cells].
- **Editorial steps:**
  - Deciding a row at a time makes the computation large, so decide cell by cell from the top-left. When deciding whether to place a king at a cell, the cells that matter are the W+1 most recently processed cells (numbered from the top-left).
  - Define dp[next cell number][state of the previous W+1 cells] = number of ways. Record the previous W+1 cells' state as a binary bit DP: e.g., if the next cell number is 10 and the previous W+1 = 5 cells' state from the top is (0, 0, 1, 0, 1) (0-indexed), then because the 2nd and 4th bits are 1, 2² + 2⁴ = 20, so this state is recorded as dp[10][20].
  - The state transition is whether or not to place a king on the cell: dp[pos][mask] → dp[pos+1][⌊mask/2⌋] (do not place) and dp[pos][mask] → dp[pos+1][⌊mask/2⌋ + 2^W] (place). There are O(2^W × HW) states and O(1) transition each, so O(2^W × HW).
- **Complexity:** O(2^W × HW)
- **Author's takeaway / typical pattern (典型):** Refining the DP transition from "per row" to "per cell" gives O(2^W × HW); but for H, W ≤ 24 this would TLE or even MLE, so further speed-up is needed.
- **Related problems (類題):** Yukicoder #611 「Day of the Mountain」, 蟻本 p.177 「ドミノ敷き詰め」

### P4 — 小課題 4
- **Keyword (キーワード):** 不要な状態を削る
- **Core idea:** In the per-cell DP most of the 2^W states are impossible, because two adjacent 1s can never occur. The number of valid states is fib(W) = O(1.62^W); enumerate only those states and transition between them.
- **Editorial steps:**
  - 小課題 3 has many unnecessary states, e.g. dp[8][26] and dp[15][23], which are invalid (0 ways): two horizontally adjacent 1s can never be a placement.
  - Concretely, writing fib(N) for the N-th Fibonacci number, the number of "possible states" is only about fib(W) = O(1.62^W). The reason is that the number of length-W 0/1 strings with no two consecutive 1s is fib(W); for W = 24, over 99% of states are unnecessary. 2^W = 16,777,216 ways drop by 99% to fib(W) = under 200,000.
  - Number the attainable states 0, 1, 2, … and consider dp[next cell number][state number] = number of ways. Whether to transition to the next state cannot be computed by a simple formula, but the transition destination can be precomputed, giving total complexity O(fib(W) × HW).
- **Complexity:** O(fib(W) × HW) = O(1.62^W × HW)
- **Author's takeaway / typical pattern (典型):** Excluding "states that can never occur" and implementing only the valid states solves the problem in O(1.62^W × HW). (Estimating Fibonacci numbers is hard; see 「アルゴリズム・AtCoder のための数学」 3-4 節.)
- **Related problems (類題):** JOI 2011 予選6 「JOI 旗」
- **Flags:** none; each subtask is fully specified.

## Author's Reference Solution
- `023-01.cpp` — Subtask 1: DFS over cells in raster order, trying "don't place" and "place if allowed" (checks the 8 neighbours of the current cell); counts all valid placements.
- `023-02.cpp` — Subtask 2: row-by-row bit DP `dp[i][j]`, enumerating the previous row `j` and the current row `k` and checking all adjacency constraints.
- `023-03.cpp` — Subtask 3: cell-by-cell DP `dp[i][j][mask]` with a W+1 bit window, shifting the mask and optionally setting the top bit.
- `023-04a.cpp` — Subtask 4: precomputes the reachable states (strings with no two adjacent 1s) via DFS and uses a map from state string to index, then DP over valid states.
- `023-04b.cpp` — Subtask 4 (integer version): same as 04a but encodes states as integers instead of strings.

```cpp
// 023-01.cpp
#include <iostream>
using namespace std;

int H, W;
char c[25][25];
bool used[25][25];

bool hantei(int sx, int sy) {
	int dx[8] = { -1, -1, -1, 0, 1, 1, 1, 0 };
	int dy[8] = { -1, 0, 1, 1, 1, 0, -1, -1 };
	for (int i = 0; i < 8; i++) {
		int tx = sx + dx[i];
		int ty = sy + dy[i];
		if (tx < 0 || ty < 0 || tx >= H || ty >= W) continue;
		if (used[tx][ty] == true) return false;
	}
	return true;
}

int dfs(int sx, int sy) {
	if (sx == H) return 1;

	int nx = sx, ny = sy + 1;
	if (ny == W) { nx += 1; ny = 0; }

	int ret1 = dfs(nx, ny);
	int ret2 = 0;
	if (hantei(sx, sy) == true && c[sx][sy] == '.') {
		used[sx][sy] = true;
		ret2 = dfs(nx, ny);
		used[sx][sy] = false;
	}
	return ret1 + ret2;
}

int main() {
	// Step #1. Input
	cin >> H >> W;
	for (int i = 0; i < H; i++) {
		for (int j = 0; j < W; j++) cin >> c[i][j];
	}

	// Step #2. DFS
	int Answer = dfs(0, 0);
	cout << Answer << endl;
	return 0;
}
```

```cpp
// 023-02.cpp
#include <iostream>
using namespace std;

long long H, W;
long long dp[25][1 << 11];
long long mod = 1000000007;
char c[25][25];

int main() {
	// Step #1. Input
	cin >> H >> W;
	for (int i = 0; i < H; i++) {
		for (int j = 0; j < W; j++) cin >> c[i][j];
	}

	// Step #2. DP
	dp[0][0] = 1;
	for (int i = 0; i < H; i++) {
		for (int j = 0; j < (1 << W); j++) {
			if (dp[i][j] == 0) continue;

			for (int k = 0; k < (1 << W); k++) {
				int bit[2][12]; bool flag = false;
				for (int l = 0; l < W; l++) bit[0][l] = (j / (1 << l)) % 2;
				for (int l = 0; l < W; l++) bit[1][l] = (k / (1 << l)) % 2;
				for (int l = 0; l < W; l++) {
					if (bit[0][l] == 1 && bit[1][l] == 1) flag = true;
					if (l < W - 1 && bit[1][l] == 1 && bit[1][l + 1] == 1) flag = true;
					if (l < W - 1 && bit[0][l] == 1 && bit[1][l + 1] == 1) flag = true;
					if (l < W - 1 && bit[1][l] == 1 && bit[0][l + 1] == 1) flag = true;
					if (bit[1][l] == 1 && c[i][l] == '#') flag = true;
				}
				if (flag == false) {
					dp[i + 1][k] += dp[i][j];
					dp[i + 1][k] %= mod;
				}
			}
		}
	}

	// Step #3. Output
	long long Answer = 0;
	for (int i = 0; i < (1 << W); i++) Answer += dp[H][i];
	cout << Answer % mod << endl;
	return 0;
}
```

```cpp
// 023-03.cpp
#include <iostream>
using namespace std;

long long mod = 1000000007;
long long H, W;
long long dp[18][18][1 << 18];
char c[25][25];

int main() {
	// Step #1. Input
	cin >> H >> W;
	for (int i = 0; i < H; i++) {
		for (int j = 0; j < W; j++) cin >> c[i][j];
	}

	// Step #2. DP
	dp[0][0][0] = 1;
	for (int i = 0; i < H; i++) {
		for (int j = 0; j < W; j++) {
			int n1 = i, n2 = j + 1;
			if (n2 == W) { n1 += 1; n2 = 0; }

			for (int k = 0; k < (1 << (W + 1)); k++) {
				if (dp[i][j][k] == 0) continue;
				int bit[25];
				for (int l = 0; l <= W; l++) bit[l] = (k / (1 << l)) % 2;
				dp[n1][n2][k >> 1] += dp[i][j][k];
				dp[n1][n2][k >> 1] %= mod;
				bool flag = true;
				if (c[i][j] == '#') flag = false;
				if (bit[0] == 1 && i >= 1 && j >= 1) flag = false;
				if (bit[1] == 1 && i >= 1) flag = false;
				if (bit[2] == 1 && i >= 1 && j <= W - 2) flag = false;
				if (bit[W] == 1 && j >= 1) flag = false;
				if (flag == true) {
					dp[n1][n2][(k >> 1) + (1 << W)] += dp[i][j][k];
					dp[n1][n2][(k >> 1) + (1 << W)] %= mod;
				}
			}
		}
	}

	// Step #3. Get Answer
	long long Answer = 0;
	for (int i = 0; i < (1 << (W + 1)); i++) Answer += dp[H][0][i];
	cout << Answer % mod << endl;
	return 0;
}
```

```cpp
// 023-04a.cpp
#include <iostream>
#include <string>
#include <map>
using namespace std;

// Input
int H, W;
char c[25][25];

// Map
int cnt[25];
bool used[25][25];
int nex0[25][1 << 18];
int nex1[25][1 << 18];
string state[25][1 << 18];
map<string, pair<int, bool>> Map[25];

// DP
int mod = 1000000007;
int dp[25][25][1 << 18];

bool hantei(int sx, int sy) {
	int dx[8] = { 1, 1, 1, 0, -1, -1, -1, 0 };
	int dy[8] = { -1, 0, 1, 1, 1, 0, -1, -1 };
	for (int i = 0; i < 8; i++) {
		int tx = sx + dx[i], ty = sy + dy[i];
		if (tx < 0 || ty < 0 || ty >= W) continue;
		if (used[tx][ty] == true) return false;
	}
	return true;
}

void dfs(int pos, int dep, string str) {
	int sx = pos / W, sy = pos % W;
	if (dep == W + 1) {
		int idx = cnt[sy];
		bool flag = hantei(sx, sy);
		state[sy][idx] = str;
		Map[sy][str] = make_pair(idx, flag);
		cnt[sy] += 1;
		return;
	}

	dfs(pos + 1, dep + 1, str + "0");
	if (hantei(sx, sy) == true) {
		used[sx][sy] = true;
		dfs(pos + 1, dep + 1, str + "1");
		used[sx][sy] = false;
	}
}

int main() {
	// Step #1. Input
	cin >> H >> W;
	for (int i = 0; i < H; i++) {
		for (int j = 0; j < W; j++) cin >> c[i][j];
	}

	// Step #2. Initialize
	for (int i = 0; i < W; i++) {
		dfs(i, 0, "");
	}
	for (int i = 0; i < W; i++) {
		for (int j = 0; j < cnt[i]; j++) {
			string t = state[i][j];
			string t0 = t.substr(1, t.size() - 1) + "0";
			string t1 = t.substr(1, t.size() - 1) + "1";
			nex0[i][j] = Map[(i + 1) % W][t0].first;
			if (Map[i][t].second == true) {
				nex1[i][j] = Map[(i + 1) % W][t1].first;
			}
			else {
				nex1[i][j] = -1;
			}
		}
	}

	// Step #3. DP
	dp[0][0][0] = 1;
	for (int i = 0; i < H; i++) {
		for (int j = 0; j < W; j++) {
			int n1 = i, n2 = j + 1;
			if (n2 == W) { n1 += 1; n2 = 0; }

			for (int k = 0; k < cnt[j]; k++) {
				if (dp[i][j][k] == 0) continue;
				dp[n1][n2][nex0[j][k]] += dp[i][j][k];
				dp[n1][n2][nex0[j][k]] %= mod;
				if (nex1[j][k] != -1 && c[i][j] == '.') {
					dp[n1][n2][nex1[j][k]] += dp[i][j][k];
					dp[n1][n2][nex1[j][k]] %= mod;
				}
			}
		}
	}

	// Step #4. Output The Answer
	int Answer = 0;
	for (int i = 0; i < cnt[0]; i++) {
		Answer += dp[H][0][i];
		Answer %= mod;
	}
	cout << Answer << endl;
	return 0;
}
```
