# 073 — Count ways to delete tree edges so every component contains both 'a' and 'b'

**Difficulty:** ★×5 (author's star rating)
**Link:** https://atcoder.jp/contests/typical90/tasks/typical90_bu

## Statement (original Japanese)
N 頂点の木が与えられます。木の頂点は 1, 2, ⋯ , N と番号付けられており、i 番目の辺は頂点 a_i と頂点 b_i を双方向に結んでいます。
各頂点には `a`, `b` いずれかの文字が書かれており、頂点 i に書かれている文字は c_i です。

0 本以上の辺を削除する方法は 2^{N − 1} 通りありますが、その中で「辺を削除した後、すべての連結成分が `a`, `b` 両方の文字を含む」ものは何通りかを求め、10^{9 + 7} で割った余りを出力してください。

## Statement (English translation)
You are given a tree with N vertices. The vertices are numbered 1, 2, ⋯, N, and the i-th edge connects vertices a_i and b_i bidirectionally.
Each vertex has either the character `a` or `b` written on it, and the character written on vertex i is c_i.

There are 2^{N − 1} ways to delete zero or more edges. Among them, find the number of ways such that "after deleting edges, every connected component contains both the characters `a` and `b`", and output it modulo 10^{9 + 7}.

## Constraints
【制約】
・2 ≦ N ≦ 10^5
・c_i は `a`, `b` のいずれか
・1 ≦ a_i, b_i ≦ N
・与えられるグラフは木である

## Author's Editorial — Concept & Essence
- **Keyword (キーワード):** 木 DP に慣れよう (get used to tree DP)
- **Core idea:** Root the tree at vertex 1 and do a DP over subtrees. For each vertex `pos`, `dp[pos][s]` counts the ways to cut edges inside the subtree so that every fully-separated component is valid and the component still containing `pos` has state `s`, where state 0 = contains only 'a', state 1 = contains only 'b', state 2 = contains both. Combining children multiplicatively and rooting the tree makes the whole computation O(N).
- **Editorial steps:**
  - **解法.** Root the tree at vertex 1 and run the following DP. `dp[pos][state] =` (the number of ways to cut edges in the subtree of `pos`, where the component containing `pos` has state: 0 = only 'a', 1 = only 'b', 2 = both 'a' and 'b'). For example, in the picture, vertex 2's component contains only 'b', so `dp[2][1] = 1`. Also, for the condition "every component cut off so far contains both 'a' and 'b'", the component containing vertex 2 exists and contains no 'a', so among the two ways of cutting shown in the figure, `dp[2][1] = 2` is intended. The answer to this problem is `dp[1][2]`.
  - **Computing the DP values.** If `pos` is labelled 'a' and the children of `pos` are (b_1, b_2, ..., b_k), then
    `dp[pos][0] = ∏_{i=1}^{k} (dp[b_i][0] + dp[b_i][2])`.
    Reason: when the edge (pos, b_i) is deleted, the connected component containing b_i must contain both 'a' and 'b' (contributing `dp[b_i][2]`); when it is not deleted, it may contain only 'a' (contributing `dp[b_i][0]`).
  - Also `dp[pos][2]` is given by the following formula (when the edge is not deleted anything is allowed, but when it is deleted we must transition from the state `dp[b_i][2]`):
    `dp[pos][2] = ∏_{i=1}^{k} (dp[b_i][0] + dp[b_i][1] + 2·dp[b_i][2]) − ∏_{i=1}^{k} (dp[b_i][0] + dp[b_i][2])`.
    (The subtracted term is the "bad" case where the component containing `pos` ends up with only 'a'.)
  - When `pos` is labelled 'b', think symmetrically: `dp[pos][1] = ∏ (dp[b_i][1] + dp[b_i][2])` and `dp[pos][2]` is the same expression with the corresponding bad case subtracted.
  - To compute `dp[pos][...]` we need `dp[b_1][...], dp[b_2][...], ..., dp[b_k][...]` already computed, so we root at vertex 1 and compute bottom-up (post-order). This is achievable by depth-first search (DFS) in O(N).
- **Complexity:** O(N) in total.
- **Author's takeaway / typical pattern (典型):** Doing DP on a tree solves the whole problem in O(N). Computing DP values from the leaves upward is called tree DP; it is also used to compute subtree sizes. Related techniques worth studying: the two-pass tree DP and the all-directions (rerooting) tree DP.

## Author's Reference Solution
- `073.cpp` — Tree DP over rooted tree at vertex 1: `dp[pos][0/1/2]` = ways for the component containing `pos` to be {only a / only b / both}, with all separated components valid; answer `dp[1][2]` mod 1e9+7.

```cpp
#include <iostream>
#include <vector>
using namespace std;

long long N, A[1 << 18], B[1 << 18];
char C[1 << 18];

long long mod = 1000000007;
long long dp[1 << 18][3];
vector<int> G[1 << 18];

void dfs(int pos, int pre) {
	long long val1 = 1, val2 = 1;
	for (int i : G[pos]) {
		if (i == pre) continue;
		dfs(i, pos);
		if (C[pos] == 'a') {
			val1 *= (dp[i][0] + dp[i][2]);
			val2 *= (dp[i][0] + dp[i][1] + 2LL * dp[i][2]);
		}
		if (C[pos] == 'b') {
			val1 *= (dp[i][1] + dp[i][2]);
			val2 *= (dp[i][0] + dp[i][1] + 2LL * dp[i][2]);
		}
		val1 %= mod;
		val2 %= mod;
	}

	if (C[pos] == 'a') {
		dp[pos][0] = val1;
		dp[pos][2] = (val2 - val1 + mod) % mod;
	}
	if (C[pos] == 'b') {
		dp[pos][1] = val1;
		dp[pos][2] = (val2 - val1 + mod) % mod;
	}
}

int main() {
	// Step #1. Input
	cin >> N;
	for (int i = 1; i <= N; i++) cin >> C[i];
	for (int i = 1; i <= N - 1; i++) {
		cin >> A[i] >> B[i];
		G[A[i]].push_back(B[i]);
		G[B[i]].push_back(A[i]);
	}

	// Step #2. DFS
	dfs(1, -1);
	cout << dp[1][2] << endl;
	return 0;
}
```
