H 行 W 列のマス目があり、上から i 行目・左から j 列目のマスを (i, j) と表します。
最初すべてのマスは白いです。次の Q 個のクエリを順に処理してください。

《type[i] = 1 のとき》
・整数 x, y が与えられる
・元々白かったマス (x, y) が赤く塗られる

《type[i] = 2 のとき》
・整数 xa, ya, xb, yb が与えられる
・マス (xa, ya) からマス (xb, yb) まで上下左右に隣り合うマスを介して移動し、赤マスのみを通って辿り着ける場合は "Yes"、そうでなければ "No" と出力する。

## Statement (English translation)
There is a grid with H rows and W columns, and the cell at the i-th row from the top and j-th column from the left is denoted (i, j).
Initially all cells are white. Process the following Q queries in order.

《When type[i] = 1》
・Integers x, y are given.
・The originally white cell (x, y) is painted red.

《When type[i] = 2》
・Integers xa, ya, xb, yb are given.
・If one can travel from cell (xa, ya) to cell (xb, yb) through vertically/horizontally adjacent cells using only red cells, output "Yes"; otherwise output "No".

## Constraints
【制約】
・1 ≦ H, W ≦ 2000
・1 ≦ Q ≦ 100000
・1 ≦ type[i] ≦ 2
・type[i] = 1 のとき、1 ≦ x ≦ H、1 ≦ y ≦ W
・type[i] = 2 のとき、1 ≦ xa, xb ≦ H、1 ≦ ya, yb ≦ W

## Author's Editorial — Concept & Essence
- **Keyword (キーワード):** 連結判定は Union-Find (Connectivity checking is Union-Find)
- **Core idea:** Treat each cell as a vertex and each adjacency between two cells as an edge. Query 1 (paint a cell red) links the newly red cell with its already-red neighbors; Query 2 asks whether two cells belong to the same connected component. A Union-Find (Disjoint Set Union) tree answers both link and connectivity in near-constant time.
- **Editorial steps:**
  - Introduce Union-Find: on N vertices, two operations — `link(x, y)` (connect vertex x and y) and connectivity check (can x and y reach each other) — each in O(α(N)), extremely fast.
  - Build a Union-Find tree of size H·W. Consider each cell a vertex and adjoining cells connected by edges. Both query types can then be handled by Union-Find, each in O(α(HW)).
  - Query 1: when painting (x, y) red, `unite` it with all adjacent cells that are already red.
  - Query 2: `same(xa·..., xb·...)` decides "Yes"/"No".
  - Footnote: α(N) is the inverse of the Ackermann function A(n,n); although A(n,n) is famously enormous even for small n, its inverse α(N) is at most 4 for any realistic data size.
- **Complexity:** O(HW + Q · α(HW))
- **Author's takeaway / typical pattern (典型):** Union-Find enables fast "are two vertices connected in a graph?" judgments, and it also handles the case where edges are added incrementally — a very convenient data structure.
- **Related problems (類題):** ATC 001-B「Union-Find」, ABC 075-C「Bridge」, 第四回アルゴリズム実技検定 問題G「村整備」
- **Flags:** none

## Author's Reference Solution
- **012.cpp** — Union-Find over H·W cells; Query 1 unites the painted cell with red 4-neighbors, Query 2 checks `same` after verifying both cells are painted.

```cpp
#include <iostream>
#include <vector>
using namespace std;

class UnionFind {
public:
	vector<int> par;

	void init(int sz) {
		par.resize(sz, -1);
	}
	int root(int pos) {
		if (par[pos] == -1) return pos;
		par[pos] = root(par[pos]);
		return par[pos];
	}
	void unite(int u, int v) {
		u = root(u); v = root(v);
		if (u == v) return;
		par[u] = v;
	}
	bool same(int u, int v) {
		if (root(u) == root(v)) return true;
		return false;
	}
};

// 入力
int H, W, Q;

// その他の変数
UnionFind UF;
bool used[2009][2009];

void query1(int px, int py) {
	int dx[4] = { -1, 0, 1, 0 };
	int dy[4] = { 0, 1, 0, -1 };
	for (int i = 0; i < 4; i++) {
		int sx = px + dx[i], sy = py + dy[i];
		if (used[sx][sy] == false) continue;
		int hash1 = (px - 1) * W + (py - 1);
		int hash2 = (sx - 1) * W + (sy - 1);
		UF.unite(hash1, hash2);
	}
	used[px][py] = true;
}

bool query2(int px, int py, int qx, int qy) {
	if (used[px][py] == false || used[qx][qy] == false) {
		return false;
	}

	int hash1 = (px - 1) * W + (py - 1);
	int hash2 = (qx - 1) * W + (qy - 1);
	if (UF.same(hash1, hash2) == true) return true;
	return false;
}

int main() {
	// Step #1. 入力
	cin >> H >> W >> Q;

	// Step #2. Union Find の初期化
	UF.init(H * W);

	// Step #3. クエリ処理
	for (int i = 1; i <= Q; i++) {
		int ty; cin >> ty;
		if (ty == 1) {
			int x, y;
			cin >> x >> y;
			query1(x, y);
		}
		if (ty == 2) {
			int xa, xb, ya, yb;
			cin >> xa >> ya >> xb >> yb;
			bool Answer = query2(xa, ya, xb, yb);
			if (Answer == true) cout << "Yes" << endl;
			else cout << "No" << endl;
		}
	}
	return 0;
}
```
