# 021 — Pairs of Mutually Reachable Vertices

**Difficulty:** ★×5 (author's star rating)
**Link:** https://atcoder.jp/contests/typical90/tasks/typical90_u
**Source:** AtCoder Typical90 #021 — official statement and samples; editorial essence distilled from the official Japanese slides.

## Statement (original Japanese)
N 頂点 M 辺の有向グラフがあります。
辺には 1, 2, ..., M と番号が付けられており、辺 i は頂点 A[i] から頂点 B[i] に向かいます。

次の条件を満たす 2 頂点 (x, y) [1 ≦ x < y ≦ M] の組はいくつありますか。
・頂点 x から頂点 y に向かうパス、頂点 y から頂点 x に向かうパス両方が存在する。

## Statement (English translation)
There is a directed graph with N vertices and M edges.
The edges are numbered 1, 2, ..., M, and edge i is directed from vertex A[i] to vertex B[i].

How many pairs of two vertices (x, y) [1 ≦ x < y ≦ M] satisfy the following condition?
・Both a path from vertex x to vertex y and a path from vertex y to vertex x exist.

(Note: the text file writes the range as [1 ≦ x < y ≦ M]; from context this is evidently a typo for [1 ≦ x < y ≦ N], since N is the number of vertices. The slide confirms [1 ≦ x < y ≦ N].)

## Constraints
・2 ≦ N ≦ 100000
・1 ≦ M ≦ 200000
・1 ≦ A[i], B[i] ≦ M
・A[i] ≠ B[i]
・入力はすべて整数

(Note: the bound 1 ≦ A[i], B[i] ≦ M is likewise evidently a typo for ≦ N.)

## Author's Editorial — Concept & Essence
- **Keyword (キーワード):** 強連結成分分解（SCC）をしよう
- **Core idea:** Partition the vertices into groups such that two vertices are in the same group exactly when they can reach each other (strongly connected components). A pair (x, y) satisfies the condition precisely when x and y lie in the same SCC, so the answer is the sum over components of C(size, 2) = size·(size−1)/2. SCC can be computed in O(N + M) by Kosaraju's two-pass DFS.
- **Editorial steps:**
  - Define a partition of the vertices into groups: put vertices that can reach each other in the same group, and vertices that cannot reach each other in different groups. (Example in the slide: {1,2,7}, {4,5,6,9}, {3,8}.)
  - If the graph splits into k groups with a₁, a₂, ..., a_k vertices, then Answer = Σ_{i=1}^{k} a_i(a_i−1)/2. (Slide example: a = (2,4,3), giving 1 + 6 + 3 = 10.)
  - ステップ1: Run a depth-first search (DFS) and record vertices in the order in which their DFS finishes.
  - ステップ2: Reverse all edges, then run DFS in decreasing order of the recorded finish numbers; each DFS tree is one strongly connected component.
- **Complexity:** O(N + M)
- **Author's takeaway / typical pattern (典型):** The condition "vertex x and y are mutually reachable" is called strong connectivity; SCC splits any directed graph into groups of strongly connected vertices. After SCC, contracting each group to a single vertex yields a DAG containing no cycles, which is useful in many problems.
- **Related problems (類題):**
  - JOI 2009 春合宿 「Advertisement」
  - AOJ 0366 「道路整備」
  - ARC 010-D 「情報伝達」
- **Flags:** none. (The statement/constraint typos noted above are in the source file, not the editorial.)

## Author's Reference Solution
`021.cpp` — Kosaraju's SCC: first DFS on the original graph G pushes vertices onto a stack `I` by finish order; then the reversed graph H is DFS'd in reverse finish order, and the size `cnts` of each component contributes `cnts*(cnts-1)/2` to the answer.

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

// Input
int N, M;
int A[1 << 18], B[1 << 18];

// Graph
bool used[1 << 18];
vector<int> G[1 << 18];
vector<int> H[1 << 18];
vector<int> I;
long long cnts = 0;

void dfs(int pos) {
	used[pos] = true;
	for (int i : G[pos]) {
		if (used[i] == false) dfs(i);
	}
	I.push_back(pos);
}

void dfs2(int pos) {
	used[pos] = true;
	cnts++;
	for (int i : H[pos]) {
		if (used[i] == false) dfs2(i);
	}
}

int main() {
	// Step #1. Input
	cin >> N >> M;
	for (int i = 1; i <= M; i++) {
		cin >> A[i] >> B[i];
		G[A[i]].push_back(B[i]);
		H[B[i]].push_back(A[i]);
	}

	// Step #2. First DFS
	for (int i = 1; i <= N; i++) {
		if (used[i] == false) dfs(i);
	}

	// Step #3. Second DFS
	long long Answer = 0;
	reverse(I.begin(), I.end());
	for (int i = 1; i <= N; i++) used[i] = false;
	for (int i : I) {
		if (used[i] == true) continue;
		cnts = 0;
		dfs2(i);
		Answer += cnts * (cnts - 1LL) / 2LL;
	}

	// Step #4. Output The Answer!
	cout << Answer << endl;
	return 0;
}
```
