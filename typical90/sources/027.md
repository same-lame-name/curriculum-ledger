# 027 — Days on Which Registrations Were Accepted

**Difficulty:** ★×1 (author's star rating)
**Link:** https://atcoder.jp/contests/typical90/tasks/typical90_aa
**Source:** AtCoder Typical90 #027 — official statement and samples; editorial essence distilled from the official Japanese slides.

## Statement (original Japanese)
低橋君は、競技プログラミングのサイト「LowCoder」を作り、サービスを開始しました。
今日の時点では、「LowCoder」にユーザーはいません。

今日から数えて i (1≦i≦N) 日後には、ユーザー名 S[i] を希望するユーザーが登録申請を行い、次のことが起こります。
・その時点でユーザー名が S[i] であるユーザーが存在する場合、その登録申請は無視されます。
・一方、存在しない場合は登録申請が受理され、LowCoder にそのユーザーが登録されます。

登録申請が受理されたのが、何日目に登録申請を行ったユーザーなのか、小さい順に出力せよ。

## Statement (English translation)
Mr. Teibashi made a competitive-programming site "LowCoder" and started its service.
As of today, there are no users on "LowCoder".

On the i-th day from today (1 ≦ i ≦ N), a user wishing for the username S[i] files a registration request, and the following happens:
・If a user with username S[i] already exists at that point, the registration request is ignored.
・Otherwise the registration request is accepted, and that user is registered on LowCoder.

Output, in increasing order, the days on which the registration requests that were accepted were filed.

## Constraints
・1 ≦ N ≦ 10^5
・1 ≦ |S[i]| ≦ 15
S[i] は英小文字または数字から成る
・N は整数

## Author's Editorial — Concept & Essence
- **Keyword (キーワード):** map を使いこなそう
- **Core idea:** Maintain a set of already-registered usernames. For each day, if S[i] has not been seen before, print i and insert it. A `std::map` (or `std::set`) gives O(log N) per lookup/insertion.
- **Editorial steps:**
  - TLE solution: for each registration request, loop over previous requests to check whether the username is already registered; this is O(N²) and TLEs. In general, 10^8–10^9 operations are the accepted limit, so N ≤ 10^5 cannot be AC'd this way.
  - Solution: use `std::map`. With `std::map`, lookup costs O(log N). It feels basically like an array, but you can access it at arbitrary positions; whereas an array would be problematic if the index is not in 0 … N−1, `std::map` allows access at the 10^9-th item or even by character string.
  - Therefore, to check whether a character string has already been added, manage it with a map as follows, giving total complexity O(N log N):
    ```cpp
    map<string, int> Map;
    for (int i = 1; i <= N; i++) {
        if (Map[S[i]] == 0) cout << i << endl;
        Map[S[i]] = 1;
    }
    ```
- **Complexity:** O(N log N)
- **Author's takeaway / typical pattern (典型):** Using data structures such as `std::map` solves this in O(N log N). Besides `std::map`, data structures like `std::set` and `std::queue` also appear frequently in competitive programming. See 「鉄則! C++アルゴリズム実装に使える 25 の STL 機能」.

## Author's Reference Solution
`027.cpp` — keep a `map<string,int>` of seen usernames; on the first occurrence print the day index and mark it.

```cpp
#include <iostream>
#include <string>
#include <map>
using namespace std;

int N;
string S[1 << 18];
map<string, int> Map;

int main() {
	cin >> N;
	for (int i = 1; i <= N; i++) {
		cin >> S[i];
		if (Map[S[i]] == 0) {
			Map[S[i]] = 1;
			cout << i << endl;
		}
	}
	return 0;
}
```
